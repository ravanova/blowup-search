## 3. The three mechanisms, and why two obvious repairs were discarded

### M1 — the convergence flag was blind to the row it drops

`newton_gauged` set `converged = hist[-1] < 1e-11` from `F = [gauge row ; residual rows except
drop]`, so `converged is True` was structurally guaranteed for **any** root of the (J−1)-row
subsystem, however large the dropped row.

Leg 114's suggested fix — *"`converged` should be computed from the full residual including the
dropped row"* — is **measured dead in its absolute form**. Clean a-family solves legitimately
carry a large dropped row, because the dropped row is where the aliasing this module's own
docstring is about actually lands:

| clean input (om0=None, c=0.5) | `kept_sup` | `dropped_defect` | verdict today |
| --- | --- | --- | --- |
| a=0.0, J=60 | 9.12e-15 | 4.31e-15 | converged |
| a=0.1, J=60 | 7.61e-15 | 8.53e-05 | converged |
| a=0.3, J=60 | 7.42e-15 | 1.16e-03 | converged |
| a=0.4, J=60 | 8.05e-15 | 1.22e-02 | converged |
| a=0.5, J=60 | 1.03e-14 | **8.00e-02** | converged |

`experiments/p2_route_d_v12_defect.py` calls `newton_gauged` on exactly `a ∈ {0.0 … 0.5}` at
five sites. Any absolute `dropped_defect` clause moves those. **Rejected.**

**What landed instead**: the flag now also requires `relres` — the relative residual this method
*already computed over all J rows including the dropped one*, and then never consulted. It
separates where the absolute form cannot:

| | `relres` |
| --- | --- |
| clean, worst over a ∈ {0…0.5} × J ∈ {40,60,80,120} | **5.05e-02** |
| M1's third root (om0 = 0.1·anchor) | **1.257e+01** |
| M2's constant (om0 = zeros / ones) | 1.322e+01 / 1.314e+01 |

**249× two-sided**; the threshold is 1.0, which is not a tuned number but a statement — *the
residual must be smaller than the source term it is supposed to cancel* — sitting **19.8×** above
the worst clean case and **12.6×** below the nearest spurious one.

### M2 — the spurious constant root

`Ω ≡ −1` satisfies the gauge row and every collocation residual row (because `H(constant) = 0`
and `Ω_X = 0`), and was returned `converged=True` from `om0 = zeros`, `ones`, `1e-8·anchor` and
`0.01·anchor`. The same `relres` clause rejects all four. Its `‖Ω‖_X(α=2) = 5.8364e+03` against
the exact anchor's `1.0000` is still asserted in the battery, unchanged.

The tempting **decay-class** predicate was measured dead first. `|Ω(θ=π)| = |Σ(−1)^k A_k|` is the
interpolant at `X = ∞`, exactly 0 for the a=0 anchor and 1 for the constant — and it closes:

| | `\|Ω(π)\|` |
| --- | --- |
| clean a=0.5, J=60 | 6.806e-03 |
| **clean a=0.5, J=240** | **1.051e-01** |
| M1's third root | 7.786e-01 |

A clean, production-reachable input lands within **7.4×** of the spurious root. There is no
threshold there that does not move a clean result. `norm_domain(·, α=2)` fails the same way
(clean a=0.5 gives **32.53** against the anchor's 1.0000). **Rejected.**

### M3 — `critical_radius` had no magnitude test

The whole crossing test was `np.diff(np.sign(E)) != 0`. `E ≡ 0.5` with one entry at `−1e-16`
returned `X_c = 15.025019` where the truth is `inf`, moving by only `1.0e-04` across thirteen
decades of dip depth.

The **sustained-run** predicate was measured dead: a *real* crossing at a=0.15 has run length
**1**, identical to the adversary. **Rejected.**

What landed is leg 114's own words — a magnitude threshold relative to `|E|` — as a
**two-sided** test: the constant-sign excursion on **each** side of a crossing must reach
`min_rel_depth · max|E|`, default 1e-2.

**One side is not enough, and this leg's first draft got it wrong and the runner caught it.**
Testing only the far side rejects the downward dip and then *readmits the identical artifact one
index later*, through the field's own re-crossing back up, whose far side is the whole clean
field. The first runner pass reported `4/4 fixed=False` for exactly that reason. Recorded here
rather than silently corrected, per the leg-88/114 precedent.

Margins, both measured: worst real crossing `1.2289e-01` (**12.3×** above the threshold), worst
adversary `2.0e-03` (**5.0×** below it). `min_rel_depth=0.0` reproduces the pre-repair answer
exactly, so leg 114's measurement survives its own repair.

### The two structural gaps

`newton_gauged(max_iter=0)` raised `IndexError` on `hist[-1]`; it now returns. The `LinAlgError`
early-exit dicts omitted the normal path's keys, so `continuation` died with
`KeyError('relres')`; both dicts now carry them and `continuation([nan])` returns one flagged row
with `converged=False`, `relres=inf`.
