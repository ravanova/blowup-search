## The four findings that matter, as magnitudes

**1. The domain guard's window is `max|X|`, but the data live on `[X_min, X_max]`.**
`compactify` tests `inside = |Xt| <= |X|.max()`. For a grid symmetric about 0 that *is* the
data interval; for any other grid it is strictly larger, and every θ-sample in the gap goes
to `lagrange_interp_uniform`, whose index clip turns it into polynomial **extrapolation**.
`n_outside_grid` counts only samples beyond `max|X|`, so it reports **0**. The ladder:

| data `X_min` | real points | θ-samples extrapolated | reported `n_outside_grid` | `domain_valid` | warnings | fitted `p` | error vs exact 1.4 |
|---|---|---|---|---|---|---|---|
| −986.05 | 677 | 5 / 16384 | 0 | True | 0 | +1.403851 | 0.003851 |
| −97.88 | 600 | 53 / 16384 | 0 | True | 0 | +1.410248 | 0.010248 |
| **−9.71** | **523** | **535 / 16384** | **0** | **True** | **0** | **−0.088885** | **1.488885** |
| −1.00 | 449 | 4107 / 16384 | 0 | True | 0 | +0.119764 | 1.280236 |
| −0.09 | 407 | 7721 / 16384 | 0 | True | 0 | +0.271177 | 1.128823 |

At `X_min = −9.71` — a grid still carrying 523 real data points over four decades — **535
of 16384 samples are extrapolated**, the fitted exponent's **sign is wrong**
(`p = −0.0889` against the exact `1.4`, an error of **1.4889 = 386× the systematic**), and
`norm_verdict` flips to `finite = False`. Every guard field says clean.

For scale: leg 84's YES, and the whole bench repair, was built on **14** samples moving `p`
by **0.4166** — *with the count reported correctly*. This is **38× more samples** and a
**3.6× larger** exponent error, with the count reported as **zero**.

**2. The adjacent key re-silences leg 84's exact case.** `spectrum` returns both
`n_outside_grid = 14` and `frac_outside_grid = 0.0008544922` **in the same dict**.
`domain_fields` does `n = int(n_outside_grid)`, which **truncates**. Threading the count →
`domain_valid = False` + 1 warning. Threading the fraction → `domain_valid = True` + **0
warnings**. Any true violation rate below 100% of samples is a float in (0,1) and truncates
to 0, the literal definition of clean. There is no type or range check either: negative
fractions read clean, the string `'0'` reads clean, `'3'` is accepted as a count of 3, and
`True` as a count of 1.

**3. `analytic_tail` validates `margin` and nothing else.** `C = NaN` → `finite: True,
bound: nan, reason: None`. `C = Inf` → `bound: inf`. `C = −0.5` → `bound: −3.298770`, a
**negative upper bound on a sum of non-negative terms**. `N = NaN` → `bound: nan`. All with
`finite = True` and no warning. The one parameter it *does* gate, it gates correctly
(gate 8, the control): exactly at `margin = 0` it refuses to bound and gives a reason
(lesson 73).

**4. The fitter absorbs corrupted coefficients and overstates its own coverage.** A NaN
anywhere in a bin makes `hh[idx].mean() > 0.0` False, so the bin is discarded — but `acc` is
reset regardless, and the fit proceeds. At **150 of 225** modes set to NaN, `fit_exponent`
returns `p = 1.404831` (within 0.0048 of exact, i.e. *nothing looks wrong*) while reporting
`n_points = 225` when only **75** were finite — a **3.0× overstatement**, `n_bins` silently
down 19 → 4, 0 warnings, `domain_valid = True`. Fifty `|h_k|` set to **−1000** (impossible
for a magnitude) move `p` by `9.07e-05`; the only trace is `frac_zero_modes = 0.2222`, whose
`hh <= 0.0` test **mislabels negatives as symmetry-annihilated zeros** — the exact case the
field was added for.

## The rest, briefly

* **Descending `k` into `weighted_partial_sums`:** `S_64` reported as **exactly 0.0** against
  the true `1.120579`, and `S_4096` as `11.536158` against the true `1.665726` — an
  overstatement of **6.93×**. A norm wrong in both directions; `searchsorted` assumes
  ascending and nothing checks.
* **Shuffled `X`/`f` pairing:** `p = 1.49e-05` against exact `1.4` — **99.999%** of the true
  exponent gone — with `n_outside_grid = 0`, `domain_valid = True`, 0 warnings.
* **Mismatched sinh scale `c`:** `c = 1e−8` → error **142×** the systematic; `c = 1e8` →
  **360×**; both flip `norm_verdict` to `finite = False`, silently.
* **Zero-norm profiles:** the identically-zero and constant profiles have `‖·‖_w = 0` over
  `k ≥ 1` — finite, trivially *in* the space — and are reported `finite = False`. Wrong, but
  in the **conservative** direction.
* **`M = 2`:** an empty spectrum returned as a normal result.
