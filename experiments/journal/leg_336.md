## 3. Adjudication of `C11_aR1`: inert-by-construction, not missing data

`C11_aR1`'s row is the term `R₁ · (9(γ−2)γ + ((2−3γ)γ+5)r + 5)` inside BCG's `R₂`

not a coincidence local to `C11`; it is the *same* fact that makes `r*` the saddle-node where
`P_s` and `P̄_s` merge (leg 305's own §14/structural_findings). Perturbing the polynomial factor
by `(1 ± ε)` multiplies an exact zero, which is still exactly zero to the runner's precision —
there is no undetected response, no broken perturbation code path, and no data the runner failed
to collect. This is the textbook Lesson 90 tell (a control that cannot come out differently):
both directions report bit-identical zero, distinguishing "the geometry forces this term to
vanish" from "the instrument never fired" (which would look like small-but-nonzero noise, as the
genuine six capped rows show). **Adjudicated: inert-by-construction.**
