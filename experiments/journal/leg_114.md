## The three mechanisms

**M1 — the convergence flag is blind to the row it drops.** `newton_gauged` assembles
`F = [gauge row ; residual rows except drop]` and sets `converged = hist[-1] < 1e-11` from
that `F` alone. The dropped row — the one the docstring itself calls *"the one row it does
not see"* — is recomputed afterwards into `dropped_defect` and never consulted. `converged is
True` is therefore structurally guaranteed for any root of the (J−1)-row subsystem. Measured
from `om0 = 0.1 × anchor`: `converged=True`, `kept_sup = 9.20e-15`, **`dropped_defect =
3.3438`**, `weighted_defect = 33.12`.

**M2 — the one-gauge system has a second root, and it is quiet in every field.** `Ω ≡ −1`
satisfies the gauge row `Ω(θ=0) = −1` and every collocation residual row to `2.80e-13`,
because `H(constant) = 0` and `Ω_X = 0`. `newton_gauged` returns it with `converged=True`
from `om0 = zeros`, `ones`, and `1e-8 × anchor`. It is outside the decay class every Route-D
bound is stated in: `‖Ω‖_X(α=2) = 5.84e+03` against the exact anchor's `1.0000` at J = 60, and
the inflation **grows with resolution** — 2.59e+03 / 5.84e+03 / 1.04e+04 / 4.15e+04 at
J = 40/60/80/160. The certificate-visible defect on it is **1.72e-11** (4.65e-10 on the exact
constant) against the true anchor's 2.38e-13 — plausibly small in absolute terms. So the
module hands over a converged flag, a machine-zero residual, *and* a small Y₀ ingredient, for
a profile wrong by O(1) at every node.

*The control that isolated it.* The sibling `newton` refuses the identical start
(`converged=False`, relres 2.54e-02) because its **second** gauge, `Ω` at the node nearest
`X = 1` equals `−1/2`, misses the constant by 0.50. One gauge kills the scaling symmetry; it
does not kill the constant. `newton_gauged` is the single-gauge one — and it is also the one
whose matrix *is* the certificate's approximate inverse `A`, per its own docstring.

**M3 — `critical_radius` has no magnitude test.** Its whole crossing test is
`np.diff(np.sign(E)) != 0`. `E ≡ 0.5` with one entry dipped to `−1e-16` (4e-16 relative)
returns `X_c = 15.025019` where the truth is `inf`, and the answer moves by only **1.0e-04
across thirteen orders of magnitude of dip depth** — it carries essentially no information
about whether the crossing is real. Chained, `zero_order` turns that non-existent radius into
`p = 0.232454` from 141 points where the truth is `(nan, 0)`.

## Reachability — measured, and it changed how the finding is reported

This was the part worth the extra runs, and it is why the leg reports rather than escalates.

- Production (`experiments/p2_route_d_v12_defect.py`) calls `newton_gauged(c=…)` with
  `om0=None`, which starts at the anchor and lands on the true anchor:
  `dropped_defect = 4.31e-15`, certificate defect `3.50e-14`. M1 and M2 need a
  caller-supplied `om0`.
- M2's basin is *under-scaled starts only*: `λ × anchor` gives the true anchor for
  λ ∈ {0.3 … 5}, M1's third root at λ = 0.1, and the constant for λ ≤ 0.01 — the two
  spurious roots sit side by side just below the anchor's amplitude. **140 draws** of
  `anchor + ε·noise`, ε from 1e-12 to 0.3, hit the constant **0 times**.
- M3 needs a roundoff-scale crossing and real `E` fields do not supply one: the tangency
  margin is `min(E) = +1.101e-03` at a = 0.131 on the J = 60 grid, ~1e+13 times the roundoff
  floor, and **40 draws** of relative noise up to 1e-08 never flipped `X_c` from `inf` to
  finite.

So the gaps are **latent, not live** — and reporting them as live would have been the easy,
wrong version of this finding. `om0` is nonetheless a documented public parameter whose most
natural degenerate value (`zeros`) triggers M2, and `critical_radius` is consumed at three
sites in `solver/turning_point.py` and five in `experiments/p2_route_d_v12_defect.py`.

## One classification I got wrong on the first run, and fixed

The first pass scored `critical_radius` returning `inf` as `NONFINITE` for the
one-`+Inf` and identically-zero `E` cases, by a blanket `not np.isfinite(v)` test. That was my
bug, not the module's: `inf` is this function's **own encoding of "no crossing"**, so
non-finiteness is not by itself evidence of anything. Re-scored: the one-`+Inf` field genuinely
has no sign change, so `inf` is correct there (`FINITE`); `E ≡ 0` is a real weakness but a
different one (`SILENT_EMPTY` — an effective speed that vanishes at *every* radius is reported
as "the profile never ends", indistinguishable from a healthy non-crossing field). Verdict
counts moved 12→12 `NONFINITE`, 6→7 `SILENT_EMPTY`, 24→25 `FINITE`; the 8 `SILENT_WRONG` were
unaffected. Recorded here rather than silently corrected, per the leg-88 precedent.

## What was banked, and how a repair must land

`test_collocation_newton_adversarial.py` — 12 checks, **7 labelled `KNOWN GAP`** and asserting
the *wrong* behaviour as measured, 5 pinning the robustness that held (poison stays visible;
7 structural adversaries raise; `zero_order` recovers exponent 3.000000 exactly under 95% NaN
poisoning; the two-gauge control; the clean production path). This is leg 92's convention for
`solver/gclm.py`: a later bench repair **fails** this file and must **invert** those 7 checks
at the same thresholds rather than weakening them.

`solver/collocation_newton.py` is not patched here — the gate's YES branch says *"report the
exact failing case; escalate, do not patch under this leg's own authority"*, and the territory
forbids the edit under either branch. This is **not** one of the four escalations
(ORCHESTRATION.md §8): it rewrites no banked result, lifts no ban, touches
`plan_of_record.py` not at all, and claims nothing about the Clay chain. It lands on `main`
and the repair is a bench leg's.

**Suggested repair shape, for whoever takes it** (not implemented here): `converged` should be
computed from the *full* residual including the dropped row, not from `F`; the one-gauge
system needs a second condition (or an explicit decay-class check) to exclude the constant;
`critical_radius` needs a magnitude threshold on the crossing relative to `|E|`; the two
early-exit dicts should carry the normal path's keys.

## Relation to leg 110

Complementary, zero file overlap, as §114 pre-commits. Leg 110 audits whether the collocation
death certificate reproduces from its banked data; this leg audits the code that produced it.
**This leg does not reopen that death certificate** — the production path is measured clean
here, and none of M1–M3 is attributable to it. What it establishes is narrower: the module's
`converged` flag is not a safe input to a bound layer, because it is computed from a subsystem
that excludes the row the certificate cares about, on a system with a second root that
satisfies everything that flag can see.
