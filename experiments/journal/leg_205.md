## Gate, verbatim (`DIRECTION.md` leg 205, pre-committed, both branches)

> Under adversarial and degenerate inputs, does `boussinesq_rescaled.py` ever silently return a
> wrong value rather than reject or visibly propagate the defect?

## Answer

**YES.** Two mechanisms, both in the same nine-line reduction `odd_field_x_slope`
(`solver/boussinesq_rescaled.py:140-162`), and they are **not the same defect** (lesson 75).
18 of 81 cases came back `SILENT_WRONG`. Neither is patched here; both are escalated and parked
per the gate's yes-branch.

### Defect A -- leg 99's class, second occurrence, in the module leg 99 flagged by line number

`odd_field_x_slope` masks a fit window and hands the result to
`coef, *_ = np.linalg.lstsq(A, d1[m], rcond=None)` with **no occupancy check and no rank
check**. An empty window gives a `(0, 3)` design matrix, which `lstsq` absorbs into a zero
coefficient without raising or warning.

- **Empty window: returns exactly `0.0` against a truth of `2.0`** -- absolute error 2.000,
  relative error **100.0%**, **2000x** the module's own acceptance tolerance (`5e-4`, read off
  `test_boussinesq_rescaled.py::test_odd_field_x_slope`). Reproduced on three grids and, on the
  fully-resolved 400-node grid, through the public `r_win` argument alone.
- **One node against three parameters:** `lstsq` returns its minimum-norm solution, presented as
  the fit. **1.9061 vs truth 2.0**, relative error **4.694e-2**, **93.9x** tolerance.
- The fabricated `0.0` is **indistinguishable from a true answer at the call site**: the zero
  field genuinely has zero origin slope, and F4 confirms `odd_field_x_slope` returns `0.0` there
  correctly. So a consumer cannot tell "the origin strain vanishes" from "I could not measure
  it" -- which is verbatim the reading leg 99 gave the sibling's `-0.0`.

This is the **second occurrence** of the mechanism leg 99 measured in `u_x_at_origin` (`-0.0`
vs `-2.0`, 100%) and leg 104 confirmed repaired **there only**.
`writeup/novelty/leg_99.md` sec.4 note 2 named `solver/boussinesq_rescaled.py:161` **by line
number**, declined to test it as out of territory, and called "a follow-up leg scoped to
`boussinesq_rescaled.py`" the obvious next audit. That line is byte-unchanged. Leg 205 is that
follow-up, and the flag is now discharged as **confirmed**.

### Defect B -- NEW at leg 205, and provably not a variant of A

The fit window `r_win=0.4` is a **hard-coded absolute length that never references the field's
own radial scale**, and the least-squares residual that would expose the resulting misfit is
**discarded by the `*_` in the same line**. So for a perfectly smooth, in-contract, odd-in-x
field whose decay scale sits well inside 0.4, the three-term basis `(r, r^3, r^5)` cannot
represent `d1` over the window, and the function returns a finite plausible wrong number **on a
fully resolved grid** -- 177 nodes in the window, no exception, no warning.

Field `2 x exp(-lam r^2)`, truth `2.0` exactly, 400-node leg-73-class grid, window full in every
row:

| field scale `1/sqrt(lam)` | returned | rel. error | x module tolerance |
| --- | --- | --- | --- |
| 1.0 | +2.000940 | 4.698e-4 | 0.9 (**inside** -- the module's own gate lives here) |
| 0.5 | +1.997847 | 1.077e-3 | 2.2 |
| 0.2 | +1.767750 | 1.161e-1 | 232.3 |
| 0.1 | +0.886782 | 5.566e-1 | 1113.2 |
| 0.05 | +0.269302 | **8.653e-1** | **1730.7** |

**It reaches the coupled entry point.** `modulation` returns `c_l = 2 eta_x(0)/omega_x(0)` =
**+0.188423 against a truth of 1.4** (rel. error **8.654e-1**, **1730.8x** tolerance) when
`omega` and `eta` carry different radial scales -- finite, plausible, no warning. The module
docstring asserts that "the projection's quadrature bias **CANCELS** in the ratio (same basis
both reads)"; that cancellation holds only when the two fields share a radial scale, which the
Chen-Hou profile these constants target does not require.

**Why B is not A, measured rather than argued.** Across the whole failing sweep the `lstsq`
**rank is 3 in every row** and the **condition number is constant at 5.537e2**, while the
discarded relative residual tracks the slope error across four decades (1.20e-5 -> 8.64e-1
against 3.86e-5 -> 8.65e-1). **Leg 99's occupancy+rank guard is therefore provably blind to
B** -- porting the sibling's fix verbatim would close A and leave B untouched. Only the
discarded residual sees it.

**The recovery control, and the fix direction as a measurement (lesson 90).** Same field, same
grid, same code, only `r_win` varying: `0.4 -> 0.269302` (86.5% wrong), `0.1 -> 1.766702`,
`0.02 -> 2.000941` (**inside tolerance**, 112 nodes), `0.005 -> 2.000999` (82 nodes). Occupancy
stays healthy throughout, so occupancy is not what changes. `odd_field_x_slope` is fully
**capable** of the right answer; what it lacks is any way to notice its default window is the
wrong size and any way to say so.

**Why it survived to leg 205.** The module's only correctness gate,
`test_boussinesq_rescaled.py::test_odd_field_x_slope`, uses `exp(-r^2)` -- `lam = 1`, the single
scale at which the read is accurate -- with a loose `3e-2` tolerance. At `lam=1` the error is
4.70e-4; at `lam=400` it is 8.65e-1, **1842x worse**, and never run.

## What the battery did NOT find -- banked so a later leg does not re-derive it

Negative results are the point, per DIRECTIVE 3.

- **The rank-deficient-but-nonempty window is NOT a live defect at `modulation()`.**
  `u_x_at_origin`'s window (`r<0.1`, 2 params) is a **strict subset** of this module's
  (`r<0.4`, 3 params) -- both mask on `index >= 3` -- so an empty window here always trips leg
  99's guard first, and in the surviving rank-deficient case both fit nodes necessarily lie at
  `r < 0.1`. Enumerated: 136 such grids exist; over **80 scored pairs**, each of which passed
  its own resolved control, the worst `c_l` error is **1.899e-6**, i.e. **0.0038x** the module's
  own tolerance. A clean negative with a magnitude. *(This is where a first cut of F2 went
  wrong: the widest gap it reported, 1.45e-2, came from `lam_eta=100` fields whose **resolved**
  control was itself 55.7% off -- defect B leaking into A's family. The standing rule "when a
  control contradicts the mechanism, suspect the control's REALIZATION" caught it; F2 was
  rebuilt as a paired experiment that scores a grid only if its resolved control passes, and
  160 of 240 pairs were rejected on exactly that criterion.)*
- **Nothing is swallowed on the field path.** NaN and Inf planted in `omega`, `eta` or `xi`,
  inside or outside the fit window, always reach the returned RHS arrays (contaminated fraction
  1.0 for `omega` plants, 6.3e-4 to 7.3e-4 for the localized `eta`/`xi` plants). `c_l` itself
  stays finite for out-of-window plants (1.3976), but the RHS is visibly non-finite, so the
  defect propagates. `NONFINITE`, not `SILENT_WRONG`, on all six.
- **The legs 129/188 dealiasing-mask class has no site in this module.** It contains no FFT, no
  spectral truncation and no mask; `grep` puts `dealias_mask2d` in `solver/spectral_utils.py`
  and the `boussinesq.py` family only. The angular DST-I here is an exact bijection on grid
  fields (`S @ S = (M/2) I`): round-trip relative error **3.64e-15** on a random field and
  **5.57e-15** on the highest representable mode `n=16`, which is not annihilated. The control
  can report the other answer -- a truncating mask would show as finite round-trip loss.
  **So this leg's YES is a genuinely different defect, and escalates separately** (see below).
- **Degenerate parameters raise rather than fabricate.** `c_l = 0/0` raises `ZeroDivisionError`;
  `n_r = 1` and `n_beta = 1` raise `IndexError`; `run(max_steps=0)` raises `UnboundLocalError`;
  a reversed radial interval is refused at `PolarGrid` construction (leg 99's own repair).
  11 `RAISED` in total.
- **`grad_xy` and `advection_speeds` are not implicated.** Known-answer controls: `f = x` gives
  `f_x` within 7.52e-4 and `f_y` within 2.58e-4 over the interior band; `u = v = 0` gives
  `s_rho - c_l = 0.0` and `s_beta = 0.0` exactly. Pinned so the escalation stays scoped to the
  one reduction.
- **Two `NO_REFERENT` cases**, recorded with magnitudes and explicitly not used to answer the
  gate (lesson 73): a constant field and an even-in-x field both violate the documented
  odd-in-x precondition, so no truth exists to compare against.

## Escalation

Per the gate's yes-branch this leg **pushes its branch only, never `main`**, does not patch, and
reports as **parked**.

1. **Defect A cross-references leg 99's escalation, it does not duplicate it.** It is the second
   occurrence of an already-known class, in the sibling leg 99 explicitly flagged and leg 104
   explicitly did not patch. The fix is the same two lines leg 99 prescribed (count the mask,
   check `lstsq`'s returned rank), applied to `odd_field_x_slope` with **3** as the parameter
   count rather than 2. It belongs to whoever owns the module.
2. **Defect B is new and needs its own decision.** It is **not** the dealiasing-mask question
   legs 129/188 raise -- that class has no site in this module (measured above) -- so under the
   gate's own disjunction it escalates **separately** rather than being folded into
   escalation #4. The available guard is the residual the code already computes and throws away;
   whether the right response is to gate on it, to size the window from the field, or to
   document the precondition is a module-owner decision, not this leg's.
3. **Blast radius, stated honestly and NOT as a claim about banked results.** The unguarded
   reduction is public and is called outside `modulation` by
   `experiments/p2_route_l_v1_precond.py:222-229` -- which additionally *divides* by its return
   value -- and by `writeup/3_spikes/spike1_stepB_evidence.py:84-85`. `RescaledBoussinesq.run`
   calls it twice per `renorm=True` step for the same purpose. **This leg did not re-run any
   banked result and does not claim any banked number moves.** Whether the Spike-1 Step-B/C
   numbers were computed on fields concentrated enough for defect B to bite is a separate
   question that needs its own leg; the profiles in play there use `exp(-r^2)`-class envelopes,
   i.e. the safe scale, which is a reason to expect no movement but is not a measurement of it.
   Flagging, not claiming.
