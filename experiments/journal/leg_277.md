## 2. Why there are two candidate constants, and which one Definition 4.1 displays

Xu's Definition 4.1 names **two** norms in consecutive sentences:

* **eq. (4.2), the displayed definition:** `X = {φ : φ odd, φ, φ″ ∈ L²(0,∞), …}` with
  `‖φ‖²_X = ‖φ‖²_{L²} + ‖φ″‖²_{L²}` — the `L²` is **`L²(0,∞)`, the half-line**;
* **the next sentence:** *"Extended oddly to the line, X is the odd part of `H²(R)` **with an
  equivalent norm**"* — named as *equivalent*, i.e. a different norm.

`solver/origin_h2_certificate.py` computes the second one: `x_norm_y` (L469) says *"over the
whole line"* and `x_norm` (L142) is documented *"up to the common factor `sqrt(2 pi)`"*. Leg
249's W2 measured that constant (`∫_ℝ φ_m conj(φ_n) dy = 2π δ_mn`), and W5 converted with it.
**Nothing in the repository records that this is the second reading rather than the first.**

## 3. X1 — the conversion constant, measured rather than assumed

The half-line Gram `H_mn = ∫₀^∞ (φ_m conj(φ_n) + φ_m″ conj(φ_n″)) dy` was built with an
independent `y = exp(sinh u)` double-exponential rule (doubly exponential at **both** endpoints —
the algebraic-tail defect leg 249 recorded is why an ordinary tanh-sinh cut will not do here).

| | |
|---|---|
| full-line rule vs `2π(I + J⁴)` | `2.33e−09` — **reproduces leg 249's W2 independently** |
| half-line: `Re H` vs `π(I + J⁴)` | **`1.48e−08`** |
| half-line: `max |Im H|` at `n = 8` | **`245890`** — exact integers (`S₀₁ = 130`, `S₂₃ = 8322`) |
| antisymmetry defect of `Im H` | `1.16e−10` |
| stability over 4 quadrature rules (`h`, `U`) | the imaginary entries are **identical to 10 digits** — converged, not noise |

So **the two norms Definition 4.1 names are not proportional as Hermitian forms**:
`H = πG + iS` with `S` real, antisymmetric and large. Its eigenvalues
(`0.0963 … 1.277e6`) are nowhere near `πG`'s (`3.479 … 1.100e6`).

**But the certificate does not live on complex coefficients.** Leg 249 §8's realification (`m`
and `ℓ` are purely imaginary, so a diagonal unitary makes the whole bordered section real) puts
it on the **real** coefficient subspace, where the antisymmetric `S` contributes exactly zero:

* real data, 8 samples: `c'Hc / (π c'Gc) = 1` to **`2.20e−14`**
* **control that can come out differently, and does:** on complex data the same ratio deviates
  by **`0.676`** — 68 %, not round-off.

**The constant for Xu's displayed definition is therefore `π`, and the squared norm is exactly
HALF the full-line one leg 249 used.** The realification itself is checked, not assumed: real
and complex sections agree to `5.9e−14 / 2.8e−15 / 2.4e−13` across the three conventions.
