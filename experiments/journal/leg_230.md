## 1. What "independent" means here, precisely

The failure mode a verification leg exists to catch is **leg 220's runner agreeing with
itself**. So `experiments/p2_route_tnr_v1_repair.py` is **never imported and never executed**
by this leg, and neither are leg 220's five rungs reused.

**The truth is a closed form, not a re-implementation.** The module samples
`theta_j = -pi + 2*pi*(j + 1/2)/M` and maps by `X_j = tan(theta_j/2)`, which is strictly
increasing on `(-pi, pi)`. So `X_j` is inside `[X_lo, X_hi]` iff `theta_j` is inside
`[2*arctan(X_lo), 2*arctan(X_hi)]`, and with `u(t) = M*(t + pi)/(2*pi) - 1/2`:

```
n_below = clamp(ceil(u(t_lo)), 0, M)      n_above = clamp(M - 1 - floor(u(t_hi)), 0, M)
```

Two `ceil`/`floor` evaluations in plain Python. **No array is ever built and no module
function is called.** A separate `O(M)` brute-force count is carried as a third opinion
purely to guard the closed form's own rounding edges; it agrees with the closed form on
**8 of 8** rungs, difference `0` on every one.

**The rungs are this leg's own and differ in KIND from leg 220's.** Leg 220's five all held
`X_hi` fixed and walked `X_lo`. These add a right-truncated rung, a two-sided offset rung, a
rung whose data interval **does not contain zero at all**, a tiny window, a near-symmetric
rung, and — the one that carries the argument — a wide asymmetric rung.

## 4. Two honest notes

**(i) A defect in THIS leg's first harness, recorded rather than quietly corrected.** The
first draft asserted that a grid symmetric about zero must report `0` samples outside. It
does not: at `X_max = 745.2` with `M = 16384` the true count is **14**, because the staggered
theta grid reaches past `|X| = 745.2` — which is exactly the number leg 84 banked. The
module was right and the harness's predicate was wrong. The corrected control property for a
symmetric rung is that the two **windows coincide** (hence the counts are equal), not that
the count vanishes. Had this not been caught, this leg would have reported a spurious NO
against a correct repair.

**(ii) A real module behaviour, measured, not gated.** On `excludes_zero` the data interval
`[0.25, 745.2]` lies strictly to one side of zero, so `far_field='power'`'s per-side
normalisation `scale = where(above, X_hi, -X_lo)` is **negative** on the left and the
continuation goes non-finite. The module **raises** (`"h has non-finite entries"`) rather
than returning a number. Leg 220's own code comment claims that outcome is "VISIBLE"; this
leg confirms it is — a raise, not a silent value. The `clamp` ablation is used on that rung
only so the guard fields can still be read, and its `p = 0.9650` is a clamped-closure number,
labelled as such.
