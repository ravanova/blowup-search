## 0. The question, and why it is not leg 382's

Leg 382 built a certified decay enclosure (`solver/dssp_decay_enclosure.py`) and probed
its resolving power with a planted-curvature ladder
`f(r) = C·r^(−p)·(1 + κ·(log r − t_mid)²)`, `κ ∈ {0, 1e-6, … , 1e-1}`. Every non-zero rung
was certified EMPTY, so its banked answer is

A ceiling with no floor is not a magnitude. A consumer reading `≤ 1e-6` cannot tell
whether the instrument is blind to `1e-7` or to `1e-40`, and those are different
instruments. **This leg supplies the floor.**

## 1. THE GATE, in its own pre-committed wording

> **Is a two-sided bracket [fail, detect] measured with at least one decade's separation

> every rung?**

**Definitions fixed now, so no verdict can be reinterpreted later.**

* **DETECT** at κ ⇔ the instrument returns `EMPTY` (a *proof* that no exponent in the
  search bracket fits the profile on the window).
* **FAIL** at κ ⇔ the instrument returns `INTERVAL` (a nonempty enclosure). This is
  **not unsoundness.** For every κ > 0 the true certified set `P_cert` is genuinely empty,
  so `INTERVAL` is the sound-but-uninformative answer: emptiness is a proof, non-emptiness
  never was one. The blind spot is a loss of *resolving power*, not of rigour, and this
  leg will not describe it as an error.
* **INCAPACITY** is a **third class** and is counted as neither. A rung returning
  INCAPACITY is reported as INCAPACITY and disqualifies that rung from being a bracket
  endpoint.
* **BRACKET** `[κ_fail, κ_detect]` := (the largest ladder rung returning INTERVAL, the
  smallest ladder rung returning EMPTY), **and the two must be adjacent rungs of a ladder
  whose step the code has asserted.**

**The gate is decided on the decade ladder, not on the bisection** (§5) — because the
gate's own wording is in decades. The bisection is reported for the scaling laws and
decides nothing.

## 2. THE MODEL — one closed form, pre-committed, falsifiable

Write `t = log r`, `g = log f`, `W = log(R₁/R₀)`, `u = t − t_mid`. A power law is an
affine `c − p·t` in these coordinates, so the instrument's whole job is: *does an affine
function fit inside the tube around `g`?* Planted curvature contributes a quadratic
`κ·u²`, and the best uniform affine approximation to `u²` on an interval of length `W` is
the constant `W²/8`, with max error `W²/8`. A line therefore fits iff

> **κ·W²/8 ≤ h**,  where `h` is the tube's log half-height.

So the detection threshold, **for every arm of this leg at once**, is predicted to be

> ### κ\* = 8·h_eff / W²,  h_eff = max( log(1+δ), h_round )

with `δ` the caller's relative tolerance and `h_round` the arithmetic's own rounding floor
in log space. **Three consequences, each independently falsifiable:**

* **P1 (precision).** At `δ = 0`, `h_eff = h_round ≈ u_arith·|g|_max` where `u_arith` is
  the rounding unit and `|g|_max = p₀·log R₁`. On window `[10,1000]` with `p₀ = 2`:
  `|g|_max = 13.8`, `W² = 21.21`. float64 (`u = 2⁻⁵³ = 1.11e-16`) gives
  **`κ*_float64 ≈ 5.8e-16`**, so the pre-committed float64 bracket is
  **`[κ_fail, κ_detect] = [1e-16, 1e-15]`**.
* **P2 (the precision lever).** `Decimal` at working precision `P` decimal digits has
  `u_arith ≈ 10^(1−P)` for these operands, giving **`κ*(P) ≈ 5.2·10^(1−P)`**: the
  threshold falls **one decade per added digit**, i.e. the log-log slope of `κ*` against
  `P` is **−1.00 ± 0.05**. Pre-committed values: `κ*(20) ≈ 5e-19`, `κ*(30) ≈ 5e-29`,
  `κ*(50) ≈ 5e-49`.
* **P3 (the window).** At fixed precision `κ* ∝ |g|_max/W² = 2·log R₁ / (log R₁/R₀)²`.
  Pre-committed ratios against `[10,1000]`: `[10,100]` **×2.67**, `[10,1e6]` **×0.32** —
  **a total span under one decade**, which is exactly why the window arm is measured by
  bisection and not by the decade ladder.
* **P4 (tolerance).** For `δ ≫ h_round`, `κ*(δ) = 8·log(1+δ)/W²`, which on `[10,1000]` is
  **`κ* ≈ 0.3775·δ`**. This is the number a real consumer needs, because leg 382 §12b
  already established that `δ = 0` is unusable on numerical data.

**Every constant above names its window.** `0.3775 = 8/W²` on `[10,1000]`; on `[10,100]`
it is `8/5.30 = 1.509`. Per leg 386, no bare constant is quoted anywhere in this leg.

## 6. MECHANISM — three candidates, and how they are told apart BEFORE the run

This leg's single most likely way to be wrong is to report a precision floor that is
really a grid artefact. Leg 385 measured exactly that failure mode on this instrument's
family: refusal of a node-aligned violation fired at `N = 1100/1500` and **not** at
`N = 500/997/1001/1010/2000` — **a violating profile can hide from a fixed grid.** So the
three mechanisms get three *different* pre-committed signatures:

| mechanism | signature | probe |
|---|---|---|
| **PRECISION FLOOR** | `κ*` moves ~one decade per added `Decimal` digit (P2) and is **independent of `N`** | arm C, `P ∈ {20,30,50}` |
| **CONDITIONING** | `κ*` moves with `N` **smoothly/monotonically** (more cells → more constraints → more accumulated rounding) | `N ∈ {50,100,200,500,1000,2000}` |
| **COMMENSURABILITY** | `κ*` moves with `N` **non-monotonically**, differing between neighbours like `997/1000/1001/1010`, and **changes under a jittered grid** | `N ∈ {97,100,101,110,997,1000,1001,1010,1100,1500}` **plus a seeded jittered non-geometric grid** |

The jittered grid (uniform random `t`-edges, endpoints pinned, seed `388`, 5 independent
seeds) is the decisive one: it has **no commensurability to have**, so if the threshold
survives it unchanged, commensurability is ruled out rather than argued away.

**Pre-committed expectation:** PRECISION FLOOR, with `κ*` independent of `N` to within one
decade ladder rung and unchanged on jittered grids. Recorded so it can be wrong.
