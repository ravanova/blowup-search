## 2. The criterion, and the realization named (lesson 91)

**ENCLOSURE IS CRITICALITY** — *you cannot enclose an object that does not exist.* A
`ν`-dependent self-similar profile exists **only** when the dissipative term is
scaling-critical for the ansatz (`δ_dis = 0`). If `δ_dis > 0` the rescaled system is
non-autonomous, every one of its steady states solves the `ν = 0` system, and there is no
viscous profile object to enclose; DOMINATED is then *maximal*, not provisional. If
`δ_dis < 0` the ansatz fails outright.

Three clauses: **C1** criticality (necessary), **C2** order-compatibility (necessary for
*continuation* from `ν = 0`), **C3** bridge type — **cited to leg 315**, not claimed here.
The criterion is **necessary, not sufficient**, and FT5 tests exactly that.

**THE KNIFE-EDGE** (the sharp corollary): for BCG-type compressible implosion `δ_dis` vanishes
at `r = 2γ/(γ+1)`, which **is** the excluded lower endpoint of leg 240's banked domination
window — deviation `0.0` at both banked γ, residual **identically 0** in exact rational
arithmetic over 45 γ. Domination owns the open window; enclosure could only live at the one
point it excludes, where C2 (first-order Euler profile ODE → second order: singular
perturbation, not continuation) and C3 (quasilinear hyperbolic vs Zgliczyński's dissipative
hypotheses) both block it. **The enclosure-eligible set has measure zero in `r`.**
