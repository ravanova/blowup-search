## 3. Where the run had to be repaired

* The first convergence criterion used the partial sum's log-log slope. A sum of positive terms is
  monotone whatever α is, so the criterion could never cross zero — bisection returned 4.0 (the
  bracket's right end) and the planted violation did not fire. Replaced by **shell increments**
  `S(2R) − S(R) ~ R^{3−α}`, whose exponent changes sign exactly at the threshold. Also switched the
  cubic `|k|_∞ ≤ N` truncation to a sorted spherical `|k|₂ ≤ R` one, which removed a shape bias.
  After the fix: worst |measured − predicted| 0.00462, threshold 2.996995, all five can_fails fired.
* `_cut_field` returned the stream function ψ while the JSON key claimed a velocity. Fixed to return
  the analytic velocity components; keys renamed to match.
* The measured divergence of the cut field (0.0092 against field sup 0.0389) looked like a
  non-solenoidal field. A refinement ladder n = 41/81/161/321 gave error ratios 3.09/3.75/3.92 →
  second-order truncation error. `u` is a curl, so `div u = 0` identically; the whole ladder is banked
  rather than the single number.
* The image-pressure magnitude increments had not reached their asymptote at N = 16; extended to
  N = 32, top rung 0.6776 against the predicted `log 2 = 0.69315`.
