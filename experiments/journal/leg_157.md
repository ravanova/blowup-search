## The finding, as magnitudes

* **Every preconditioning construction in either paper induces `A21 = 0`** — the class leg
  58's theorem already proves `Z_1 >= 1` on. Five of the six inventoried rows; the sixth
  (Cadiot §5.3) is off-diagonal in the **component** index, not the Fourier index.
* **"Identity on the tail" ⇒ `A21 = 0`, measured not asserted.** Both papers build
  `P = P_N + (I − Π^N)` (Cadiot §3; BPRT eq. (2.12)). Induced `max|A21| = 0.0` exactly;
  the control, which perturbs only `P`'s tail-by-finite block through the same code path,
  reports **24.01**.
* **The algebraic hinge, located.** Cadiot's Lemma 3.3 proof: *"since `L` is diagonal, we
  have that `L π_N = π_N L π_N`"* — the unbounded part drops out of **both** coupling
  blocks. Our unbounded part is bidiagonal with zero diagonal, so it survives there. This
  is **leg 53's `K/2` coupling, reached from the literature's side.**
* **The one theorem that drops the nonzero diagonal fails on a different hypothesis.**
  BPRT Theorem 2.6 asks only for a Schauder basis, property (2.2), and a **compact
  resolvent**. Eigenvalues in a fixed disc, `M = 128…1024`: ours `20 → 32` at `r = 10`
  (**+4.00 per doubling**) and `112 → 248` at `r = 100` (**+45.2 per doubling**), while
  `min|λ|` **decreases** `0.5392 → 0.3146`. The spectrum **accumulates** rather than
  escaping. The positive control (a diagonal operator with growing symbol — Cadiot's
  Assumption 1 class, BPRT's Weyl-law class) holds **exactly `floor(r)`** at every radius
  and every truncation. **Two hypotheses, two independent failures: this is not the
  `l_min` obstruction wearing a new hat.**
* **A diagonal change of basis cannot move a diagonal.** `max|diag(Q⁻¹TQ) − diag(T)| = 0.0`
  exactly for all five weight families, including BPRT's own Definition 2.8 and a
  super-polynomial one this repository has never used; the non-diagonal control on the same
  matrix through the same path moves it by **1.787e3**. This is the mechanism-level reason
  leg 52's weight search could never have repaired a zero diagonal.

## Two defects found in this leg's own first draft, fixed and recorded

* **A NaN wearing the costume of agreement.** `diagonal_conjugation_moves_diagonal` first
  took weights directly; the super-polynomial family overflowed to `inf`, giving `inf/inf =
  nan`, which `max()` silently skipped and reported as a clean `0.0`. Now computed in log
  space, with finiteness reported as its own field. The family's diagonal move really is
  `0.0`; its **off-diagonal** overflows float64, which is itself worth knowing — a
  factorial-type weight is the only kind that could shrink this operator's Gershgorin radii
  and it is not representable in this arithmetic.
* **A log-log exponent flattering a logarithm.** The first ladder fitted `count ~ M^a` and
  reported `0.30` off `[2,2,2,4]` at one radius. The growth is logarithmic in the
  truncation, so the honest statistic is the slope against `log2(M)` at several radii —
  "new eigenvalues admitted per doubling" — which is what the JSON now carries
  (discipline 72).

1. **Cadiot §5.3 / Theorem 5.5 eq. (46) is a published worked instance of exactly the

2. **A sharper localization than "no published construction covers us":** *no published

   cannot move a diagonal), one because it is finite-rank by construction. That is precisely
   where an `A21 != 0` construction would have to be original, and it says the originality
   cannot be borrowed.
