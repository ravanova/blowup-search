## Dispatch, restated

Leg 357's `ledger_nrs_tsai()` tested only `||V||_L3(R^3)` convergence, giving a binary
EXCLUDED/NOT-EXCLUDED verdict. Leg 359 adjudicated the underlying theorems (Tsai 1998)
precisely at primary text and found this binary reading UNDER-FIRES in one direction: Tsai
1998 is TWO theorems proved by the SAME mechanism with TWO different finishing moves —
Theorem 1 finishes on `U ∈ L^q(R^3)` (what leg 357's screen implements), Theorem 2 finishes
on the strictly weaker `U → 0 at infinity`, no integrability required at all. A genuinely
exact-self-similar candidate at this repo's own measured decay rate (~-1, log-divergent in
`L³`) would read "excluded by neither theorem" under the old binary screen, when Tsai's
Theorem 2 in fact excludes it (its own headline motivating example, eq (1.5), is essentially
this exact decay rate). Separately, this repo's ACTUAL DSS object survives NEITHER theorem
for a THIRD reason: both theorems require the exact (continuous) self-similar ansatz
`(1.2)_1`, and a discretely-self-similar-at-λ>1 object fails this ansatz regardless of decay.

My task: extend the ledger to a three-way EXCLUDED-BY-T1 / EXCLUDED-BY-T2 /
NOT-REACHED-BY-ANSATZ reading, gated on three controls (planted gap-then-closure, real-object
ansatz classification, and a byte-level regression check), landing ONLY if all three pass.

## Design decisions and why

**Backward compatibility via optional arguments, not a new function name.** `ledger_nrs_tsai(
l3_result, decay_result=None, ansatz_result=None)`: omitting the two new arguments (every
existing call site — `test_dssp_screen.py`'s original tests, `experiments/
p2_route_dsspb7_v1.py`, `machine_read_ledger()`'s own default call) reproduces leg 357's
ORIGINAL two-key `{excludes, verdict, reason}` dict byte-for-byte. Supplying both routes to a
new `_ledger_nrs_tsai_three_way()` helper. This is what makes the regression control a
guarantee rather than a hope: the fallback branch's code is untouched, not merely
"functionally equivalent."

**Ansatz gate checked FIRST, dispositive on its own.** Per leg 359's finding that BOTH
theorems require the exact-SS ansatz, a candidate failing it is not reached by either theorem
regardless of decay or `L^q` status — this matches the task's own framing of
NOT-REACHED-BY-ANSATZ ("regardless of decay, neither theorem's hypothesis is met"). Only a
candidate passing the ansatz gate is then checked against Theorem 1's stricter `L^q` route,
falling through to Theorem 2's weaker decay-only route if `L^q` fails. This is mathematically
more careful than the task's literal bullet list (which describes EXCLUDED-BY-T1 without
mentioning the ansatz), because Theorem 1's own hypothesis is ALSO stated `"u is of the form
(1.2)_1"` — an L^q-convergent-but-DSS candidate should NOT be excluded by "Theorem 1" in
substance, since the theorem's own hypothesis is not met. In practice this asymmetry never
fires in either of my gate controls (the DSS control's L³ diverges anyway, so Theorem 1's
route wouldn't have fired regardless of ansatz), but it is the mathematically correct reading
per leg 359's own confirmed text, and I chose correctness over a literal minimal reading of
the dispatch's summary bullets.

**`classify_ss_ansatz()` driven off `lambda_from_trajectory()`'s own measurement**, the same
input `ledger_pineau_vicol()` already consumes — no new measurement machinery invented. A
MEASURED non-trivial period at λ>1 is read as the operational DSS-not-SS signature (a fixed
point of the rescaled flow has, by definition, no period to find). No trajectory ever
supplied (a static candidate field) is read as satisfying the exact-SS ansatz: Tsai's ansatz
`(1.2)_1` literally IS "a single stationary profile U(y)", which is exactly what a static
field represents. This is a genuine modelling choice, documented in the function's docstring:
this module does not invent a third "maybe secretly DSS but never measured" state.

**`decays_to_zero_at_infinity()` reuses `fitted_far_field_decay_exponent()`'s own
measurement** rather than resampling: a strictly negative fitted exponent, CONFIRMED by the
sampled magnitude actually decreasing from the first to the last sampled radius (guards
against a negative least-squares slope on non-monotonic/noisy data), is read as `U → 0` at
infinity — the exact, and only, hypothesis Theorem 2's finish needs.

## The three gate controls, run via `experiments/p2_route_b7x_v1.py`

**Control 1 — planted, positive direction (gap demonstration then closure).** Synthetic field
`U(y) = (y/|y|)/|y|`, decay exponent exactly -1 (Tsai's own headline example (1.5), with
`A(θ) = θ`). No trajectory supplied → classified EXACT-SS. Its `||V||_L3` is log-divergent
(same mechanism as the real object: `|V|³ ~ 1/r³`, volume integral `~ ∫ dr/r`). **Before the
fix** (`ledger_nrs_tsai(l3_result)` alone): `verdict = "NOT EXCLUDED"` — the gap, reproduced
live. **After the fix** (`ledger_nrs_tsai(l3, decay_test, ansatz)`): `verdict =
"EXCLUDED-BY-T2"`. **PASS.**

**Control 2 — real object.** `field_uB` (leg 351's Type-I Biot-Savart witness) combined with
a genuinely periodic λ>1 trajectory — the SAME synthetic-periodic-control construction leg
357's own landed test suite already uses as its positive detector
(`test_lambda_detected_on_synthetic_periodic_trajectory`, `S0_true=2.0`), here used to TAG the
object as discretely self-similar (measured `λ = 2.634 > 1`). Result: `verdict =
"NOT-REACHED-BY-ANSATZ"`, `deciding_clause` quotes Tsai 1998 eq (1.2). **PASS.**

I deliberately did NOT reuse leg 354's own landed B4 trajectory (which relaxes monotonically
to the trivial state `Ω=0` for the physical Galerkin coefficients α,β) as "the real DSS
object", because that trajectory's own landed finding is that it is NOT periodic — using it
would have produced `lambda=None` (measured=False) and classified as EXACT-SS, the wrong
demonstration for this control. The dispatch's own wording ("leg 351's Type-I Biot-Savart
witness, or whatever object leg 357's screen was tested against") gave latitude here; I chose
the concrete DSS-tagged construction already present in leg 357's own test file, rather than
inventing a new one, so the "real object" is traceable to landed code, not manufactured for
this leg alone.

**Control 3 — regression.** Re-measured leg 357's own final-checkpoint ledger in-process
(same `galerkin_coefficients(80,60,64,10.0)` / `integrate_rk4(0.01, alpha, beta, 5.0, 2000)`
call as `experiments/p2_route_dsspb7_v1.py`), then diffed every `verdict`/`excludes` field
against the ORIGINAL banked `writeup/data/p2_route_dsspb7_v1.json` (loaded read-only, never
edited). **Zero mismatches.** Separately, I also re-ran `experiments/p2_route_dsspb7_v1.py`
itself end-to-end and diffed the regenerated JSON against a saved copy of the original
byte-for-byte: only `consumed_from` (an absolute worktree path, `.leg357-work` vs
`.leg362-work` — expected, environment-dependent) and `runtime_seconds` (expected, timing
noise) differ; every verdict field is identical. The regenerated file was then discarded
(`git checkout -- writeup/data/p2_route_dsspb7_v1.json`) so the banked file is untouched in
this leg's diff. **PASS.**

All three controls pass → **gate verdict: YES.** The extension is banked.
