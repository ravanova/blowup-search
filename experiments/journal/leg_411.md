> **(a)** that a **scalar recurrence score used as an admission filter biases the recovered orbit

> **(b)** that **re-mining a fixed trajectory silently re-finds what the first run already found**?
> Search the Chandler–Kerswell / Lucas–Kerswell / Cvitanović line and the wider recurrence-mining

### 0.1 THE CEILINGS, FIXED BEFORE THE ANSWER EXISTS

**These are written now, not after, precisely because leg 348 carried an abstract-depth reading for
45 legs through an escalation and a user ruling and the claim FELL when finally read at full text.**

1. **TIER 2.** No `L1 → L4` link moves. A literature search moves none, in either branch.
   **Clay stays ~0.05%.** `CLAY_OBLIGATIONS.md` §6's two no-method obligations stay OPEN.
2. **THE arXiv API SEARCHES METADATA, NOT FULL TEXT.** `search_query=all:` covers title, abstract,
   authors and comments. **Both of `P1`'s effects are the kind of statement that lives in a
   METHOD SECTION, not in an abstract.** Therefore the API arm of this leg is a
   **CANDIDATE-ENUMERATION instrument and NOT an adjudication instrument**, and **an ANDed zero
   from it is NEAR-WORTHLESS as evidence of absence**. This is declared here, before the run, and
   it is the single most important limit on this leg. Adjudication is by **instrument 2**, a
   full-text grep over fetched PDFs, which has its own controls (§0.4).
3. **PRE-arXiv AND JOURNAL-ONLY SOURCES ARE UNREACHABLE BY BOTH INSTRUMENTS, DECLARED IN ADVANCE.**
   Named now so the list is not assembled after the fact: Kawahara & Kida, *JFM* **449** (2001);
   Kawahara, Uhlmann & van Veen, *Annu. Rev. Fluid Mech.* **44** (2012) — a review, and reviews are
   exactly where methodological folklore gets written down; Nagata, *JFM* **217** (1990); Cvitanović
   *et al.*, **ChaosBook** (a web book, not arXiv); any Springer/Elsevier/CUP book chapter; and
   every conference proceeding. **If either effect is stated only in one of those, this leg cannot
   see it and says so rather than returning a zero.**
4. **PAGINATION.** arXiv preprints are not paginated as the journal is. Where the fetched PDF is a
   preprint, the gate's "at which page" is answered as **preprint page + section**, and the journal
   page is given **only** where the fetched PDF carries journal pagination. Stated in advance so
   that a preprint page number is never quietly presented as a journal page number.
5. **NO OUTREACH OF ANY KIND**, standing user hold. Reading published material is authorised;
   contacting an author, group, maintainer or list is not and is not done. **No paywall
   circumvention.** `Papers/fetch.sh` is arXiv-only and nothing else is used.
6. **A pre-run probe from this container returned HTTP 429 from Semantic Scholar on the very first
   call.** Throttling on that arm is therefore **EXPECTED**, is banked as `THROTTLED`, and is
   **never rendered as a zero** — anywhere, in any count, table or summary line. That is leg 387's
   exact failure and it is the failure this leg is built not to repeat.
7. **`Papers/` is gitignored by policy.** No PDF is committed. Pointers and hashes go to
   `Papers/MANIFEST.md`.

### 0.2 Instrument rules — the leg-392 standard, adopted whole and not weakened

1. **Controls fire BEFORE any substantive verdict is recorded.** A generic positive control; a
   **TOPICAL** positive control in this literature; a nonsense negative that must return
   **exactly 0**; and **AND-operator control pairs** of phrases known to intersect, so that an
   ANDed zero is a measurement rather than an artefact.
2. **`MEASURED` vs `DID-NOT-MEASURE` is a per-query field.** `MEASURED` requires HTTP 200 **and** a
   parsed `totalResults`. A 429 surviving backoff, a timeout, a non-200 or a parse failure is
   `THROTTLED` / `FAILED`, and `total` is `None` **by construction** so that no downstream reader —
   including one who never reads this journal — can render a non-measurement as a zero.
3. The **opensearch namespace actually served** is banked verbatim from the raw feed and the parser
   names no namespace version anywhere. **Checked against the response, never assumed from the
   request.**
4. ≥ 12 s spacing between arXiv calls; exponential backoff on 429; reduced coverage is reported as
   reduced coverage, and a null from an under-covered search is **`UNDER-RESOURCED`, not `NO`**.
5. **A control that does not fire as planted is DISCLOSED in the artefact and the verdicts it
   governs are VOID. It is never quietly re-planted.**
6. Ids are banked, never counts alone.

### 0.4 Instrument 2 — the full-text corpus, and its own controls

Candidates are fetched from arXiv as PDFs, extracted with `pdftotext -layout`, and grepped. Its
controls, planted before it runs:

* **positive**: a term certain to be in the corpus (`hookstep`) must hit in ≥ 2 documents;
* **topical positive**: `recurrent flow` must hit in ≥ 2 documents;
* **nonsense negative**: an invented string must return **exactly 0** across the whole corpus;
* **AND-pair**: `Newton` and `Kolmogorov` must co-occur inside at least one document, so that a
  co-occurrence zero is a measurement.

The corpus and its sha256 hashes are banked. **Depth per §3k**: anything quoted from a fetched and
extracted PDF is `FULL TEXT`; anything from an API abstract is `ABSTRACT`; anything taken from
another paper's description of a third is `SECOND HAND`; anything not obtainable is `UNREACHABLE`.
**An `ABSTRACT`-depth hit CANNOT answer "stated how strongly" and will not be allowed to.**

### 0.5 The adjudication rule, fixed before any result was seen

**Effect (a) is answered YES** only if a located text, read at `FULL TEXT`, states that the
**recovered/converged SET of invariant solutions is systematically skewed** as a consequence of
using the recurrence measure (or a threshold on it) to decide **which candidates are attempted**.
A statement about the **per-guess convergence probability** as a function of the residual is
**NOT** effect (a) — it is about the success rate, not about the composition of the output set —
and it is graded `S0 ADJACENT`, not YES.

**Effect (b) is answered YES** only if a located text, read at `FULL TEXT`, states that continuing
or repeating the search **over the same or a fixed trajectory predominantly returns solutions
already found** — duplication, diminishing returns, or saturation of the distinct-solution count.

**Strength grades**, applied to whichever effect is hit:

| grade | meaning |
|---|---|
| `S3 EXPLICIT-QUANTIFIED` | stated **and** measured — a number, a table or a figure supports it |
| `S2 EXPLICIT-QUALITATIVE` | stated as a claim in the running text, unsupported by a measurement |
| `S1 IN PASSING` | a caveat sentence, no support, not returned to |
| `S0 ADJACENT` | related but does not meet the effect's own wording above — **NOT a YES** |

**The word "silently" in effect (b) is adjudicated separately and is not allowed to rescue a `NO`.**
If a paper reports the duplication openly, the **effect** is in print even though it was not silent
for that paper; the leg reports the effect as `YES` and records the "silently" qualifier as a
separate, weaker sub-claim.
