## 5. Clause (c) — the sweep, its robustness stated, its blind spots stated

The instrument implements the standing hardened scoping rule that this bundle's own sources
produced (leg 272's real product; PUB2's six-pass correction history via `verify_276` §10).
**Robustness, explicitly:**

* **case-insensitive** — `re.IGNORECASE` on all 13 patterns;
* **wrap-immune** — each file read as **one stream**, with all whitespace *and* wrapped-blockquote
  markers (`#`, `>`, `|`, `*`, backtick) collapsed to single spaces **before** matching, so a
  phrase split at the 100-column hard wrap still matches; line numbers recovered by offset map;
* **hyphenation-tolerant** — every intra-phrase space written `[-\s_]+` (`six name` / `six-name` /
  `six_name` all match), module names matched across `[-_.]` boundaries.

**1,236 files** (`*.md`, `*.py`, `*.json`, `*.txt`, `*.sh`; `.git`, `.venv`, `Papers`,
`__pycache__` excluded). **Result: no third consequence site exists.** Outside the four fixed
sites, every hit is the finding's own artifacts, leg 218's own record (original wording standing
by convention; leg 279 already appended its pointers), an integration- or DM-owned ledger
(`experiments/JOURNAL.md:2918, :3939`; `DIRECTION.md:12178, :12194, :12199` — flagged, never
edited by a leg), or **leg 272's own verification artifacts** recording `class_P: 18`, which is
its faithful record of what leg 263 *published* and must stay verbatim. The full table is in
`CORRECTIONS.md` §9.

**The blind spots, since a sweep's blind spots are part of its result.** Five text extensions
only — no PDFs under `Papers/`, no binary or notebook formats. `*`, backtick and `|` are treated
as separators, so a phrase with an *internal* asterisk inside a word would be split. It is a
phrase-family sweep: a paraphrase carrying none of the 13 patterns' anchors would not surface.
Two patterns (`class-P-18`, `all-18`) are deliberately over-broad and returned **43 hits, 0 of
them about this phrase family** — reported rather than tuned away, because a pattern narrowed
until it looks clean is the exact failure this register was opened over.

**A sixth instrument failure in the same family, logged.** The first draft of the `six-name`
pattern was `six[-\s_]+(?:[-\s_]+\w+){0,3}…` — the leading and inner separator classes overlap,
which backtracks catastrophically; the run had to be killed after 120 s. Rewritten as
`six[-\s_]+(?:\w+[-\s_]+){0,3}…`. Recorded because a slightly faster version of the same bug
returns a *clean-looking empty result*, which is how the previous five failures presented.
