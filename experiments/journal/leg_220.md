## The repair, in three lines

```
inside = np.abs(Xt) <= X_max            ->   inside = (Xt >= X_lo) & (Xt <= X_hi)
edge   = np.where(Xt > 0, f_hi, f_lo)   ->   above = Xt > X_hi;  edge = where(above, ...)
ratio  = np.abs(Xt) / X_max             ->   scale = np.where(above, X_hi, -X_lo)
```

**Leg 204 named the first and neither of the other two** (`writeup/novelty/leg_220.md` R2).
Changing only the membership test would have left the far-field branch still reading the
symmetric assumption: on an asymmetric grid a sample at `Xt = −0.5` with `X_lo = −0.1` is
above the data interval on the left but *negative*, so the old `Xt > 0` form continues it
from the wrong endpoint, and a single scalar `X_max` is the wrong normalisation for both
sides at once. All three reduce identically when `X_lo = −X_hi`, which is the bit-identity
argument and is measured in Part A.

`spectrum` now also reports `X_lo_data` / `X_hi_data`. `X_max_data` keeps its name and value
but is **no longer the guard's threshold** and must not be read as one.

## The lesson-90 control

A differential reporting "0 moved" is worthless if the two sides are secretly the same module
object — leg 129 hit exactly that, and its *control* silently reported 0/33 too. So before
any bit-identity claim is admissible, the runner asserts executably that the two modules are
distinct objects, that the pre-repair source contains the old predicate and lacks the new
one, that the repaired source does the reverse, and — behaviourally — that on an asymmetric
probe grid the two **disagree**. It passes, and with a magnitude: on the probe grid
`X ∈ [−1, 745]` at `M = 4096`, the pre-repair module reports **4** samples outside and the
repaired one reports **1026**. If any clause fails the runner raises and refuses to report
Part A at all.

documented the fourth rather than widen). The other six are re-measured against the

| mechanism | status | magnitude, post-repair |
|---|---|---|

| mismatched sinh scale `c` | **STILL OPEN** | `c = 1e−8` → `p = 0.8545`; `c = 1e+8` → `p = 0.0129`, against the exact `1.4` |
| fitter absorbs NaN coefficients, overstates `n_points` | **STILL OPEN** | 150 of 225 in-band modes NaN: `n_points` reported 225 against 75 finite, a **3.0×** overstatement, 0 warnings, `domain_valid = True` |

On that last row, one honesty note: leg 204's draw returned a *finite* `p = 1.404831` — the
dangerous case, where nothing looks wrong. This leg's draw (seed 204, 150 of the 225 in-band
modes) returns `p = nan`, which is **visible**. The `n_points` overstatement reproduces leg
204's `3.0×` exactly and is the part that is genuinely silent; the exponent's visibility here
is a property of which modes the draw happened to poison, not of any repair, and it is **not**
claimed as one.

The shuffled-`X`/`f` case is worth one sentence: it is **not** a windowing defect, and the
repaired guard correctly does **not** catch it. A guard that started flagging it would be
over-rejecting, which is exactly what leg 94's precision suite exists to prevent.
