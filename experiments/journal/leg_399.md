## §1 — METHOD (pre-registered, before any row was read)

1. Enumerate rows: the four named by the dispatch, plus anything my own control net surfaces.
2. For each row, obtain the **primary source** (arXiv abstract/listing at minimum; full text
   where reachable). Never grade from a prose summary in this repository.
3. Per row, answer two independent booleans:
   - `dissipative_term_inside_certified_equation` — is the object the interval certificate
     encloses a solution of an equation carrying the dissipative term?
   - `genuine_fluid_equation` — transport nonlinearity / incompressibility / fluid-adjacent
     structure, not an off-axis scalar or complex-field model?
   Verdict = `GRADE_A_FLUID` iff both true; else `NOT_GRADE_A` / `NOT_FLUID` / `NEITHER`.
   Unreachable primary source ⇒ `UNREACHABLE`. Rate-limited API ⇒ `THROTTLED` with the query.
4. Per row, quote the **failing clause verbatim from the paper's own text**, with its location
   (lesson 91: a negative names what it ran against).
5. Rows already adjudicated in this record are **CITED, not redone** (see pre-committed
   readings (c)). I record which rows had *never* been graded before this leg.
