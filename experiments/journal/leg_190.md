## The gate, and its answer in its pre-committed wording

> **Gate.** Can "EGM" be located as a real, checkable primary source, and does it state the
> `p=2`, `−1/2`-gap claim as relayed, with its own hypotheses?

**YES — with one correction, running the opposite way from the one the leg expected.**

EGM is **Elgindi–Ghoul–Masmoudi, *Stable self-similar blowup for a family of nonlocal
transport equations*, arXiv:1906.05811 [math.AP] (13 Jun 2019), published as *Analysis &
PDE* 14 (2021), no. 3, 891–908, doi:10.2140/apde.2021.14.891.** Read at full text from the
PDF **and** from the arXiv LaTeX e-print. The acronym has exactly one referent in this
subfield (two search routes, §3 of the novelty pass).

**Proposition 2.1** (§2 "Coercivity", p. 6) states the gap, with **three hypotheses inside
the statement**: (i) `a` small enough; (ii) `f` odd with `f′(0) = Hf(0) = 0`; (iii)
`∫_R |f|²φ < ∞`, in the weighted space `L²_φ` with `φ = (1+y²)²/y⁴`. Hypothesis (ii) is not
free — EGM buy it with the modulation parameters `μ, λ` in §3, in their own words. At `a = 0`
(their `a = 0` **is** CLM, their sentence) the constant is exactly **`−1/2`**.

The **"`p = 2`, width 2.0"** half of the relayed sentence is **leg 165's, not EGM's**
(`experiments/journal/leg_165.md:106-108`; leg 111's window `(3, 2p+1)`, which is `(3,3)`
width `0.0` at `p=1` and `(3,5)` width `2.0` at `p=2`). EGM say nothing about `p`. The join —
EGM's `γ = 4` lying inside `(3,5)` — is arithmetic about the two, not a claim EGM make. The
ledger row keeps the two owners separate so the composite cannot be re-quoted as EGM's.

Per the gate's yes-branch: the full citation, the verbatim claim and the verbatim hypotheses
are recorded, and `EGM_PRIMARY_READ` is appended to `solver/literature_gates.py`. **One new
top-level block. No existing row touched, no existing structure resized.**

## Plain language: what actually changed

Two things, one clerical and one not.

**The clerical one.** "EGM" had been relayed into this project's steering documents twice and
appeared in **no shared ledger at all**. That looked like a missing citation; it was not. Leg
141 had read the paper at full text back when it was needed, and legs 159, 165 and 181,
`capabilities.py` and four Route-W\*/XUL runners have been using it since — all of them
citing it out of leg 141's own artifacts. The gap was in the **shared** ledger, which is the
only place a later leg would think to look. That is now closed, append-only.

**The one that is not clerical.** Before appending, the resumed session re-fetched the paper
rather than trusting the first session's summary — the standing "re-measure your own headline
before building on it" discipline. It pulled the LaTeX e-print as well as the PDF, and the
proposition block reads

```latex
\int_\RR f\MM f \phi(y)dy&\leq-\Big(\frac{1}{2}-C\,|a|\Big)\int_\RR f(y)^2 \phi(y)dy.
```

The bracket is **`−(1/2 − C|a|)`**: the gap **degrades** as `|a|` grows. This repository has
been carrying **`(−1/2 − C|a|)`** — gap *improving* with `|a|` — since leg 141, through leg
165, and the first session of this very leg not only repeated it but wrote a section
"catching" the ar5iv HTML mirror for having it right. Five sites carry the wrong bracket
(`experiments/journal/leg_141.md:30,117`, `writeup/novelty/leg_141.md:233`,
`experiments/journal/leg_165.md:120,128`), plus this leg's own §2.

The mechanism of the error is worth one sentence, because it will recur: **`pdftotext` drops
`\Big(` … `\Big)` silently**, so an extracted layout cannot distinguish `−(1/2 − C|a|)` from
`(−1/2 − C|a|)`. A PDF text extract is *not* a primary source for a sign inside a bracket.
Two things inside the paper would have caught it anyway: the proof adds the `a`-part through
an absolute value (`|∫ f M̃_a f φ| ≤ C ∫|f|²φ`), which can only make the constant *worse*
than `−1/2`; and EGM's own §6 `C^α` analogue reads `(1/2 − Cα)`, degrading identically. §2
quoted that §6 line without noticing it contradicted the reading two paragraphs above.

**No banked number moves.** Both readings are exactly `−0.500000` at `a = 0`, and `a = 0` is
the only value legs 141 and 165 ever compared at. What was wrong is the **sign of the slope in
`|a|`** — zero error on axis, wrong direction everywhere off it. Quantified in `E4` at
`C = 1`: `0.0000` at `a = 0`, `0.0200` at `a = 0.01`, `0.2000` at `a = 0.1`, `0.4000` at
`a = 0.2`, i.e. `2C|a|`.

## What was measured, not quoted

The gate could have been answered with a paragraph saying "we read it". Leg 141 already did
that. This leg's runner answers it with numbers off EGM's own printed formulas.

| | check | result |
|---|---|---|
| **E1** | EGM's closing coefficient `D(y) = −2HF₀ − 1 + ½∂_y(yφ)/φ` against their printed `−1/2`, analytically and by finite differences of `φ`, on 4000 nodes over six decades | `4.441e-16` (spread `8.882e-16`); finite-difference route `5.000e-06` |
| | **negative controls** — two decoy profiles through the identical code path | miss by `0.5000` and `0.3431` |
| **E2** | is `γ = 4` a choice? Scan `φ_γ = (1+y²)^{γ/2}/\|y\|^γ` | `γ = 4` is the **unique** `y`-independent member, `1 of 10` scanned: spread `0.0000` at `γ=4` vs `0.0500` at `γ=3.9` and `γ=4.1`, `2.0000` at `γ=8` |
| | leg 165's `D_φ(0) = (3−γ)/2` | **recovered from EGM's algebra**, not quoted; far-field value is `−1/2` for every `γ` |
| **E3** | `HF₀ = −1/(y²+1)` against `solver/line_hilbert.py`, an instrument sharing no algebra with the paper | matches; residual is the omitted `1/y` tail, `err·S = 0.639` against `2/π = 0.6366` over four grid extents (`S = 74 … 29937`) |
| | sign convention | pinned, not assumed: the **negated** target is off by `2.0` at every extent |
| **E4** | the transcription audit | `0` banked numbers moved, `6` sites carrying the wrong bracket |
| **E5** | leg 111's window vs `γ = 4` | `p=1`: `(3,3)`, width `0.0`, `γ=4` **outside**; `p=2`: `(3,5)`, width `2.0`, inside |

**E2 is the one genuinely new observation**, and it is small and carefully bounded: `γ = 4` is
not one admissible exponent among many, it is the only one at which EGM's coercivity constant
is *exact* rather than an infimum over `y`. Off `γ = 4` the `−1/2` survives only as the
far-field value while the origin value slides to `(3−γ)/2`. **This is a statement about the
local/diagonal term only** — EGM's vanishing identity `∫ Hf f F₀ φ = 0` is itself `γ = 4`
algebra — so it does **not** say "any `γ ≥ 4` works", and the runner and the ledger row both
record that caveat explicitly.
