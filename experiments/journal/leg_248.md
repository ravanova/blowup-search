## 1. What was inherited, and what of it survived checking

This leg resumed from `origin/leg/248-cnr2-v1-wip2`, a WIP commit salvaged from an interrupted
session. **It was verified, not assumed.** Three things were found and are recorded:

   and `main()` calls it, but the committed `writeup/data/p2_route_cnr2_v1_repair.json`
   contained no `F` key — i.e. the artifact predated the runner. The whole runner was
   re-executed from scratch on this leg's rebased tree and the JSON regenerated. Every

   reproduced the inherited values exactly, and F — the section the stale artifact lacked

   *Method note.* End to end the runner costs well over an hour (F alone re-runs the 41-case
   battery at eight tolerances), which exceeds the wall clock a single process gets here, and
   two uncapped attempts were killed at 50 and 60 minutes having written nothing. The runner
   therefore now **checkpoints each section, and each of F's eight tolerance rows, to a cache
   outside the repository**, so the artifact is assembled from bounded runs. This changes no
   computation: every section is a deterministic function of the same seeded inputs, so a
   cached section equals the section one long run would have produced. Deleting the cache
   forces a clean end-to-end recomputation.
2. **A wording defect in the mathematics.** Both the module docstring and the runner
   described the gauge defect as *"absolute and homogeneous of degree 1"*. It is **affine**,
   not homogeneous: `F[J] = g0·Ω + 1` and `F[J+1] = Ω[i1] + 1/2` carry nonzero constants.
   Corrected in both places. The correction strengthens rather than weakens the argument —
   what the repair needs is that the quantity is *not degree 0*, and the affine form moves as
   `|λ−1|` times the gauge value under `(Ω,c) → (λΩ, λc)` while `rel`, a ratio of two
   degree-2 quantities, is degree 0 **exactly**.
3. **No novelty pass existed at all.** Written and committed before any further construction,
   per standing discipline. It records that the dispatch's premise — *"the same fix shape leg
   226 applies"* — is only half true; see §5.

## 2. What the repair is

`ACollocation.newton` assembles a `(J+2)`-row system: `J` residual rows plus **two gauge
rows** `F[J] = g0·Ω + 1` (Ω at θ=0 equals −1) and `F[J+1] = Ω[i1] + 1/2` (Ω at the node
nearest X=1 equals −1/2). It then returned `converged = bool(rel < 1e-9)` with
`rel = rms(R)/rms(Ω·H(Ω))` — **and threw the two gauge rows away**. Leg 237's hit, verbatim:
`R` is degree 2 in `(Ω, c)` and so is the denominator, so `rel` is *exactly* invariant under
the degeneracy the two gauge rows exist to break.

The repair ANDs in the discarded rows:

```
gauge_defect = max(|g0·Ω + 1|, |Ω[i1] + 1/2|)
converged    = (rel < 1e-9) and (gauge_defect <= gauge_tol)
```

with `gauge_tol = 1e-8`. **No new quantity is computed.** The pre-repair flag is not
discarded — it comes back unchanged as `converged_relres_only`, alongside `gauge_ok`,
`gauge_defect` and a `reason` string, and `gauge_tol=inf` reproduces the pre-repair verdict
exactly. The `LinAlgError` branch carries the same four keys so `continuation` and every
other caller can read them unconditionally (leg 150's dict-shape discipline, extended).

`continuation` inherits the fix at all three of the branch decisions leg 237 named:

* **retry** if the residual is unconverged **or** the profile is off gauge;
* **accept the retry** lexicographically on `(gauge_ok, −relres)` — on-gauge beats off-gauge
  first, `relres` decides only within a gauge class (the pre-repair rule is the second
  component alone);
* **reseed the remainder of the ladder** only from a member that is both converged **and** on
  gauge.

Every clause can only ever **reject** a warm start the old code would have taken, which is
why a ladder whose members are all on gauge runs bit-identically.

## 4. Is the threshold load-bearing? — the honest answer, both halves

`gauge_tol = 1e-8` is **adopted**, not fitted: it is leg 237's own escape predicate
(`gd > 1e-8`), taken unchanged. Against the cases the gate scores, the headroom is enormous —
**1.1e+07×** above the worst gauge defect among the 17 converged battery cases (8.882e-16),
and **1.0e+08×** below the smallest defect of an escaped member (1.000, at λ=2). Section F
sweeps the tolerance over `1e-14, 1e-12, 1e-10, 1e-8, 1e-6, 1e-4, 1e-2, 0.5` and finds
**both gate clauses holding at all eight** — 41/41 battery-correct with 17 converged, and
4/4 escaped members refused, at every one. The band of indifference is therefore **13.7
decades wide and not closed at either end by this sweep**: the gate's answer does not depend
on the value of `gauge_tol` anywhere in the range tested, which is the claim the repair makes.

**The inconvenient half, recorded because it is inconvenient.** The headroom is *not*
uniformly fifteen decades over all clean inputs. Section C's `J=60, a=0.5` case carries a
gauge defect of **1.584e-08** — that is **1.6×** *above* `gauge_tol`, i.e. the margin there is
a factor of 1.6 in the wrong direction, not seven decades. It changes no verdict only because
that case fails `relres` anyway (**2.125e-05** against 1e-9), so the residual clause rejects
it first and the gauge clause never decides anything. The same shape appears at `J=100,
a=0.5` (**1.471e-08**). The operative margin is the one restricted to the population where
the new conjunct can actually decide — the rows where the *old* test already passed — and
there the worst gauge defect over all 12 clean cases is **3.331e-16**, i.e. **3.0e+07×**
below `gauge_tol`. So the correct statement is: **the threshold is not load-bearing on
any case this gate scores, and the separation on those cases is fifteen decades wide; but the
gauge defect on the far end of the a-range at coarse J is not itself comfortably below 1e-8,
and a future leg that tightens `relres` at a ≈ 0.5 on a coarse grid would find the gauge
clause becoming the deciding one.** Flagged for the light post-repair check rather than
papered over.
