## The red path, and the harness bug it caught

**Demonstrated before any live verdict was reported, and re-demonstrated after the fix.**
9/9 synthetic cases plus a live bad endpoint, and deliberately in *both* directions:

| case | required | observed |
|---|---|---|
| arXiv 200 + empty body | REFUSED | REFUSED |
| S2 200 + empty body | REFUSED | REFUSED |
| arXiv 429 (the literal leg-382 condition) | REFUSED | REFUSED |
| arXiv 200, well-formed XML, no result container | REFUSED | REFUSED |
| S2 200, well-formed JSON, no `{total,data}` | REFUSED | REFUSED |

| S2 genuine zero container | CONTROLLED-ZERO | CONTROLLED-ZERO |
| arXiv genuine hit | HITS | HITS |
| **live** request to a nonexistent arXiv path | REFUSED | REFUSED (real HTTP 503) |

Both directions matter: a harness that only ever says REFUSED proves nothing about its zeros,
so `CONTROLLED-ZERO` and `HITS` were shown reachable too.

**It immediately earned its keep.** Run 1 of the live harness returned **REFUSED for every
arXiv response**, including a **37201-byte** positive control that plainly contained results.
Cause: the parser listed only opensearch namespace `1.0`; **arXiv serves `1.1`**, so
`opensearch:totalResults` was never located. The strict tri-state refused to call an
unparseable 200 a zero, which is exactly what surfaced the bug.

**Had the harness counted `len(entries)` instead — the obvious implementation — it would have
reported "0 results, no prior art" for all four arXiv queries.** That is a fabricated
controlled zero produced by a namespace typo, on the precise question this leg exists to
answer. This is the fifth instance this cycle of a green that could not go red, and the first
one caught *by* the rule rather than after it. Fix: accept both namespaces; red path re-run
after the fix, still 9/9.

## The harness, banked verbatim (territory forbids a runner in `experiments/`)

Run as `python dxnv_harness.py red` then `python dxnv_harness.py live out.json`.

```python
UA = "leg387-route-dxnv/1.0 (Unsolved repo; novelty-completion of leg 382)"
ATOM = "{http://www.w3.org/2005/Atom}"
# arXiv serves opensearch 1.1; 1.0 accepted too so the parser is not hostage to
# a namespace bump. The first live run REFUSED every arXiv response because only
# 1.0 was listed -- the harness bug the strict tri-state caught instead of
# laundering into a zero.
OPENSEARCH_NS = ("http://a9.com/-/spec/opensearch/1.1/",
                 "http://a9.com/-/spec/opensearch/1.0/")

def fetch(url, timeout=45):
    """Return (status, body, transport_error). Never raises."""
    req = urllib.request.Request(url, headers={"User-Agent": UA})
    try:
        with urllib.request.urlopen(req, timeout=timeout) as r:
            return r.status, r.read().decode("utf-8", "replace"), None
    except urllib.error.HTTPError as e:
        body = ""
        try:
            body = e.read().decode("utf-8", "replace")
        except Exception:
            pass
        return e.code, body, None
    except Exception as e:
        return None, "", f"{type(e).__name__}: {e}"

def parse_arxiv(status, body, transport_error):
    if transport_error is not None:
        return "REFUSED", None, [], f"transport error: {transport_error}"
    if status != 200:
        return "REFUSED", None, [], f"HTTP {status} (non-200)"
    if not body.strip():
        return "REFUSED", None, [], "HTTP 200 with EMPTY body -- not a controlled zero"
    try:
        root = ET.fromstring(body)
    except ET.ParseError as e:
        return "REFUSED", None, [], f"HTTP 200, body did not parse as XML: {e}"
    tot = None
    for ns in OPENSEARCH_NS:
        tot = root.find(f"{{{ns}}}totalResults")
        if tot is not None:
            break
    if tot is None or tot.text is None:
        return ("REFUSED", None, [],
                "HTTP 200, parsed, but NO opensearch:totalResults container -- "
                "cannot distinguish zero from malformed")
    total = int(tot.text)
    entries = [{"id": (e.findtext(f"{ATOM}id") or "").strip(),
                "title": " ".join((e.findtext(f"{ATOM}title") or "").split()),
                "published": (e.findtext(f"{ATOM}published") or "").strip(),
                "updated": (e.findtext(f"{ATOM}updated") or "").strip()}
               for e in root.findall(f"{ATOM}entry")]
    if total == 0:
        return "CONTROLLED-ZERO", 0, [], "opensearch:totalResults present and equal to 0"
    return "HITS", total, entries, f"opensearch:totalResults = {total}"

def parse_s2(status, body, transport_error):
    if transport_error is not None:
        return "REFUSED", None, [], f"transport error: {transport_error}"
    if status != 200:
        return "REFUSED", None, [], f"HTTP {status} (non-200)"
    if not body.strip():
        return "REFUSED", None, [], "HTTP 200 with EMPTY body -- not a controlled zero"
    try:
        doc = json.loads(body)
    except json.JSONDecodeError as e:
        return "REFUSED", None, [], f"HTTP 200, body did not parse as JSON: {e}"
    if not isinstance(doc, dict) or "total" not in doc or "data" not in doc:
        return ("REFUSED", None, [],
                "HTTP 200, parsed, but no {total,data} result container -- "
                "cannot distinguish zero from malformed")
    total = doc["total"]
    entries = [{"id": d.get("paperId"), "title": d.get("title"), "year": d.get("year"),
                "externalIds": d.get("externalIds")} for d in (doc["data"] or [])]
    if total == 0:
        return "CONTROLLED-ZERO", 0, [], "JSON 'total' present and equal to 0"
    return "HITS", total, entries, f"JSON 'total' = {total}"
```
