## 2. The named obstruction (lesson 91: name the realization)

1. **The condition is not realization-invariant, and `arXiv:2509.14185` names no realization.**
   Until the space is fixed — specifically the condition imposed at the profile's singular point —
   "the spectrum in the right-half µ-plane consists of a finite number of eigenvalues" has **no
   truth value to prove, disprove *or check*.** This is Xu's published dichotomy
   (`arXiv:2607.19762`), already in this repository at legs 70/171/173/249: same CLM profile,
   maximal-`L²` gives an in-strip smear, origin-`H²` gives `σ_ess = {Re λ = −½}` and point
   spectrum exactly `{0, 1}`. **Cited, not claimed.**
2. **Once a realization is fixed, the residual obligation is a high-frequency resolvent bound on
   the unbounded region `|Im µ| → ∞`** — Hardy–Mellin (Xu), or maximal dissipativity plus
   relatively compact perturbation (BCG `2208.09445` / CGSS `2310.05325` / GHJS `2509.12435`).
   **It is a theorem, not a computation.** No certified count on a bounded box can supply it.

**Named mechanism / one-line corollary: for this condition, numerics is a refuter, not a
verifier.** A truncation ladder can *falsify* finiteness; a certified count can say what sits
inside a box; neither can ever *establish* finiteness.

## 4. Why (iii) and not (ii)

Every rigorous computational route counts **inside a bounded box**; the condition is a claim
about `|Im µ| → ∞`. Four independent literatures show the same split:

* **GHJS `2509.12435`** (149 pp) — energy method at low **and high** frequency, "**rigorous
  computer-assisted techniques in the intermediate regime**". Computer gets the compact middle
  (`Re λ ∈ [0,1]`, `|Im λ| ≤ 8` — this repo's leg 265/verify_265); the unbounded tail is a theorem.
* **Barker–Zumbrun `1601.00837`** — a genuine certified unstable count, via an Evans-function
  winding number on `∂(B(0,R) ∩ {Re λ ≥ 0})` with `R = (√γ + ½)²` **derived analytically**. The
  computer works inside the disc; **the disc is a theorem**.
* **Gallay–Wayne** — `σ_ess = {Re λ ≤ −(m−1)/2}` in `L²(m)`: finiteness is bought by raising the
  weight, i.e. by changing the realization. Independent confirmation of obstruction (1).
* **Chen–Hou** — the computer-assisted 3D-Euler-with-boundary proof **sidesteps** the condition
  (energy estimates + finite codimension), rather than discharging it.

Classical ancestry: Weyl / Kato IV.5.35, the Jörgens–Vidav–Voigt chain, Chicone–Latushkin;
Bricmont–Kupiainen's RG template imposes finiteness by choice of space. **None is available for
CCF, IPM, 2D Boussinesq or 3D Euler with boundary.**
