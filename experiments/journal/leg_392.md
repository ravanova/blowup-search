## 0. The gate, pre-committed — final wording, not re-scoped by this leg

> Does the search locate a **published theorem** excluding a finite-time singularity for 3D
> Navier–Stokes on `T³` of the shape Lane T would need — a periodic/torus analogue of the
> Nečas–Růžička–Šverák / Tsai rigidity results?
> **yes →** name the theorem, its hypotheses **verbatim**, and which hypothesis a Lane T ansatz
> would have to violate. Lane T is killed or narrowed accordingly.

and this leg does not steer toward `no`.

### 0.1 The pre-committed reading — fixed on `main` before dispatch. No fifth branch is constructed.

* **(a)** A located `T³` theorem covering only **self-similar or asymptotically self-similar**
  objects does **NOT** kill Lane T — the lane needs a **non-DSS** ansatz anyway, because the DSS
  ansatz does not survive periodization (leg 390 check_B: 342 modes survive one DSS step at
  `λ = 1.7`, **ZERO** survive two). Recorded as **narrowing, not killing**, with the object class
  left standing stated exactly.
* **(b)** A located theorem covering a **BROADER** class — any bounded-energy periodic solution
  under a scaling-invariant smallness or regularity hypothesis — **bites Lane T directly**, and the
  lane must state what class survives before anything is built.
* **(c) A CONTROLLED ZERO IS NOT EVIDENCE LANE T IS CLEAR.** Leg 348's ceiling clause governs:
  *"absence of a positive instance is not a proof of impossibility"*, and its converse binds here.
  A null is reported as **"not excluded by anything located, with the search's coverage stated"** —
  **never as "clear"**, and never as a result that advances Lane T.
* **(d) NO EXTERNAL OUTREACH — standing user hold.** arXiv / Semantic Scholar APIs only; no author
  group is contacted, ever. **(D)'s data conditions (8) and (9) stay UNREAD**; they need outreach,
  the hold sits on Lane T's critical path, and this leg **raises that (§6) rather than routing
  around it**.

### 0.5 The adjudication rule, fixed before any result was seen

A located record answers the gate **YES** only if its own statement, read verbatim, carries **all
four** of:

* **K1 — DOMAIN**: `T³` / periodic. Not `ℝ³`, not a bounded domain with boundary, not 2D, not a
  slab.
* **K2 — EQUATION**: 3D incompressible **Navier–Stokes**, viscous term inside the theorem. Not
  Euler, not a 1D model, not an averaged equation.
* **K3 — CONCLUSION**: an **exclusion** — no finite-time singularity, or triviality/nonexistence of
  the singular object. Not an existence theorem, not a numerical study.
* **K4 — CLASS**: the hypothesis class is one a Lane T ansatz would have to sit in.

Then, and only then, the branch is read off:

* hypothesis restricted to (asymptotically) self-similar / DSS objects → **branch (a)**,
  *narrowing, not killing*;
* hypothesis a bounded-energy / scaling-invariant smallness or regularity condition on a general
  solution → **branch (b)**, *bites directly*, including when the exclusion is **conditional** (a
  regularity criterion), in which case the hypothesis a Lane T ansatz must violate is named;
* nothing satisfying K1–K4 → **branch (c)**, a controlled null, reported with coverage and
  **never as "clear"**.

**§3d binds:** a null from an under-covered search returns **`UNDER-RESOURCED`** with the coverage
stated and a cost for the compliant search — **never `NO`**. If throttling cuts coverage, the leg
states what fraction of the planned query set actually executed.
