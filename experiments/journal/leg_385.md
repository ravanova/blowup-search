## 1. The object

An adapter `samples_to_cells(r, f_lo, f_hi, hypothesis, ...)` taking point samples on a
radial grid and returning **certified cell enclosures** `(r_lo, r_hi, f_lo, f_hi)` of the
kind `certified_decay_from_cell_enclosures` consumes: `f_lo[i] ≤ f(r) ≤ f_hi[i]` for **every**
`r` in cell `i`, not merely at the sample points.

**Two hypothesis paths, and no third.**

* **PATH A — MONOTONE.** The caller declares `f` monotone (non-increasing or non-decreasing)
  on the whole window. Then on a cell whose two endpoints are sampled, the extremes are
  attained at the endpoints: for non-increasing, `f(r) ∈ [f_lo[i+1], f_hi[i]]`. Exact; no
  slack beyond the caller's own sample error bars.
* **PATH B — MODULUS.** The caller declares a certified, non-decreasing modulus
  `ω(h) = L·h^α`, `α ∈ {1/2, 1}`, in one of two coordinate kinds:
  * `kind="absolute"`: `|f(r) − f(s)| ≤ ω(|r − s|)`;
  * `kind="loglog"`: `|log f(r) − log f(s)| ≤ ω(|log r − log s|)` — the natural form for a
    profile spanning decades, and the one a producer of a decaying profile can plausibly
    certify.
  Every point of a cell of width `h` lies within `h/2` of one of its two endpoints, so
  `f(r) ∈ [min − ω(h/2), max + ω(h/2)]` (absolute), or the same statement multiplicatively in
  the `loglog` kind.

**`solver/interval.py` has no `iexp`.** The `loglog` kind is therefore closed back to
multiplicative form using two elementary bounds that need only `+ − × ÷` on the proved
substrate: `e^{−x} ≥ 1 − x` for all `x ≥ 0`, and `e^{x} ≤ 1/(1 − x)` for `x ∈ [0,1)` (because
`1/(1−x) = Σ xⁿ ≥ Σ xⁿ/n! = eˣ`). Both are used **outward**. Pre-registered as the mechanism
so a reader can check it rather than trust it. Inputs with `ω(h/2) ≥ 1` in this kind are
refused, not approximated.

**Refusal is a first-class output.** An input carrying **neither** hypothesis returns
`INCAPACITY`, never a guess. This is not defensive programming: from finitely many point
evaluations alone, with no regularity hypothesis, *every* superinterval of the range is
consistent with the data, so a "default" enclosure would be a fabrication.

**Conditionality is recorded in the row.** Every returned row carries `hypothesis`,
`hypothesis_detail`, `sample_exactness` and a one-sentence `conditional_on`, and the
convenience wrapper `certified_decay_from_samples` merges those fields into leg 382's own
output dict, so a downstream consumer sees the certificate and its condition together. *A
certificate whose conditionality is invisible is worse than no certificate.*

## 4. The controls — each must be able to fail, and none will be widened

**The leg-361 rule is in force: if a control does not fire, this leg STOPS and reports it
verbatim. No threshold, amplitude, window or modulus is touched to make a control pass.**

* **X1 — NO HYPOTHESIS.** Samples alone. Must return `INCAPACITY`; leg 382's routine must
  never be called.
* **X2 — MONOTONICITY VIOLATED, VISIBLY.** S1's samples with one interior sample raised by
  5%. The declared direction is contradicted *by the samples themselves*, a necessary
  condition the adapter can check. Must return `INCAPACITY` naming the offending index.
* **X3 — MONOTONICITY VIOLATED, SECRETLY.** True profile
  `f(r) = 3 r^-1 · (1 + A·sin(2π (log r − t₀)/Δt))` with `Δt` **exactly** the grid's spacing
  in `t = log r`, so the wiggle vanishes at every sample node and bulges by `A = 0.05` inside
  every cell. The samples are then *identical* to S1's. The adapter **cannot** detect this —
  that is precisely the content of the hypothesis — so it must **accept**, and the failure
  must show up as a **containment failure**: the true profile leaves the claimed cell
  enclosure. The certificate produced is *false about the true profile* while being *valid
  under the declared hypothesis*, and that is the leg's whole argument for recording
  conditionality.
* **X4 — MODULUS UNDERSTATED, DETECTABLY.** `f = r^-2` (true log-log Lipschitz `2.0`)
  declared with `ω(h) = 0.1·h`. Adjacent samples already violate it. Must return
  `INCAPACITY`.
* **X5 — MODULUS UNDERSTATED, UNDETECTABLY.** X3's profile declared with `ω(h) = 1.05·h`
  (`loglog`). The *node-to-node* increments satisfy it exactly (`|Δg| = Δt ≤ 1.05Δt`), so the
  necessary condition passes and the adapter accepts; the true within-cell variation `A =
  0.05` far exceeds the inflation `ω(Δt/2) ≈ 2.4e-3`. Must show a **containment failure**.

**Containment audit.** A float64 device, `containment_audit`, evaluates the *true* planted
profile on a dense sub-grid strictly inside every cell and reports the worst signed margin
(positive = the truth escaped the claimed enclosure). It is available only for planted
knowns, is documented as a validation tool and never as part of a certificate, and the
violations it is asked to demonstrate (~5e-2 relative) sit ~14 orders of magnitude above
float64 noise, so demonstrating a failure with it is sound even though certifying a success
with it would not be.

## 5. Where Part I was WRONG — recorded, not amended

**P11 REFUTED.** Part I §5 predicted X3's profile would be *visibly* non-monotone on the
half-cell-shifted grid and refused. It is not: the adapter returns `CELLS`, and so it does on
the quarter-shifted grid. **Mechanism:** the wiggle has period exactly one cell in
`t = log r`, so a uniform shift by `s` cells multiplies *every* sample by the same constant
`(1 + A sin 2πs)`; a constant multiple of a monotone sequence is monotone and its
log-increments are unchanged, so both necessary conditions pass at every uniform shift. The
half-shift is doubly invisible because `sin π = 0`. Part I's reasoning was wrong about which
grids can see the wiggle.

A **post-hoc** probe (labelled as such in the JSON, and deciding nothing about the gate)
located the correct statement: detection is a **commensurability** effect — `N = 1100`
(`+7.032e-3`) and `N = 1500` (`+2.494e-2`) refuse; `N = 500, 997, 1001, 1010, 2000` do not.
A hypothesis-violating profile can hide from any *fixed* grid. That strengthens the leg's
conclusion: the hypothesis is doing the work, the sampling never was.
