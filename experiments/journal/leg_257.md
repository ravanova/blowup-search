heuristic here, and that is the one methodological thing this leg would most want carried
forward.**

**704**, eq (2) @ **84**, `References` @ **1883** — and the full census re-ran on it to

**The lesson worth banking: an md5 on a PDF does not pin a text extraction.** Leg 245 and this
leg both quote "md5 X, 2060 lines", which reads like one pin but is two artifacts — the second
is reproducible only if the *extraction command* is part of the pin. It now is, in this
module's docstring. A locator-bearing leg should state the command, not just the hash.
