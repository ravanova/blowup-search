## 1. Why a single-mode Galerkin truncation, not a free 3D solve

A full free-form 3D grid/spectral solver for the rescaled vorticity equation

    d_s Omega + Omega + (1/2)(y.grad)Omega + (V.grad)Omega - (Omega.grad)V = Delta Omega,
    V = BS(Omega)

is out of a 2-leg budget (this is M1-M2-M3's full stack, §3.3 of the plan). This brick builds
the smallest HONEST reduction that still integrates the true equation's actual coefficients:
restrict to `Omega(y,s) = c(s) Omega_B(y)`, `V(y,s) = c(s) u_B(y)` (BS is linear, so this V is
exact, no new Biot-Savart solve needed), and require the residual to be L^2-orthogonal to
`Omega_B` — a genuine Galerkin condition, not a curve fit. This gives a scalar ODE

    c'(s) = alpha*c(s) + beta*c(s)^2,
    alpha = -(1/4 + G/M),  beta = -N/M,
    M = <Omega_B,Omega_B>, G = <grad Omega_B,grad Omega_B>, N = <Omega_B,(u_B.grad)Omega_B-(Omega_B.grad)u_B>

using two EXACT identities that hold for ANY sufficiently-decaying vector field `f` (not
special to `Omega_B`): `<f,(y.grad)f> = -(3/2)<f,f>` (from `div(y)=3` in R^3, integration by
parts) and `<f,Delta f> = -<grad f,grad f>` (integration by parts, boundary term vanishes for
`Omega_B`'s `r^-3` decay). These two identities are why the SAME formula `alpha_f =
-(1/4+G_f/M_f) <= -1/4` is a general energy (Lyapunov) bound on the equation's linear part for
ANY test field, not an artefact of this one witness — this is the pre-stated window's
theoretical floor, written down in the runner BEFORE any quadrature ran (see the runner's own
module docstring).

## 2. The measurement

`M, G, N` computed by a 3D spherical quadrature (Gauss-Legendre in a Boyd-mapped radial
coordinate and in `cos(theta)`, trapezoid — spectrally accurate for a smooth periodic
integrand — in `phi`). Cross-check: `M` at the finest resolution matches leg 351's OWN
independent closed form `||Omega_B||_L2^2 = 2*pi^2` to `<6e-15` relative. Across four
independent (resolution, domain-scale) settings, `alpha` is stable to `<7e-15` relative and
converges to the exact rational

    alpha = -19/16 = -1.1875

`N/M` is `~1e-18` relative to `M~20` — not merely small, an EXACT identity: `Omega_B` and
`u_B`'s `(x1,x2)`-components have opposite parity in `x3` (`Omega_B` even, `u_B`'s in-plane
components odd, `u_B`'s `x3`-component even), which makes the full integrand of `N` an ODD
function of `x3`; its integral over the `x3`-symmetric domain R^3 is exactly zero (see the
module docstring for the full parity count). So `beta=0` for this witness, and its Galerkin
mode decays EXACTLY LINEARLY: `c(s) = c0*exp(alpha*s)`.

**Known-answer reproduction (the gate, stated window `S_max=5.0`, `n_steps=2000`,
`c0=0.01`, fixed in the runner BEFORE running):**

    max rel error, RK4 stepper vs closed form  = 3.85e-12   (threshold 1e-6)
    c(S_max)/c0                                 = 2.64e-3   (threshold: < 1e-2, i.e. visibly relaxed)

PASS.

**Planted non-trivial control.** Because `alpha_f <= -1/4` for EVERY decaying vector field
(the general bound above), no choice of DATA within the correctly-implemented linear dynamics
can fail to decay — using a different data vector as the "planted control" would make the
check vacuous for a different reason (universal decay). The control this leg plants is
therefore a single-coefficient SIGN BUG on the stepper: the confinement term's coefficient
(the plan's own §3.1 names it explicitly as `1`) flipped from `+Omega` to `-Omega` — a
realistic sign-convention bug on exactly the term/axis leg 332's §10 rider and this plan's
own §3.1 flag as significant (the backward-vs-forward similarity-variable drift sign). With
this one sign flipped, the SAME derivation gives

    alpha_bug = 7/4 - G/M = 13/16 = 0.8125   (POSITIVE)

On the IDENTICAL `c0=0.01` and IDENTICAL window `S_max=5.0`:

    growth ratio c(S_max)/c0 = 58.12   (threshold for FAIL: > 1, i.e. grown not relaxed)

FAILS AS REQUIRED. The relaxation-to-trivial check is therefore not vacuous: it distinguishes
the correctly-signed stepper from a one-sign-bit bug on the same data and window.

A second, independent stress test (not itself a decaying-Leray probe — a synthetic
`alpha=-1,beta=1,c0=2>c*=1` case with a KNOWN finite closed-form blowup time `s*=0.693147`)
confirms `integrate_rk4`'s own divergence-stop machinery fires within one step-width of `s*`
(`s_stop=0.693494`), i.e. non-relaxation is DETECTED by the stepper's own machinery, not
silently overflowed past.

## 3. What this measurement is not

This is a single-mode Galerkin truncation, verified against a closed-form scalar ODE. It is
NOT a free 3D PDE solver (M1's full stiff-linear/explicit-nonlinear integrating-factor scheme,
§3.3, is out of this brick's 2-leg budget) and it does not exercise a genuinely non-trivial
nonlinear self-interaction (`beta` is exactly zero for THIS witness — an honest finding, not
engineered). B5/B6, if they build a genuine multi-mode or grid stepper, will need `beta != 0`
machinery this leg's module already carries (the general Riccati branch of `closed_form_c`/
`rhs`/`integrate_rk4` is exercised and tested independently in `test_dssp_step.py` on a
synthetic nonzero-`beta` case, not just the physical `beta=0` mode).
