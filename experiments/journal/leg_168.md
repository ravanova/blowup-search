## The thing that decided this leg's design, before it ran

Leg 152 already ran both halves of this gate on its own authority: 552,258 clean leaves
bit-identical, all five mechanisms inverted. **A leg 168 that re-ran leg 152's leaf set would
reproduce 552,258 identical numbers and prove nothing** — lesson 90 in its purest form, a
control that cannot come out differently, whose tell is that the numbers are identical. The
novelty pass (`writeup/novelty/leg_168.md`, committed at `eb08afe` **before** a line of the
runner was written) located where leg 152's coverage actually stops, and the leg was aimed
there instead. Four gaps, all four occupied.

## The number neither leg 117 nor leg 152 ever took

Both asserted the new guards are unreachable from every shipped configuration — leg 117 by a
**textual** census of call sites, leg 152 by its own leaf set. Neither measured **how far** any
shipped configuration sits from a guard's activation boundary. It is a number, so it was taken.

`velocity()`'s G2 guard fires on a `RescaledHLDynamic` grid exactly when the `Xc=1` grid stops
reaching back to `X_ref=0`, i.e. when `X.min() > 0`. Bisected over every shipped resolution
(200 iterations each), the boundary is **M\* = 1.038017** (worst case, at `n=101, delta=0.05`;
the finest grids sit at `1.00291`). Against it:

| site | M | margin |
|---|---|---|
| `test_hl_rescaled_adversarial.py:445,506` | 20.0 | **19.27×** |
| `experiments/p2_conj24_relax.py:136` | 150.0 | 144.51× |
| `test_hl_rescaled.py:146` | 200.0 | 192.67× |
| `test_hl_rescaled.py:110,131` | 500.0 | 481.69× |
| `test_hl_rescaled.py:67,86` | 1000.0 | 963.37× |

**The smallest margin anywhere in the repository is 19.27×.** The `RescaledHLScenario2` grid has
no boundary at all: `X = 0` is an exact node by construction (`X ∈ [−745.24, +745.24]`).
This measurement could have come out badly on its own — had the smallest shipped `M` sat just
above `M*`, the repair would be a latent regression waiting for the next parameter change
rather than a closed defect. **Lesson-90 control, one argument changed in the identical call:**
the guard fires **3/3** below `M*` and stays silent **3/3** above it.

## The pre-registered question, and the answer that went against the suspicion

Leg 117 **prescribed** `np.isfinite(X)` for the G8 mask; leg 152 **shipped** `np.isnan(X)`
(`solver/hl_rescaled.py:339`). They differ exactly on `±inf` — textbook incomplete-fix shape
("a narrow report produces a narrow patch"). Both outcomes and the **discriminator** were fixed
in writing in the novelty log before the measurement, precisely so the answer could not be
retrofitted. The discriminator is leg 117's own G8 bar: a finding requires the value to be
indistinguishable from legitimate physics **and wrong**.

**Measured, and it is not a finding — the narrowing is benign here, for a specific reason:**

* At `X = -inf`, all 3 kinds return **exact `0.0`** for both fields — indistinguishable from a
  legitimate `X <= 0` node. But `degenerate_ic` maps `X` through `xp = np.maximum(X, 0.0)`, so
  the defining formula is *itself* evaluated at `xp = 0` and returns `0` by the same arithmetic.
  **Two independent routes — the formula and the module's one-sided-support convention — give
  the same `0.0`, so it is the CORRECT value there, not a fabrication.** That is exactly what
  separates it from the NaN case, where `0.0` was invented for an abscissa that has no location.
* At `X = +inf`, every kind returns either **NaN** (visible, with a numpy `RuntimeWarning`) or
  the **true limit `0.0`**. **No kind returns a wrong finite value** — the property that
  actually matters, and the one now pinned.
* Recorded rather than smoothed: the three kinds **disagree with each other** on `Theta0` at
  `+inf` (A and C give `0.0`, B gives NaN). Every disagreement is visible, never a wrong finite
  number, so it is an inconsistency and not a defect.

So the honest report is **"narrower predicate than prescribed, defensibly so, measured"** — not
a gate-flipping incomplete fix. Reporting it the other way would have been the easier headline.
