## §1. WHY THIS UNIT EXISTS

`L6` (leg 401) reported, at `n_dof = 6720`, branch B, smallest residual **1.6138**,
`decreases_under_refinement = "NO"`, ladder `J0`–`J4` = {3.6467, 1.6987, 1.6756, 1.6219,
1.6138}. The Conductor's landing audit (`writeup/waves/WAVE6_CLOSE.md`) found, **in the
artefact and not in the unit's summary**, that at every rung above the coarsest the minimum
is attained by **exactly one start — the continuation from the rung below** — while all five
independent random seeds land 10–24× higher and get **monotonically worse** as `n_dof`
grows (`J1 ≈ 6.8 → J4 ≈ 32–38`); and that **all 133 starts hit the 800-iteration cap**
(`cost_and_shortfall.maxiter_actually_used = 800` against
`preregistered_maxiter = 20000`, `fraction_of_starts_capped = 1.0`). A ladder each of whose
rungs is initialised at its predecessor's minimiser, at a budget too small to explore the
dimensions the rung just added, is **biased toward measuring "no change"**. `L6`'s own §8.4
concedes its number is not an infimum.

So `L6`'s `NO` is not yet a fact about the **ansatz**, and the Lane-L queue behind it
(`L7`, `L4`) is priced as if it were. This unit separates the two hypotheses at the one
place they can be separated cheaply: **fixed resolution, 25× the iteration budget.**

## §2. THE REALIZATION, TRIAL SPACE, BASIS AND NORM (lesson 91) — TAKEN, NOT CHOSEN

All four are read out of `writeup/data/p2_route_l6_profile_v1.json`
(`self_hash = 6a033004deef39d3`, re-derived here from the document itself, not trusted from
prose) and are **unchanged**:

- **Realization.** Backward `λ`-DSS blow-up profile of 3-D incompressible Navier–Stokes on
  `ℝ³`, `λ = 1.7`, `a = −λλ_t = 0.5`, period `T_s = 2 log λ`, unit viscosity, no forcing,
  non-axisymmetric admitted.
- **Trial space.** Chandrasekhar poloidal–toroidal representation w.r.t. the position
  vector, `V = curl curl (f y) + curl (g y)`, so `div V ≡ 0` identically — no projection,
  no Bogovskiĭ corrector.
- **Basis.** Real spherical harmonics `Y_lm` (`1 ≤ l ≤ Lmax = 4`); radial algebraic map
  `u = r/(r + 2)` with Chebyshev `T_n(2u−1)` and end prefactors `u^l` (poloidal),
  `u^l(1−u)` (toroidal), `Nr = 20`; real Fourier in `s` on one DSS period, modes `0..Ks`,
  `Ks = 3`. **`n_dof = 6720`, fixed.**
- **Norm (load-bearing).** `‖curl F‖_{L¹_t L^{3/2}_x} = ∫₀^{2 log λ} ‖curl_y R[V](·,s)‖_{L^{3/2}(ℝ³)} ds`,
  pressure-free, taken through `L6` from `L5`'s banked artefact.
- **Branch B normalisation.** `(1/T_s) ∫ Σ_lm F_lm(∞,s)² ds = 1` — the `α = 1` far-field
  amplitude held at unit size. Branch A is not run: the gate names branch B.

## §4. THE OPTIMISER, AND THE DEFECT CARRIED FROM `leg_401.md` §7.3

**Carried, not rediscovered.** `L6`'s objective is invariant under `c ↦ t c`, because the
normalisation is applied *inside* the AD tape. Hence `∇J ⊥ c` and `‖∇J‖` falls like
`1/‖c‖`, while L-BFGS-B's stopping test is on `‖proj ∇J‖_∞`. Once the iterate drifts
outward, **the stopping test fires while the objective is still falling** — measured by
`L6` at rung `J0`, branch B, seed 401: `CONVERGENCE: NORM OF PROJECTED GRADIENT <= PGTOL`
at iteration 1041 with `|g|_∞ = 6.85e−13`, `J` still dropping 2.7% per 25 iterations,
`‖c‖ ≈ 185`; continuing past that point took the same start from `J = 3.7734727962` to
`J = 1.4447691808`, a factor 2.6.

`L6`'s fix is used **verbatim**, by importing the same module constants and calling the
same functions: on every stop the iterate is rescaled onto the normalisation surface
(changing no function value) and the solver is restarted with the remaining budget; the
loop ends only when a restart buys less than `REL_STALL = 1e−10` relative improvement, or
the budget is spent. `ftol = 1e−16`, `gtol = 1e−12`, `maxfun = 2 ×` remaining, exactly as
`L6`. `L6`'s scale-invariant stationarity measure `‖x‖‖∇J‖/|J|` is recorded per start.

**Pre-committed now: if a start reports convergence before the cap, I must prove it is not
this defect recurring, with the same check.** The proof required, fixed before any run: the
artefact carries, per start, every restart round's `nit`, `fun`, `status` and `message`; a
recurrence of the defect is visible as a round that stopped on PGTOL and whose **successor
round bought a large further decrease**. A start is declared genuinely stalled only if its
**last** restart bought `< REL_STALL` relative improvement — i.e. renormalising and
restarting from the reported point does **not** continue to descend. Both the round table
and the scale-invariant gradient are banked so a verifier can check this without rerunning.

## §5. THE TWO DELIBERATE DEVIATIONS FROM `L6`'s `_minimise_one`, BOTH NON-NUMERICAL

Declared here, before the run, because a unit whose whole job is to compare against `L6`
must state exactly where its code differs from `L6`'s.

- **(D1) The trajectory's iteration index is made CUMULATIVE across renormalising
  restarts.** `L6`'s callback counter resets to zero at every restart. This was **latent**
  in `L6` — all 133 of its banked starts have `restarts = 1`, i.e. exactly one round — but
  this unit runs 25× longer and will restart, and the gate asks for "the residual
  trajectory **against iteration count**". Without this, the reported trajectory would not
  be the thing the gate asks for. **This is a real (if latent) instrumentation defect in
  `L6`'s recorder; it is recorded here and `L6`'s file is not edited.**
- **(D2) Checkpointing.** Every 100 iterations each worker atomically rewrites
  `experiments/route4/l6b_ckpt/<start>.json` with its trajectory so far and its current
  6720-coefficient iterate, and the parent commits those **tracked** files on a timer. Wave
  3 lost three of four units because only one left anything behind, and git-ignored
  checkpoints have died with a container twice.

Neither deviation touches the objective, the gradient, the normalisation, the stopping
rule, or the sequence of iterates. Everything numerical is called out of `l6`.
