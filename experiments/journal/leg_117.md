# Leg 117 — Route-HRA: adversarial audit of `solver/hl_rescaled.py`

**Branch** `leg/hra-v1`. **Exploration leg, standard, CLAIM-BEARING** (adversarial audit).
**Gate (verbatim).** *Under an adversarial battery of degenerate or poisoned inputs, does
`solver/hl_rescaled.py` ever silently return a wrong result instead of flagging the input?*

## GATE ANSWER: **YES.** Escalated, not patched.

`solver/hl_rescaled.py` is untouched by this leg, under the gate's own instruction (the
territory names it read-only under any outcome). Four independent silent-corruption
mechanisms found, all finite, all zero-warning, all zero-exception:

| | mechanism | magnitude | worst case |
|---|---|---|---|
| **G1** | `velocity(X, Homega, X_ref)` never validates `X` is ascending | 20/20 random permutations silently wrong | max abs error **212.04** (91x the true scale) |
| **G2** | same function's `X_ref` pin silently clamps via `np.interp` when `X_ref` is outside `[X.min(), X.max()]` | 4/4 out-of-domain `X_ref` values | uniform additive shift **1.4712** at `X_ref=-5.0` vs a `[0,10]` window |
| **G3** | `sinh_grid_at(n, M=<negative>)` is never validated for `M>0` | silently returns the exact descending mirror grid, 0 warnings | — |
| **G8** | `degenerate_ic`'s closing `np.where(X > 0.0, field, 0.0)` uses an ordered comparison, so IEEE-754 makes it False for NaN | 3/3 `kind`s launder a NaN abscissa into exactly the clean 0.0 a legitimate `X<=0` point produces | indistinguishable from valid data, all 3 NaN positions tested |

**G8 is the headline.** It is not a caller-contract violation like G1–G3 (a caller who sorts
`X` or checks `X_ref`'s range can avoid those); G8 happens *inside* the module's own
one-sided-support convention, and a NaN that entered `X` from anywhere upstream is silently
erased into a value indistinguishable from legitimate physics, with zero trace.

## What was checked and found NOT exploitable (recorded as loudly as the findings)

- **G4**: `RescaledHL.__init__`'s ascending guard `np.any(np.diff(X) <= 0)` has the identical
  NaN-comparison blind spot as G8's mechanism — genuinely defeated by a NaN anywhere in `X`.
  But in every configuration tested, the poisoned grid propagates to an **all-NaN** Hilbert
  transform downstream (`line_hilbert.py`'s dense operator sums a NaN into every output row),
  visibly, not a plausible finite answer. Reported at that strength and no higher, per the
  novelty pass's own honesty rule; `test_CHARACTERIZE_nan_defeats_ascending_guard` pins the
  boundary so that if this ever *does* start returning a finite result, the test fails loudly
  as a new, more severe finding rather than silently drifting.
- **G6**: `_solve_3x3`'s absolute `1e-14` pivot threshold never returned a silently-wrong
  solution over 300 random systems spanning 16 decades of scale (0/300) — it always matched
  `numpy.linalg.solve` or raised. It DOES over-reject a uniformly-tiny (1e-16) but perfectly
  well-conditioned matrix as "singular," a false positive recorded for completeness (not a
  violation of this leg's gate — over-caution is not corruption).
- **G7**: `+/-inf` at a grid ENDPOINT survives the ascending guard (order comparisons
  involving a signed infinity at an edge are well-defined), unlike an interior inf (correctly
  rejected as a control); downstream always visibly warns or returns non-finite. 0/2 silently
  clean.
- `degenerate_ic` correctly raises `ValueError` on an unrecognised `kind` string — its own
  correct-flagging behaviour, banked alongside its NaN-laundering defect.
- `scenario2_ic`, which has no closing `np.where` mask, visibly propagates the *same*
  NaN-poisoned `X` to NaN output — confirming G8 is specific to `degenerate_ic`'s particular
  construction, not a property of "any IC generator in this module."
- `normalize_amp`/`amp_gauge` (the same `abs(h0) < 1e-14` guard shape as the ascending check)
  never silently returned a clean finite field across NaN, single-poisoned-entry, and
  near-max-float `Omega` (0/3).

## Disposition

**ESCALATE. Do not patch under this leg's authority.** `solver/hl_rescaled.py` is not edited.
When authorised, the repairs are small and independent per mechanism: `velocity()` should
validate `np.all(np.diff(X) > 0)` and `X.min() <= X_ref <= X.max()`; `sinh_grid_at` should
validate `M > 0` (or take `abs(M)` with a warning); `degenerate_ic`'s closing mask should use
`np.where(np.isfinite(X) & (X > 0.0), field, np.where(np.isfinite(X), 0.0, np.nan))` or an
explicit `np.isfinite(X)` precondition check before the comparison. None of these change any
number `capabilities.py` records for `test_hl_rescaled.py`'s validation anchors.

`test_hl_rescaled_adversarial.py`'s four `test_PIN_*` gates assert the current, defective
behaviour and **must be inverted, not deleted or weakened**, the day a repair lands — leg
66/69/84's precedent, reused verbatim by legs 92/96/106/116/120's own adversarial suites.
