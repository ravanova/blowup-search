## §1 METHOD, AND THE ONE THING THAT MAKES THIS REPORT READABLE

**Every check below carries its class**, per `CORRECTIONS.md` §45:

- **`[P]` recompute-from-primary** — the number is re-derived from raw data, from a file the unit did
  not write, or from code written before the unit existed. It can certify the CLAIM.
- **`[A]` re-read-own-artefact** — the number is re-read from, or recomputed inside, the same
  artefact whose claim is at issue. It certifies INTERNAL CONSISTENCY and nothing more.
