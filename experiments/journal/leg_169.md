## The method, and the two things that made it possible

**Clause (b) is a same-process two-arm bitwise differential**, not a comparison against a banked
number. That was forced, not chosen: `capabilities.py:368-371` records this module as
*"no known-answer gate; bounds checked against dense sampling"*, so there is no external referent
— leg 105's finding, in the form it takes here. The pre-repair arm is `07f2b03`'s source read out
of `git` and exec'd into a private module object in the same process, on the same libm/BLAS, so a
moved leaf can only come from the module's own source. `solver/nk_seminorm.py` — the module's
only `solver` import — is **byte-identical** at `07f2b03` (sha256 `d6964d06…`), so the
differential isolates `hilbert_holder.py`; leg 103's precedent.

**The `on_unsound='extrapolate'` escape hatch is what makes clause (a) measurable at all.** Leg
153 designed it in per leg 135. Without it the pre-repair number is unreachable from the current
module and there is no two-sided comparison to make.

## FINDING 3 — leg 153's `HEAD_WARN_TOL` margins are quoted on a coarser grid than the module ships

Not a regression, and not a soundness question — `HEAD_WARN_TOL` governs a **warning** that
changes no returned value and can reject nothing. But the numbers on `main` are measured on a
grid the module does not use.

Leg 153 measured the discarded-head shares on `pair_grid(n_theta=24, n_d=14)` at `n_quad=200` —
**481** increment-regime pairs. `hilbert_holder_constant`'s own **default**, the grid every
banked `b_sup`/`b_semi` is computed on, is `pair_grid(n_theta=48, n_d=28)` at `n_quad=400` —
**2009** pairs. Reproduction control first: **on leg 153's own grid this leg recovers leg 153's
own numbers bitwise**, so what follows is a resolution effect and not a harness difference.

| worst head / returned value | leg 153's 24×14 grid | shipped 48×28 grid | ratio |
|---|---|---|---|
| shipped `(1.5, 0.5)` | `1.3926124218598773e-05` | `1.430660418824069e-05` | **1.0273×** |
| production `(1.4, 0.15)` | `0.050804197109344515` | `0.05384763279240704` | **1.0599×** |
| margin **below** worst shipped | `71.81×` | **`69.90×`** | |
| margin **above** worst production | `50.80×` | **`53.85×`** | |

Both margins move *toward* the tolerance on the shipped side and away on the production side, and
**the band still separates the two configurations on both grids** — the constant is correctly
placed, and it is placed with less shipped-side headroom than the banked figure suggests. The
direction is the expected one: a grid supremum can only under-report, which is
`test_nk_hilbert_holder.py` gate 3's own point turned on leg 153's measurement.

## FINDING 4 — legs 119 and 153 disagree about the ε-drift diagnostic, and the disagreement is the ε pair

Leg 153's novelty §4b reports that extending leg 119's `γ` ladder below its floor of `0.05` puts
**3 sound `γ` above leg 119's banked "1.98× when unsound" floor**, with max-when-sound `2.3816`.
Leg 119's `1.98` is banked by its gate `A8`, which compares `ε = 1e-8` against `1e-16` — **8
decades**. Leg 153's §4b table tabulates `u(1e-16)/u(1e-6)` — **10 decades**. Both reproduce
here, on the same extended `γ` ladder:

| ε pair | max when sound | min when unsound | sound rows above 1.98 | separation |
|---|---|---|---|---|
| leg 119's gate A8, `1e-8 → 1e-16` | **1.7984** | **1.9820** | **0** | **survives** |
| leg 153's §4b, `1e-6 → 1e-16` | **2.3835** | **2.6268** | **3** | survives (re-fitted) |

So leg 153's numbers are right *on its own pair*, and its comparison against leg 119's floor is
apples-to-oranges: on the pair that floor was banked from, **no sound `γ` crosses it** — leg
119's separation is **narrowed, not broken**. Leg 119's own `1.34` also reproduces exactly
(`1.339`) on its own pair with its own ladder stopping at `γ = 0.05`.

**What survives both readings, and it is the only thing that matters:** the margin **collapses**
once the ladder goes below `γ = 0.05` — measured `1.4800× → 1.1021×` on leg 119's own pair (and
to the *same* `1.1021×` on leg 153's pair, from `1.6348×`) — because the
drift is continuous through `γ = 0⁺` (`s0^γ/γ → ∞`). So **leg 153's conclusion is correct and
unaffected**: no fixed threshold on this diagnostic is safe, and the guard must use the exact
predicate. Only its supporting comparison mixed two ε pairs. Nothing in the module's behaviour
depends on which reading is taken — the guard uses `γ > 0` and no threshold at all.
