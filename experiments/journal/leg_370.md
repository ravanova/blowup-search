## The Ṁq,1 definition used, quoted (leg 368, Sec 2.1 read)

`||f||_{Ṁp,l(Ω)} = sup_{R>0} sup_{x∈Ω} [ R^{3(1/p−1/l)} ∫_{Bx(R)∩Ω} |f(y)|^l dy ]^{1/l}`, l=1 for
`Ṁq,1`: `||f||_{Ṁq,1} = sup_{R>0} sup_x [ R^{3(1/q−1)} ∫_{Bx(R)} |f(y)| dy ]`. Purely ball-averaged
(Lebesgue-integral), no pointwise-decay content.

## Implementation

`solver/dssp_screen.py`, additive:

- `_l1_ball_integral_ladder(field_fn, R_hi_ladder, ...)` — reuses `_spherical_shell_nodes()`
  directly (the SAME quadrature convention `l3_norm_ladder()` uses), computing the cumulative
  `Int_{B_R(0)} |V(y)| dy` (power 1, not power 3) over the same shell ladder.
- `morrey_ball_average_sweep(field_fn, q_values=None, R_hi_ladder=..., ...)` — the genuine
  numerical test: sweeps a finite grid of q densely sampled across the OPEN interval `(3/2, 6)`
  (26-point `np.linspace(1.5, 6.0, 26)[1:-1]`, endpoints excluded to match the theorem's own strict
  range), and for each q computes `R^{3(1/q-1)} * I(R)` over the ladder, fitting a log-log trend
  (the same "measurement, not error" convergence-check convention `l3_norm_ladder()`'s own
  `converged` flag uses, applied to the boundedness direction). Membership (`in_morrey_class`) is
  `True` iff ANY swept q gives a non-increasing/bounded ladder.
  - STATED SCOPE LIMITATION, in the code's own docstring: `sup_x` is evaluated at `x=0` ONLY (the
    same convention `l3_norm_ladder()` already uses for its own quadrature center), not the
    theorem's literal sup over uncountably many `x ∈ R³`; and `sup_R`/the q-sweep are over finite
    grids. This is a genuine at-resolution test, not an exhaustive one — stated explicitly, not
    silently assumed.
- `ledger_morrey(morrey_result, ansatz_result)` — the ledger entry itself, structured IDENTICALLY
  to `_ledger_nrs_tsai_three_way()`: the ansatz gate is checked FIRST (`NOT-REACHED-BY-ANSATZ` if
  the candidate fails it, citing leg 368's own quoted ansatz-check finding as the deciding clause),
  then `EXCLUDED-BY-MORREY` if `in_morrey_class` is True (citing Theorem 1.2, the embedding chain,
  and the Ṁq,1 definition, all quoted verbatim from leg 368's banked record), else `NOT EXCLUDED`.
- `machine_read_ledger(l3_result, lambda_result, decay_result=None, ansatz_result=None,
  morrey_result=None)` — extended with a NEW, OPT-IN `morrey_result` parameter, defaulting to
  `None`. A `"Morrey"` key is added to the returned dict ONLY when both `morrey_result` and
  `ansatz_result` are supplied — every pre-existing call site (leg 357's and leg 362's own
  runners, and every existing test) omits it, so the returned dict's key set is UNCHANGED for
  them. This is the same backward-compatibility pattern leg 362 already used for
  `decay_result`/`ansatz_result`.

No existing function's body was edited. `git diff --stat` on `solver/dssp_screen.py` shows only

**(a) Planted control, construction notes.** The FIRST attempt (a radially-symmetric bump on a
1/|x| base, breaking monotonicity along the sampled ray) evaded T2 but, because the bump was
isotropic, also inflated the FULL-solid-angle L³ shell integral enough that `l3_norm_ladder()`'s
own relative-change-of-last-step convergence check falsely read `converged=True` — a single large
early-rung spike dwarfing the true log-divergent tail's ongoing per-decade growth in the RELATIVE
comparison. This was diagnosed by printing the full shell ladder (not trusting the boolean flag
alone), matching this same "artefact vs. genuine measurement" caution the module's own
`l3_norm_ladder()` docstring already flags for shell ratios. The WORKING construction instead makes
the bump ANGULARLY NARROW (a Gaussian in solid angle, `exp(-ang^2/0.01)`, centred exactly on
`fitted_far_field_decay_exponent()`'s own default sampled ray direction) and radially narrow
(`exp(-((log10(r)-3)^2)/0.0005)`, centred at r~1000, the last of the 12 default log-spaced sample
radii): large ON that one ray (amplitude factor ~300 there), negligible as a fraction of the total
solid angle at each radius (so the full-sphere L³ shell integral stays genuinely, measurably
log-divergent -- confirmed by printing the full ladder: shells 87.8, 87.8, 87.8-per-decade
constant, exactly the Type-I log-divergence signature the existing test suite already checks for),
and a bounded, localized perturbation of a genuinely-decaying base field, so the ball-averaged L¹
mass growth rate is unchanged asymptotically and the profile lands inside Ṁq,1 (witnessing q ≈
3.12, inside the open (3/2,6) range). Measured, not asserted: T1/T2's own three-way ledger reads
`NOT EXCLUDED` on this field; the new Morrey entry reads `EXCLUDED-BY-MORREY`.
