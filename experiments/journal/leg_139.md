## What the novelty pass changed about the leg

All five findings got a citable boundary before a line of the battery existed, and two of them
were *reframed* by it.

**(1) G1's threshold is published, and it is the module's own.** The one-pass induced-norm
trick is the monotone / inverse-positive matrix argument (a non-singular M-matrix has a
non-negative inverse, so the extremal source realizes the induced norm). The discretization is
the trapezoidal rule, which is **A-stable but not unconditionally positivity-preserving** —
positivity carries a finite step restriction (Bonaventura & Della Rocca
[arXiv:1510.04303](https://arxiv.org/pdf/1510.04303); Horváth et al.
[arXiv:2105.07403](https://arxiv.org/pdf/2105.07403) for the θ-method on the advection operator,
which is the operator here). So the audit's job was never to argue that some grid is "too
coarse" — it was to show that a **known** condition is enforced on one branch and not its
sibling, and to measure what that costs.

**(2) G3 stopped being "negative α is out of scope" and became a sharp boundary at α = −1.**
`math.lgamma` returns `log|Γ(x)|` and drops the sign, which POSIX keeps in `signgam` and SciPy
in `gammasgn`; Python exposes no `signgam` at all. That gave a *decisive oracle* (the reflection
formula) and, with it, a control that could have failed and did not: on `−1 < α < 0` the
expansion is legitimate and the module is **right**, verified against a Γ-free quadrature.

**(3) G5 could not be reported as "undocumented truncation".** The truncation *is* documented
(`max_{j+k ≤ len(v)}`). The published Beurling condition is a supremum over **all** pairs, so
the honest statement is narrower and worse: a documented restriction silently converts a
two-sided *sharp* bracket into a one-sided under-estimate, with no consistency check against the
`2K` modes the module's own `quadratic_coeffs` emits by default.

## The five findings, with magnitudes

Every number below is in `writeup/data/p2_route_dga_v1_adversarial.json` and is re-derived by
`test_decay_grading_adversarial.py`. Reference value throughout: the module's **own** exact
closed form `farfield_inverse_norm_finite(1.5, 1, 1e12) = 3.999996`.

**G1 — THE GUARD ASYMMETRY (headline).** At `n = 20` (`dtau = 1.4543 > 2c = 1.0`): `alpha=2.5`
raises `ValueError("grid too coarse: need dtau < 2c")`; `alpha=1.5` returns **26630.848**, a
factor **6657.7×**, silently. Worst over the ladder **1.458e17×** at `n = 4`. **The dangerous
regime is the quiet one:** at `n = 28` (`dtau = 1.0234`, barely past the threshold) it returns
**2.8534** — a perfectly believable norm that is **29% low**. Nobody would query 2.85; that is
the point.

*Mechanism, separated from ordinary discretization error (this is the part that makes it a
correctness claim).* The module never forms the map `g → h` as a matrix. The runner does, with
an independent second implementation of the same recursion, validated against the module on the
clean extremal source (`reimplementation_matches_module: true` at every probe). The one-pass
value equals the true discrete induced norm **iff** that matrix is entrywise non-negative — the
module's own stated hypothesis. Measured:

| grid | `dtau` vs `2c` | negative entries | one-pass ÷ true induced norm |
|---|---|---|---|
| `n = 401` | 0.0691 < 1.0 | **0.0%** | **1.000000** |
| `n = 60` | 0.4683 < 1.0 | **0.0%** | **1.000000** |
| `n = 28` | 1.0234 > 1.0 | 23.2% | 1.0366 |
| `n = 20` | 1.4543 > 1.0 | 22.5% | **3.2890** |
| `n = 14` | 2.1255 > 1.0 | 21.4% | 1.1590 |

Past `dtau = 2c` the returned quantity **is not an induced norm at all**. Below it, it is exact.

*The control that could have come out flat (lesson 90).* If the cause were "the grid is small",
the onset would not care about `c`. It does: the largest `n` the `alpha > 2` branch refuses is
**14 / 28 / 56 / 111** for `c = 1 / 0.5 / 0.25 / 0.125`, against the `dtau = 2c` predictions
**14.82 / 28.63 / 56.26 / 111.52** — and at every one of those grids the `alpha < 2` branch
returns a finite number instead of refusing.

**G2 — THE FABRICATED ZERO NORM.** A negative speed `c = −0.5` and a swapped domain
`X0 > Xmax` each drive `farfield_inverse_norm` to return **exactly 0.0** as an induced norm —
3 of 4 inadmissible cases — while the `predicted` companion it returns beside it still reads
**4.0**. The module's only guard cannot fire: with `c < 0`, `beta < 0`, so
`q = 1/dtau − beta/2 = 73.38 > 0`. The one case that *is* refused is caught only incidentally,
by the coarse-grid guard aimed at something else (a descending grid makes `dtau` negative).
**Zero is the maximally unsafe direction**: `‖A_far‖` enters a Newton–Kantorovich budget in the
numerator, so zero makes any budget look free.

**G3 — FABRICATED COEFFICIENTS AT NEGATIVE α.** `cos_power_coeffs` returns `a_0` with the
**wrong sign** in **4 of 5** negative-α probes against the reflection-formula oracle (magnitudes
agree to 1e-10; only the sign is lost), contradicting its own docstring's *"no Gamma of a
negative argument is ever formed"*. Worse: for `α ≤ −1` the profile is not integrable, so **no
coefficient sequence exists** — and a finite array comes back anyway, with `|a_K|` **growing**
`10.0×` (α = −1.5) and `1000.0×` (α = −2.5) from `K = 100` to `K = 10000`, and the evaluated
series moving *away* from the function it claims to be (error `47.6×` / `3310.5×`). This is not
a truncation error a larger `K` repairs; it gets worse. **Sharp boundary, both sides checked:**
`α = −1` and `α = −2` **raise** (Γ poles), and on `−1 < α < 0` the expansion is legitimate and
the module is **correct**, max relative error **1.05e-3** against a Γ-free midpoint quadrature.
The refusal pattern exists **one function away in the same file** — `cos_power_mass` refuses
`α ≤ 1`, and leg 116 banked that refusal as a virtue (lesson 73).

**G4 — THE NEGATIVE NORM.** `farfield_inverse_norm_finite` returns **−3999996.0** for
`X0 > Xmax`, on **4/4** alphas, where the clean value is `3.999996`. A quantity that is a norm
by construction comes back negative. `X0 < 0` *does* raise — the module refuses the obviously
broken input and accepts the subtler one.

**G5 — THE ALGEBRA CONSTANT ABSORBS POISON.** `+Inf` at mode 1, `−Inf` at mode 1, and a wholly
sign-flipped weight vector all return `S` **bit-identically** to the clean call
(**385.9411764705883**, 0 ULP, no warning, no Inf, no NaN) — 3 of 6 poisoned vectors, the
leg-115 signature. An `Inf` that *does* register moves `S` **down**, to 273.0667 (**0.7075×**).
A `v` sized to `len(u)` instead of `2(len(u)−1)` under-reports by **5.558×** — with no length
check, while `quadratic_coeffs` emits `2K` modes by default. **Every direction is the unsafe
one**, and the bracket `S/4 ≤ M ≤ S/2`, documented as sharp, is reported unchanged in all of
them.
