## The second defect, which is not the same defect

The pointer check ran **two** predicates: the ledger's own line shape (STRICT) and a
deliberately looser one (LOOSE) that **can** return a different answer — lesson 90's test for
whether a control is a control at all. **It did, on exactly one leg of the 15: leg 58.**

Following that single disagreement instead of tightening the regex until it vanished produced
check **A3b**. `experiments/JOURNAL.md:2830` still reads:

> Legs 58, 59, 61, 62, 63 and 71 have branch progress but no answered gate, so they are
> deliberately absent from this block.

Of the **6** legs named, **5 (58, 59, 61, 62, 71)** have since answered a gate and landed;
only **1 (63)** remains accurate. So the ledger does not merely omit — **one sentence in it
now asserts something false about 5 legs**. Leg 58 is the worst case: its gate answered
**YES** — the `NG` theorem on the class `A21 = 0`, the most consequential gate in this window
— and the only thing `JOURNAL.md` currently says about leg 58 is that it has no answered gate.

**A missing pointer and a wrong pointer are two defects, not one** (lesson 75), and they take
different remedies — 15 **additions** versus 1 **correction**. They are reported separately
and deliberately not summed.
