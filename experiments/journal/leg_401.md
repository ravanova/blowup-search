## §2. THE REALIZATION (lesson 91, part 1 of 3)

**Object.** A **backward `λ`-discretely-self-similar blow-up profile of the 3-D incompressible
Navier–Stokes equations on `R³`**, `λ = 1.7`, similarity constant `a = −λ λ_t = 0.5`, similarity
period `T_s = 2 log λ`, unit viscosity, **no forcing**, **non-axisymmetric admitted** (all azimuthal
orders `|m| ≤ l` are carried, and `m ≠ 0` modes are free). `λ`, `a` and the period are taken from the
banked leg-381/`L5` realization (`experiments/p2_route_l5_v1.py` constants `LAMBDA = 1.7`,
`A_MOD = 0.5`, `PERIOD = 2 log LAMBDA`) so that this unit's object is **the same object** the two
existing route-4 bills were charged against.

**Route 4's profile system, in `L5`'s own notation** (`p2_route_l5_finite_energy_v1.json`
`.ansatz.profile_system`):

    R[V] = V_s + a (V + y·∇V) − ΔV + V·∇V + ∇P = 0,     div V = 0,     V(·, s + T_s) = V(·, s).

**Pressure-free (vorticity) form — this is what the load-bearing norm measures.** With `ω = curl V`,

    W[V] := curl R[V] = ω_s + a(2ω + y·∇ω) − Δω + (V·∇)ω − (ω·∇)V,

using `curl(a(V + y·∇V)) = a(2ω + y·∇ω)`, `curl(V·∇V) = curl(ω×V) = (V·∇)ω − (ω·∇)V` for
`div V = div ω = 0`, and `curl ∇P ≡ 0`. **No pressure, no Leray projector, no operator-norm constant
enters the measured number.** This is exactly `L5`'s load-bearing construction
(`leg_400.md` §3.1) applied to a field that is being *solved for* rather than posited.

## §3. THE TRIAL SPACE AND BASIS (lesson 91, parts 2 and 3 of 3)

### §3.1 Divergence-free by construction — Chandrasekhar poloidal–toroidal representation

    V = ∇×∇×(f y) + ∇×(g y) =: P[f] + T[g]

with `y` the position vector. `div V ≡ 0` **identically and exactly** — not to a tolerance, not by a
projection, not by a Bogovskii corrector (leg 381 measured the Bogovskii corrector *growing*, so this
unit takes a representation that never needs one). This representation is complete for solenoidal
fields on `R³` decaying at infinity.

In vector spherical harmonics `(Y_lm ê_r, Ψ_lm := ∇_S Y_lm, Φ_lm := ê_r × ∇_S Y_lm)`, with
`f = Σ F_lm(r,s) Y_lm`, `g = Σ Q_lm(r,s) Y_lm`:

    V = Σ [ l(l+1) F_lm / r ] Y_lm ê_r + [ (F_lm + r F'_lm)/r ] Ψ_lm − Q_lm Φ_lm
    ω = curl V = P[g] + T[−Δf]      (poloidal scalar of ω is Q_lm, toroidal scalar is −(Δf)_lm)

`l = 0` carries no solenoidal content and is excluded. `curl` and `Δ` act **exactly** on the radial
scalars in this basis, so `ω`, `Δω`, `y·∇ω = r ∂_r ω` (the vector-harmonic basis vectors are
`r`-independent, so `y·∇` acts on radial coefficients alone) are computed **without any finite
difference**. Only the two nonlinear terms are formed on a grid, and they need **first** derivatives
only.

### §3.2 The basis

- **Angular:** real spherical harmonics `Y_lm`, `1 ≤ l ≤ L_max`, `|m| ≤ l`.
- **Radial:** the algebraic map `u = r/(r + L_map) ∈ [0,1)`, `L_map = 2.0` (control run at
  `L_map = 4.0`), with Chebyshev polynomials `T_n(2u−1)`, `0 ≤ n < N_r`, carrying prefactors that
  impose the correct behaviour at both ends:
    - poloidal: `F_lm(r) = u^l · Σ_n a^F_{lmn} T_n(2u−1)`  — gives `F ~ r^l` at `0`, `F → const` at
      `∞`, hence `V ~ r^{−1}` far field, i.e. **the trial space contains the pinned exponent
      `α = 1` and is not rigged against it**;
    - toroidal: `Q_lm(r) = u^l (1−u) · Σ_n a^Q_{lmn} T_n(2u−1)` — `Q ~ r^l` at `0`, `Q ~ r^{−1}` at
      `∞`.
  Faster decay is reachable inside the same space (it is the subspace on which the leading
  coefficient combination vanishes), so **both `α = 1` and `α > 1` are representable**.
- **`s`:** real Fourier series on one DSS period, modes `k = 0 … K_s` (`cos`, `sin`), period
  `T_s = 2 log λ`. **DSS periodicity is exact by construction.** `K_s = 0` is exactly self-similar
  and is used as the reading-(c-1) control, not as a candidate.

**Degrees of freedom:** `n_dof = 2 · Σ_{l=1}^{L_max}(2l+1) · N_r · (2K_s+1)`.

### §3.3 Quadrature (the discretisation, stated separately from the basis)

- radial: Gauss–Legendre in `u ∈ [0,1]`, `n_q_r = 3 N_r + 12` nodes, so `r` runs over **all of
  `[0,∞)`** with no artificial outer boundary;
- angular: Gauss–Legendre in `cos θ` with `n_θ = 2L_max + 8`, uniform in `φ` with `n_φ = 4L_max + 12`;
- `s`: uniform trapezoid with `n_s = 4K_s + 6` nodes on one period (spectrally accurate, periodic).

### §3.4 The normalisation that forbids `V ≡ 0` — fixed now, two branches, both pre-registered

`V ≡ 0` solves the system exactly. A residual minimisation without a nontriviality constraint is
void. Two branches are run, and **both** are reported:

- **BRANCH A — free far field.** Constraint `N_A(V) := (1/T_s) ∫₀^{T_s} ∫_{R³} |V|² e^{−|y|²/4} dy
  ds = 1`. The Gaussian weight is the standard similarity-variable weight; it is finite on the
  `α = 1` class and on every faster-decaying class, so **the branch does not pre-select a decay
  rate**. Imposed by the exact rescaling `c ↦ c / N_A(c)^{1/2}` (`N_A` is homogeneous of degree 2 in
  the coefficients), so the constrained problem is solved as an unconstrained one with no multiplier
  and no penalty.
- **BRANCH B — pinned far field, `α = 1` imposed.** Constraint
  `N_B(V) := (1/T_s) ∫₀^{T_s} Σ_{lm} F_lm(∞,s)² ds = 1`, i.e. the `α = 1` angular amplitude is held
  at unit size. **This is the class the Chae–Wolf pin says any nontrivial backward `λ`-DSS blow-up
  profile must lie in**, so branch B prices route 4's actual object class and branch A is the
  control that shows what the minimiser does when it is allowed to leave it.

### §3.5 Predicted mechanisms — written down BEFORE any run so the outcome cannot be narrated afterwards

1. On the pinned class `V ~ r^{−1}`, `ω ~ r^{−2}`, so the transport term `a(2ω + y·∇ω)` **vanishes
   identically in the far field** when `ω` is exactly `(−2)`-homogeneous, `Δω ~ r^{−4}` and the
   nonlinear terms `~ r^{−4}` are both `L^{3/2}`-integrable at infinity, **but `ω_s ~ r^{−2}` is
   not**: `∫^∞ |ω_s|^{3/2} r² dr` is logarithmically divergent unless the far-field angular amplitude
   is `s`-independent. **Prediction: route 4's own closure norm is log-divergent on its own pinned
   object class unless the profile is asymptotically exactly self-similar.** This is the same
   obstruction `L5` isolated as `T3 ∝ ṁ` and leg 381 measured as a non-decaying critical tail; if it
   reappears here it reappears on a *solved-for* field rather than a stand-in.
2. Consequently branch A's minimiser is expected to **kill the `α = 1` tail** (drive `F_lm(∞) → 0`),
   buying a finite residual at the price of leaving the pinned class. **That is not a solution of
   route 4 and will not be reported as one**; the far-field exponent of the minimiser is measured and
   reported next to the pin.
3. Branch B is expected to show the log-divergence directly, as **growth of the measured norm under
   radial-quadrature refinement and under domain truncation `r < R`**.

Each prediction is recorded so that a *failure* of the prediction is as reportable as a success.

### §5.1 THE DECISION RULE — fixed before any number exists

Let `ρ_j` be the best residual at joint rung `J_j`, `n_j` the dof count.

- **YES (decreases under refinement)** iff `ρ` is strictly decreasing over the **last three rungs
  reached** *and* the relative decrease per rung exceeds **5 %** *and* the least-squares slope of
  `log ρ` against `log n_dof` over those rungs is `< −0.05`.
- **NO (stalls or grows)** otherwise. A `NO` reports the measured slope anyway — a stall is
  `slope ≈ 0`, growth is `slope > 0` — and per reading (b) **is not softened**.
- **The rate** is that least-squares slope, reported as `d log ρ / d log n_dof`, together with the
  per-axis slopes and the per-rung relative changes.
- If a rung cannot be reached in the wall-clock available, reading (d) fires: the answer is
  `UNDER-RESOURCED` **with** the rung reached, its wall-clock, and the rung the answer needs.

## §7. EXECUTION RECORD — apparatus only. Written before any gate number existed.

Insert-only. Nothing in §§0–6 is touched. This section records what had to be built and what
went wrong building it. It contains **no result numbers**; the residuals are §8.

### §7.1 The residual evaluation had to be made ~3× faster before the ladder was affordable

The first working implementation cost ≈ 1.98 s per objective-plus-exact-gradient at the top
rung `J4` (`n_dof = 6720`). Profiling showed the cost was **not** floating-point work — the
whole evaluation is a few hundred MFLOP — but **memory traffic on rank-5 arrays** of shape
`(n_q_r, n_s, n_P, 3, 3)`, 42 MB each at `J4`.

Three changes, each verified to leave all six self-tests **unchanged to the digit**:

1. Two-operand contractions routed through `matmul` with the transposed constant cached.
2. Field layout changed from `(radial, angular, s, component)` to `(radial, s, angular,
   component)`, so every large contraction is already in `matmul` layout and no rank-4 or
   rank-5 array is ever transposed or copied; and the radial part of `(B·∇)A` contracted
   analytically, which removes the rank-5 **gradient** tensors entirely.
3. The three-term vector-spherical-harmonic synthesis fused into **one** `matmul` over
   stacked components (`concat0`), and the two remaining rank-5 contractions fused into a
   single `einsum` pass with no temporary in either direction (`matvec_last`).

Measured objective+gradient, one process: `J0` 0.326 → **0.106 s**, `J2` 0.690 → **0.280 s**,
`J4` 1.432 → **0.783 s**.

### §7.2 Process parallelism across starts buys much less than it looks like it should

Measured aggregate throughput (`experiments/_l6_scaling.py`), evaluations per second:

| rung | 1 proc | 2 | 3 | 6 |
|---|---|---|---|---|
| `J0` | **5.20** | 3.59 | 3.81 | 4.21 |
| `J2` | 1.70 | 2.33 | 2.98 | **3.13** |
| `J4` | 1.31 | 1.69 | 1.74 | **2.35** |

At the smallest rung six processes are **slower in aggregate than one**; at the top rung they
buy 1.9×. This is the same memory-bandwidth ceiling as §7.1. The driver therefore selects the
process count per rung from this measurement rather than assuming linear scaling. **This is
why the wall-clock cost in the artefact's `cost_and_shortfall` block is what it is**, and it is
recorded so the cost is a measurement and not an excuse.

### §7.3 A FALSE CONVERGENCE, found by probing and fixed

**This is the most important thing in this section.** The objective is invariant under
`c ↦ t c`, because the normalisation of §3 is applied *inside* the tape. Hence `∇J ⊥ c` and
`‖∇J‖` falls like `1/‖c‖`. L-BFGS-B's stopping test is on `‖proj ∇J‖_∞`. So once the iterate
drifts outward, **the stopping test fires while the objective is still falling.**

Measured, rung `J0`, branch `B`, seed 401: L-BFGS-B returned
`CONVERGENCE: NORM OF PROJECTED GRADIENT <= PGTOL` at iteration **1041** with
`|g|_∞ = 6.85e−13`, at which point `J` was still dropping **2.7 % per 25 iterations** and the
coefficient vector had grown to `‖c‖ ≈ 185`. Continuing past that point took the same start
from `J = 3.7734727962` to `J = 1.4447691808` — **a factor 2.6**.

Had this not been caught, **every residual in this leg would have been ~2.6× too large, and
the refinement comparison the gate asks for would have been measuring L-BFGS-B's stopping
test rather than the construction.**

The fix changes neither the objective nor the minimiser: on each stop the iterate is rescaled
onto the normalisation surface — which changes no function value, the objective being
scale-invariant — and the solver restarts with the remaining budget, until a restart buys less
than `1e−10` relative improvement. This makes L-BFGS-B *honour* its own pre-registered `gtol`
and `ftol` instead of stopping spuriously; it is a defect repair, not a change to the §5
protocol.

`scale_invariant_grad = ‖c‖·‖∇J‖ / |J|` is recorded from here on. **`|g|_∞` alone is not a
convergence measure for this parametrisation** and is not read as one anywhere in this leg.

### §7.4 Why the minimisation is slow, and what was NOT done about it

The load-bearing norm's integrand is `|W|^{3/2}`, whose gradient is **Hölder-1/2, not
Lipschitz, where `W` vanishes**. That is a fact about route 4's own closure norm, not about
the discretisation, and it is why a quasi-Newton method crawls on it.

An `ε`-smoothing homotopy on `(|W|² + ε)^{3/4}` was implemented and **tested against plain
L-BFGS-B on an equal 1200-iteration budget** at `J0`/`B`: homotopy reached `J = 2.7274006160`,
plain reached `J = 3.7734727962`. A 1.4× gain — judged **not worth deviating from the
pre-registered start protocol of §5**, and therefore **not used in the production run**. The
`eps` argument survives in the code with default `EPS_FLOOR = 1e−300`, i.e. the load-bearing
norm itself. **Every number reported by this leg is evaluated at that default.**

### §7.5 Three defects the evidence script caught before any result existed

`experiments/p2_route_l6_v1_evidence.py` was written and run against a throw-away low-iteration
artefact *before* the production run. It failed three of its own checks. All three were real:

- **C18** — the banked coefficients did **not** reproduce the banked residual (73.089 against
  69.721). Cause: `objective` rescales `c ↦ c/√N(c)` inside the tape, so the residual it
  reports belongs to the *normalised* field, while the *raw* iterate was being banked. The
  normalised field is banked now and C18 agrees to every digit.
- **C20** — the banked field samples were `NaN` on the polar axis, a coordinate singularity of
  the vector spherical harmonics (`Ψ`, `Φ` involve `∂_φ Y / sin θ`) and not of the field; and
  the check was silently swallowing the `NaN`, because `max(0.0, nan)` returns `0.0`. Sample
  directions now avoid the axis and finiteness is asserted in both the writer and the checker.
  The quadrature never touches the axis: Gauss–Legendre nodes in `cos θ` are interior.
- **C11** — the norm check demanded character equality with `L5`'s string, and `L5` writes the
  integrand as `curl_y R_loc` where this leg writes `curl_y R[V]`. The artefact now carries
  `L5`'s string **verbatim**, read from the banked JSON and never retyped, and the check
  requires that.

**Lesson 68 earned its keep here**: the script's whole value was that it failed.
