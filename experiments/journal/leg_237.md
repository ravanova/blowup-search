## 1. Why this is a class and not an instance

Leg 202 (Route-PNA) mechanism M2 established the shape on `profile_newton.py`: `relres` is
exactly scale-invariant, `converged` is computed from the residual history alone and never
consults the gauge rows, and the two gauge rows are 2 rows against `n` in an **overdetermined
least-squares** solve, so they are *tradeable*. The consequence there was a returned wave
speed of **−306421** against a true **0.49797** with `converged=True`.

The class question is whether any other module is built the same way. Answered by reading the
expression that produces each boolean — not by grepping for the presence of a ratio, which
would have produced false positives on at least four modules that turn out to be fine.

Three criteria, all three required for a hit:

| | criterion |
|---|---|
| **C1** | the boolean verdict is a function of a scale-invariant quantity only |
| **C2** | no absolute-scale companion enters the **same** boolean |
| **C3** | the equation admits a scaling degeneracy, so an escaped member exists to be confused with the physical one |

**C3 was not pre-committed — it was discovered mid-pass**, and the novelty note says so
rather than presenting it as foresight. It was forced by
`spectral_certificate.tail_norm_ladder`, which satisfies C1 and C2 (its verdict is read off
an increment *ratio*, alone) and is nonetheless **not** the defect: the property under test is
membership of `h` in `l¹_w`, which is *itself* exactly invariant under `h -> λh`, so every
member of the family has the same true answer and there is no wrong number to hide. A census
without C3 would have reported that as a second hit and been wrong.

## 3. The hit, verified by construction

**G1 — the blindness, measured.** Feeding `(λΩ*, λc*)` to the module's own verdict
expression, across λ ∈ {1, 2, 10, 1000, 0.001}:

| quantity | behaviour across λ |
|---|---|
| `rel` (the verdict quantity) | spread **8.725e-14** — constant |
| `c` (the reported wave speed) | spans **1.000e+06 ×** |
| absolute residual rms | spans **1.128e+12 ×** |

The verdict quantity is flat to 14 digits while the number the module exists to report moves
six orders of magnitude. This is C1, measured rather than argued. The algebra behind it:
`R = Ω·H(Ω) − c·Ω_X − a·U·Ω_X` is homogeneous of degree 2, and the denominator `Ω·H(Ω)` is
also degree 2, so the ratio is invariant **exactly**, not approximately.

**G2 — a broken-gauge member the verdict calls converged.** `(λΩ*, λc*)` is an exact zero of
all J residual rows for every λ. Fed to the verdict expression:

| λ | verdict | `rel` | reported `c` | gauge defect |
|---|---|---|---|---|
| 1 | True | 9.010e-14 | +0.4960884 | 3.3e-16 |
| 2 | True | 9.010e-14 | +0.9921767 | **1.000** |
| 10 | True | 1.694e-13 | +4.960884 | **9.000** |
| 1000 | True | 1.774e-13 | +496.0884 | **999.0** |

**3 of 4 are members whose gauges are violated by up to 999 and whose reported wave speed is
wrong by 1000×, and the verdict expression returns `True` on every one**, at a `rel` that is
*better* than nothing and indistinguishable from the reference's 9.010e-14. C1 and C2 are
established.

**G3 — the control, in the same module.** `newton_gauged` answers
`converged = converged_kept AND full_ok`, where `converged_kept = (kept_sup < 1e-11)` is an
**absolute** sup test — leg 150's repair. On the same three small-amplitude inputs it returns
`converged=False` **3/3**, with `kept_sup` at 1.09e-13/1.11e-13/5.72e-14 and an explicit
`reason` naming the full-residual `relres` of 36.70/37.42/41.29. The absolute companion is
exactly what does the work. This is the strongest evidence that the hit is a real gap and not
a stylistic preference: **the fix already exists, one method away, in the same class.**

## 4. The reachability negative, and why it is the honest headline

Leg 202's journal records that it *got this question wrong once* — an intermediate reading
held that gauge blindness was "structural but unreachable at the default budget", and the
runner's own `reading` field says so, because the small-amplitude route *did* reach it. So
this leg owed the same question a real answer rather than an analogy.

**It does not reach here. 0 escapes in 41 cases.** Among the 17 that converged, the worst
gauge defect is **8.882e-16** and the worst relative error in `c` is **1.175e-14** — every one
is the gauged member to machine precision. The a-ladder through `continuation` at J = 60
produces `converged=False` at **all 5** of a > 0, with honest `relres` of 5.67e-07 … 4.17e-03;
leg 202 M1's rescue-clause walk-off does **not** reproduce.

**G3b, the calibration, is what makes this a contrast rather than a null.** The same
small-amplitude route run against the known positive at this leg's own resolution reproduces
leg 202's banked M2 table to the digit:

| ε | `converged` | reported `c` | true `c` | gauge defect |
|---|---|---|---|---|
| 1e-8 | **True** | **−6127.935** | 0.49797 | 0.250 |
| 1e-10 | **True** | **−306421.259** | 0.49797 | 0.250 |

(leg 202 banked −6127.94 and −306421.26.) **Same route, same class of defect: 2/2 escapes on
`profile_newton`, 0/41 on `collocation_newton`.**

**Why the difference, stated as mechanism and not as luck.** In `profile_newton` the two
gauges are values at two *nodes* (`Ω(0) = −1`, `Ω(X≈1) = −1/2`); in `ACollocation.newton`
gauge 1 is `Ω(θ=0)`, a **spectral** evaluation `g0 @ om` that couples *every* coefficient, and
θ=0 is not a node. The dense gauge row is a stronger constraint in the least-squares trade,
and Gauss-Newton restores the member in **3 iterations** from a λ=10 start (the E-route budget
sweep: `converged=False` at max_iter 1 and 2, `True` and on-gauge from 3 on).

**Latent is not absent.** The guard is the *iteration's* behaviour, not the *test*. Nothing in
the module enforces it, no test pins it, and it would be silently lost by any change to the
gauge rows, the damping, or the lstsq conditioning — none of which currently has a reason to
preserve a property nobody has written down. That is the finding.

## 5. Claim adjacency — measured from the tree, not asserted

The escalation rule turns on this, so it was enumerated by `git grep` rather than judged:
**14 call sites** of the two hit functions outside `solver/`; **13 are in adversarial audit,
repair, or `test_*` files**; the 14th is a line of prose in `writeup/novelty/leg_114.md`.
**0 are in claim-bearing experiment runners.** Verdict `NOT_CLAIM_ADJACENT`.

The load-bearing fact behind it: **Route-D's real consumers call the sibling.**
`test_collocation_newton.py`, `experiments/p2_route_d_v12_defect.py` and
`p2_route_d_v13_turning.py` all call `newton_gauged` — the one carrying leg 150's absolute
companion — not `newton`. `test_collocation_newton_adversarial.py:282` even calls `newton`
under the comment *"the sibling, unchanged"*, which is the repair legs recording in passing
that they knew this function was the one they were not touching.

**So the census's real content is about coverage, not mathematics.** Leg 114 found the defect
class next door; leg 150 repaired it thoroughly, with 3570 bitwise-identical clean-input
comparisons; and the repair landed on `newton_gauged` and stopped at the method boundary. The
sibling kept the shape. Nothing was hidden — it was simply never in scope.

## 6. What came back CLEAN, at equal weight

Frozen in the census table before the numerics, so these are results, not omissions.

* **`newton_gauged`** — absolute sup companion, plus `relres_has_referent` refusing to
  fabricate a denominator from an identically-zero source scale (leg 150). Not a hit.
* **`gclm_rescaled.run`** — scale-invariant **by design** (leg 85's Route-GRA repair), and
  the decisive reason it is not the defect is *not* the returned `gauge`/`tol_effective`
  fields but that its claim quantity is the **rate** `c_omega`, itself invariant under the
  same λ family. There is no wrong number for the blindness to hide.
* **`marginal_flow`** — a residual-over-floor ratio, but ANDed with an absolute finiteness
  test and an absolute state-growth cap whose calibration (246× headroom above the largest
  legitimate trajectory, 141× below the nearest true positive) is written at the site.
* **`nk_seminorm`, `interval_certificate.KawaharaProblem.newton`** — the relative-with-floor
  expression is the loop's **stop**, not the verdict; and `max(1.0, T)` makes it absolute
  below 1 anyway.
* **`port_certification.gmres`** — the explicit **anti-instance**, banked as such: its own
  docstring pre-empts this defect at line 121, *"Reported as a MAGNITUDE (the relative
  residual), never as converged/not (lesson 58)"*. A scale-invariant quantity never turned
  into a boolean cannot be a sole convergence test.
* **The radii-polynomial `closes`** family (`nk_bounds`, `nk_fourier`,
  `interval_certificate`) — `Z1` is dimensionless but `Y_0` is a **norm** and carries absolute
  scale into the discriminant, so the test is not scale-invariant.
* **`dissipative_profile`** — carries *both* degeneracies, pins them with `c_omega` and an
  explicit returned `scale_gauge`, stops on an absolute rms, and manufactures no boolean.
* **`hl_rescaled`, `boussinesq_rescaled`, `bordered_hl`, `weight_search`, `first_integral`,
  `finite_support`, `rescaled_spectrum`, `viscous_novelty`** — all absolute sup/rms tests;
  the two rescaled integrators additionally renormalise amplitude every step, which is the
  absolute-scale companion made structural.

## 7. What this does and does not buy

It **narrows** concern about recurrence: the defect class is not endemic. One other function
carries it, its consumers do not use it, and its sibling in the same class already shows the
one-line fix. It **does not eliminate** the concern — the census covers `solver/` verdict
sites only, and the one hit is held clean by an unwritten property of the iteration rather
than by any test.

**No link of the L1→L4 chain moved. Clay stays ~0.05%.** This is an audit leg; it produces no
bound and no physics.

**Recommendation to the DM, not acted on here:** if leg 226 lands an absolute-scale companion
on `profile_newton`, the same shape applies verbatim to `ACollocation.newton`, and the JSON
names the exact expression (`converged_kept`-style absolute sup on the gauge rows, ANDed with
the existing `rel < 1e-9`). Cost is one line; the leg-150 precedent shows how to prove it
moves no clean-input float.
