## The object, and why it is tractable at all

At `a = 0` the exact CLM profile is `Ω(y) = −y/(y² + ¼)`. On the upper-half-plane Hardy space
the Hilbert transform acts as `−i`, and Xu's **single-simple-pole identity**
`HΩ − iΩ = i/(y + i/2)` collapses the **nonlocal** linearization to a **scalar first-order**
operator (Xu eq. 4.21), with `b(y) = y + i/2`:

```
    L₀⁺ = −1 − y d/dy + i/b
```

`X` is the odd part of `H²(ℝ)` with the equivalent norm `‖φ‖²_X = ‖φ‖²_L² + ‖φ''‖²_L²`, and
`‖φ‖²_X = 2‖P₊φ‖²_{X₊}`, so every operator-norm statement transfers from the Hardy block to
`X` **with constant 1**.

### The bordered formulation, written down explicitly

This is what DIRECTION.md asked for as "a bordered operator formulation compatible with Xu's
own realization", and it is fully explicit rather than gestured at. At `z = 0` the **only**
singular object in Xu's kernel is `c₁ = G'(0)/z`, and `G'(0) = (b²f)'(0)` is a **rank-one
functional** of `f`. So:

```
    [ L₀⁺   m ] [ u ]   [ f ]        m(y) = y b(y)⁻²            (the z = 0 null mode, G3)
    [ ℓ     0 ] [ κ ] = [ 0 ]        ℓ(f)  = i f(0) − f'(0)/4    (= G'(0), the only z = 0 pole)
```

One border column and one matching row **per Hardy block**; rank two on the real odd space.
That is the same shape stage TC already assembled in `ℓ¹_w` — a border column, its own
amplitude, and a matching condition. `ℓ(f)` after projection onto the solvability subspace is
**exactly 0.0** in all three test cases.

## A floating-point catch that was real, and is kept (lessons 76 and 86)

The first working draft formed `G₂(t) = G(t) − G(0) − G'(0)t` by literal subtraction. `G₂` is
`O(t²)` while `G(0)` is `O(1)`, so for small `t` that is a difference of nearly equal floats —
and the resolvent integrand then multiplies the resulting noise by `s^{z−2}`, which is `1e+14`
at `s = 1e−6`, `z = −0.4`.

**The tell was not the size, it was the disagreement.** At the SAME `z = −0.4`, the
`simple_pole` datum reported a relative residual of **9.216e−06** and the `mixed` datum
reported **1.0001e+09**. Fifteen orders of magnitude between two data on one identity is a
floating-point statement, not a mathematical one. The repair builds `G₂` from its own Taylor
coefficients (`G(t) = (−¼ + it + t²)P(t)`, `G₂ = Σ_{m≥2} g_m t^m`, nothing subtracted), and the
same case now reads **1.418e−14** — an improvement of **7.05e+22×**. Both numbers are banked in
the JSON. A second, independent quadrature defect was caught the same way: a single power panel
across the whole `s`-interval cannot see both the origin-Taylor regime and the `log₁₀(y)`
decades beyond `s = 1/y`, and the fix is a two-panel split at `s* = min(1, 1/y)` with **log
grading** on the outer panel. G1's control has the same shape — its integrand carries an
indicator with a jump at `s = 1/y`, and moving the panel boundary onto the jump took it from
**1.391e−05** to **2.122e−14**.

### The sharpest in-repo finding, and it is not about certificates

`capabilities.py`, the `solver/rescaled_spectrum.py` entry, already says it:

> "point spectrum {0,1} at a=0, which XU Theorem 2 later proved — but **in the LOOSE
> realization: our grid imposes NO origin condition (70)**"

Xu §4.6 says what the loose realization actually is: on the maximal `L²` realization **every
point of the open strip `−½ < Re λ < 3/2` is a genuine eigenvalue**, with an explicit odd
eigenfunction `φ_λ = B₊ − S B₊`, confirmed numerically against the full nonlocal `L₀`. So the
strip is `σ_ess` and **there is no `L²` spectral gap at all**. The one feature separating those
modes from the physical ones is the second derivative at the origin: `u_λ'' ∼ y^{−1−λ}`, whose
square integral diverges exactly when `Re λ ≥ −½`, except at `λ ∈ {0,1}` where the singular
coefficient `λ(λ−1)` vanishes. **Requiring `φ'' ∈ L²` near the origin is the whole difference.**

Every numerical object this repository owns for this operator is therefore in the realization
**without** the gap. That is an actionable finding independent of whether a certificate is ever
built, and it is the part of this leg I would most want the user to see.

## The obstruction census — including the one that closes the value, not the viability

* **O1 — the `α^{−3/2}` blow-up.** NOT the `ℓ¹_w` class. Engaged only as `Re z → −½`. The
  certificate sits at `z = 0`, `α = ½`, a distance ½ from the essential line, where
  `α^{−3/2} = 2.8284`. **No severity for a static certificate.**
* **O2 — non-normality: the gap is not a decay rate in the `X` norm.** NOT the `ℓ¹_w` class.
  **No severity for a static invertibility certificate; HIGH severity downstream.** Xu's own
  abstract keeps the semigroup on a *third* space `Y_θ`, origin-stricter than `X`, reached by a
  bounded transfer map. An origin-`H²` certificate would certify **invertibility**, not
  **nonlinear stability** — and nonlinear stability is what `L1` needs.
* **O3 — `a = 0` exactness dependence. FATAL for transfer.** Every usable object above is a
  consequence of `Ω` being the *exact* CLM profile: the single-simple-pole identity, the collapse
  of the nonlocal operator to a scalar first-order ODE on each Hardy block, the closed-form
  kernel, the exact Mellin norm `1/α`. For `a > 0` Xu proves only a **conditional two-line
  inclusion** under his hypothesis `Adm(a)` — no resolvent, no invertibility, no gap.
  `HL_S2_nonsymmetric` is not a CLM profile and inherits none of it. **The corollary must be
  said out loud: a certificate at `a = 0` in origin-`H²` would certify an object Xu already
  inverts in closed form.**
* **O4 — realization coupling for `a > 0`.** Xu §4.6: *"One cannot use the `H²` metric to empty
  the strip and the `L²` metric to close the origin channel."* The origin-regularity index and
  the positions of the essential lines are **coupled**; a stronger `H³` realization shifts the
  origin line off, and for `a > 0` the two-line picture is relative to the choice of
  realization. At `a = 0` the two lines coincide — which is why the picture is clean there, and
  only there.
* **O5 — the `ℓ¹_w` class obstruction itself. Checked for, and it DOES NOT RECUR.** See the
  contrast table above.

## What the escalation actually asks the user

**Not** "we can now certify something new." The honest statement is three-part:

1. This repository's ~70-leg obstruction is now positively identified as a property of the
   **chosen realization**, not of the operator — leg 127 proved the `ℓ¹_w` half, and this leg
   re-derived the origin-`H²` half from primary source (G1–G4, worst residual 2.8e−14).
2. A certificate formulation on origin-`H²` is **structurally viable**, with the split, the
   shape and the bordered rows all explicit — but at `a = 0` it would re-derive a closed form,
   and O3 says none of it transfers to the actual target.
3. The transferable thing is the **realization discipline**, not the certificate: enforce the
   origin condition in the discretization. Right now this repository's grid does not, and per
   Xu §4.6 that is the realization with no spectral gap.

Whether that is worth a construction leg is the user's call, not this leg's.
