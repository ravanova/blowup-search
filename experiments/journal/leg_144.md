## 1. Why this module, and what the stakes are

`solver/energy_coercivity.py` is the instrument behind leg 111's headline — every admissible
weight's coercivity gap converges to `-(3-γ)/2`, damping at the origin needs `γ > 3`, the space
exists only for `γ < 3`, **the window has zero width** — which leg 141/WEL is scoping for
publication. It has **exactly one commit** (`41f4ac0`, leg 111) and has never been modified.
The repo carries **23** `test_*_adversarial.py` batteries and **none** was for it; its only test
was `test_energy_coercivity.py` (14 gates), and every input in that file is legal and in-domain.
Four call sites, two of them the legs whose conclusions rest on it.

## 2. The six sites, with magnitudes

**A — `coercivity_gap` never consults `admissibility`, and the number it returns beyond the
admissibility edge is not a measurement.** `γ = 4` has a measured admissibility ratio of
**1.678e7** with divergence shape `increment_ratio = 4096` (a power, not a log). Called at
`n = 48` it nevertheless returns `-3.346922`, finite, **0 warnings, no error**. That value:

* **violates the module's own nested-subspace invariant.** The trial spaces are nested, so the
  Rayleigh sup must be non-increasing in `n` (`test_energy_coercivity.py` gate 13 asserts
  exactly this — at `γ = 2` only). The `γ = 4` ladder over `n = 8…256` **increases by
  +2.774108** at `n = 128`. All six other members are non-increasing.
* **moves 128.35 across the quadrature dial** (`n_grade = 8…96` at `n = 64`:
  `+0.500615 → +0.500622 → -3.097463 → -73.857519 → -127.853732`), where the `γ = 2` control
  moves **1.3e-15**. The `order` dial moves it too (`-3.982, -3.347, -5.009` over
  `order = 6/12/20`; the `γ = 2` control is stable to 6e-16).
* **breaks the module's own published tripwire in the other direction**: at `n_grade = 8..16`
  it returns `+0.500622`, which **exceeds** `KNOWN_ANSWER_CEILING = 0.5` (Xu arXiv:2607.19762)
  by `+6.216e-4` — the module's header calls a value above `1/2` "an instrument bug, not a
  result", but the check lives in the *driver*, not in the function.

**A2 — and it is not reproducible across builds.** Re-running leg 111's exact calls with exact
defaults: **6 of 7** named weights reproduce its banked JSON to **≤ 6.8e-14** absolute
(`A0_flat`, `A1`, `A2`, `A3`, `B0`, `B2` — bit-for-bit at the top of the ladder).
`A4_chen_hou` differs by up to **1.818 absolute / 142 % relative** (at `n = 64`: `-3.0975` now
vs `-1.2790` banked), with the count of conditioning-dropped directions differing by 1–2
(12 vs 13 at `n = 64`, 111 vs 109 at `n = 256`). It is deterministic *within* this environment
(3/3 identical runs), so this is a LAPACK-build dependence, not noise. **Consequence for leg
141/WEL: the `A4_chen_hou` gap values in `writeup/data/p2_route_we_v1_coercivity.json` must not
be quoted as measurements.** The admissible members are safe and are what the conclusion needs.

**B — the divergence detector reports CONVERGED when its own kwarg is turned down. Highest
stakes of the six.** `admissibility()` is the function that defines the `γ < 3` edge of the
zero-width window. With the default `n_grade = 24`, `γ = 4` reports `ratio = 1.677722e7`,
increments `8.761e14 / 3.589e18`, `increment_ratio = 4096` — a power divergence, loud and
correct. With `n_grade = 0` (or any `n_grade ≤ 0`, both public kwargs) it reports
**`ratio = 1.000000`, `increments = [0, 0]`, `increment_ratio = None`** — which the module's own
docstring (lines 405–413) reads as *"the integral has CONVERGED… a divergence shape has no
referent there"*. **Suppression factor 1.678e7.** The only field still telling the truth is
`exponent_margin = -1.0`, and that is computed from `γ` alone, never measured. `n_grade = 1`
misreports the *shape* instead of the fact (`ratio = 2.000031`, i.e. it looks logarithmic).

**C — `graded_quadrature(grade ≥ 1)` silently returns an ungraded mesh; `grade > 1` leaves the
interval.** At `grade = 1.0` (and `0.0`) the total mass is still **exactly π**, so the module's
own consistency gate (`test_energy_coercivity.py` gate 5) passes, while the innermost node
moves `1.349e-11 → 2.263e-4` — and that alone turns the `γ = 4` divergence ratio from
**1.678e7 into exactly 1.000000**, i.e. site C composes into site B. At `grade = 1.5`,
**290 of 2112** nodes fall outside `(0, π)` (min node `-408.8`, max `+411.9`) and the total
mass is **829.435 = 264 × π**; at `grade = 2.0` it is `823552.8 = 262147 × π`. No warning at any
of these.

**D — `n_unif = 1` doubles the measure of the interval, exactly.** The construction takes
`edges[1:-1]` for the interior panels and then *adds* both end panels, which at `n_unif = 1`
each span the whole interval: every node is counted twice. Total mass **6.283185307 =
2.000000 × π**; the flat-weight Gram diagonal comes back as **3.14159265** instead of
`π/2 = 1.57079633` (ratio exactly 2, which `test_energy_coercivity.py` gate 4 would catch — at
the default `n_unif` only). The propagated gap agrees with the default to **5.9e-7 at `n = 8`**
— exactly where a person would sanity-check it — and is **-11.1011 vs -0.4949 at `n = 32`
(22.4×)**. `n_unif = 0` raises loudly.

**E — `weight_values` is silently even and periodic off `(0, π)`.** `θ = -0.1` returns
`100.08337502`, **bit-identical** to `θ = +0.1` (relative difference exactly 0.0), unwarned:
the square inside `2 sin(θ/2)` erases the branch that defines the domain. Same shape as leg
107's finding in `solver/first_integral.py`, in a different module. Two riders: at `γ = 3` the
same input returns a **negative weight** `-1001.2509` — a "weight" that makes the Gram matrix
indefinite — and at non-integer `γ = 2.5` a **silent NaN** (one numpy warning). `θ = 2π + 0.1`
wraps to the in-domain value to `1.2e-12`. Only `θ` exactly `0` warns (divide-by-zero).
`damping_factor` is likewise finite off-domain (`-1.0 → +0.040`, `4.0 → -1.154`, `7.0 → +0.254`).
This is what makes site C *silent* rather than loud: the off-interval nodes get plausible
weights instead of an error.

**F — a trial space smaller than the modulation saturates the published ceiling.**
`coercivity_gap(3, "A", 2.0)` returns `gap = 0.4999999999999991` from `dim_trial = 1` — that is
`8.9e-16` **below** `KNOWN_ANSWER_CEILING = 0.5`, so the module's instrument-bug tripwire (a
`<=` test) cannot fire, while the converged value at `n = 48` is `-0.497767`. The same shape
appears at `γ = 1` (`+0.2308`) and `γ = 0` (`+7.1e-17`). A positive gap from a one-dimensional
trial space is precisely the shape that would read as "the window is open". `n = 1` and `n = 2`
raise loudly, which is what makes the failure specific rather than general.
