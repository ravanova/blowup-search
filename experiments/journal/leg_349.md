`solver/weight_search.py::six_property_gate()` (lines ~952–1054 on this worktree's checkout):

* **Verdict rule, quoted exactly**: `verdict = "PASS" if all(p["pass"] for p in props.values())
  else "FAIL"` — **all six**, no partial credit. Leg 49's own 4/6 was a NO under this identical
  rule; this leg holds itself to the same standard.
* **P1/P5 (`spread >= 1.0`/`2.0` decades)**: literally the same `spread` value at two thresholds —
  the log10 range of finite fitness across a 32-genome roster (see `props["P5_wide_band"]
  ["band_decades"] = spread`, identical variable to P1's).
* **P2 (`finite_fraction >= 0.90`)**: fraction of the roster whose fitness evaluates to a finite
  number at all.
* **P3 (`violations == 0`, `slope_error <= 0.05`)**: at the fitness engine's own **converged
  state**, a synthetic defect of size `eps` is injected and the fitness response is required to
  fall monotonically and track slope 1 in log-log space, resolved down to `eps = 1e-11` on a
  per-weight window (`defect_ladder()`). This is a smoothness/correctness probe of the fitness
  FUNCTION itself near an optimum, not a probe of anything about the search process that produced
  that optimum.
* **P4 (`spearman >= 0.90`, `top3_overlap >= 2`)**: the SAME 32-genome roster, scored once at
  coarse and once at fine numerical resolution, must rank the genomes almost identically.
* **P6 (`interior_margin >= 0.05`, `wall_gain <= 0.05`, `far_field_power < WALL_POWER`)**: a
  grid-search hill-climb over the 5-gene box must land its optimum away from any box wall, and the
  box-free optimum must not do meaningfully better than the boxed one.

I read this directly off the executing code, per the leg's own instruction, rather than
paraphrasing from memory of what a "fitness-quality gate" generically checks — the specific
mechanics above (spread-as-log10-range, converged-state defect injection, coarse/fine roster
re-ranking, grid-search wall-margin) are all load-bearing in §3 below.

## 3. The mapping, property by property (full reasoning: JSON `six_property_analysis`)

**P1/P5 — spread. FAIL.** There is no natural realization of "did NK converge" that produces a
wide, continuous, log-scaled fitness range. A boolean indicator has no "decades" of spread at all
(a category error against a threshold literally stated in decades). An iteration-count or
terminal-residual realization is defined only on the convergent subset — which P2 (next) argues is
expected to be small and unrepresentative — and even there, Newton's locally quadratic convergence
rate compresses iteration counts into a narrow band once inside a basin, working against the wide
spread the threshold demands.

**P2 — finite fraction. FAIL, and this is the sharpest, most measurement-grounded finding.**
"Finite" for a convergence-outcome fitness means "NK converged." Leg 342 already measured this
exact search space and found **0 of 5** hand-curated, literature-sourced candidate profiles
survive route 4's screen (`experiments/journal/leg_342.md`: "THE SEED SET FOR THE SCREENED OBJECT
IS EMPTY"). A random 32-genome roster with no curation has no basis in this record for beating a
curated 0/5. Independently, leg 334's own plan document states the basin volume for exactly this
shape of guess is **"UNMEASURED, and there is no reason on this record to believe it is
non-empty"** (`TECHNICAL_P2_ROUTEDSSP_V1.md:722–724`). 0.90 is not within reach of anything this
repository currently knows.

**P3 — monotone defect ladder. FAIL, on a type mismatch, reinforced by a well-established fact.**
P3 presupposes a smooth functional near a FIXED converged state that a synthetic defect can probe.
"Did NK converge from this guess" has no such state — the object varied across the roster is the
INITIAL GUESS, and the outcome is a global, discrete result of a multi-step iteration, not a
pointwise-evaluable residual near an optimum. Independently of the mismatch: basin-of-attraction
membership as a function of the starting guess is a standard numerical-analysis fact (the "Newton
fractal" phenomenon) — basin boundaries are generically fractal and everywhere discontinuous, so
arbitrarily small perturbations (down to `eps = 1e-11`, exactly P3's own resolution floor) of a
guess near a basin boundary can flip the outcome discontinuously. This is the opposite of "falls
every step, zero violations, exact slope-1 linearity."

**P4 — resolution-stable ranking. UNMEASURED, weakest finding, does not change the verdict.** This
property tests the thesis's own headline claim ("not fakeable by an under-resolved run") most
directly, and I cannot certify it analytically — it is an empirical question about a discretisation
that does not exist in this repository. What can be said: standard numerical-analysis background
(discretisation sensitivity of Newton-Krylov basins under mesh/spectral refinement, GMRES's own
resolution-dependent behaviour) argues against assuming stability by default, and — more
concretely, as a first-party fact already on record in this repository, not an outside citation —
leg 334's own plan drafts a dedicated brick, **B5 (DSSP-NKBASIN)**, whose entire purpose is to
measure NK-extraction basin behaviour against a KNOWN published 2-D orbit before any 3-D commitment
is made (`TECHNICAL_P2_ROUTEDSSP_V1.md:852–859`). The repository has already recognised, on its own
authority and independent of this leg, that this property is not currently known. Because the gate
requires a measured PASS, not an absence of a measured failure, P4 cannot be banked as passing —
but this is reported honestly as a plausibility argument plus an admitted evidence gap, not a proof
of failure, and it is explicitly not what decides this leg's overall NO (P1/P2/P3/P5/P6 already do).

**P6 — interior, non-wall-pinned optimum. FAIL, on the same type mismatch as P3.** Grid-search
hill-climbing presupposes a continuous surface with a meaningful interior optimum. A
convergence-indicator landscape is a plateau-with-holes: constant "non-convergent" almost
everywhere (P2) with isolated convergent islands whose boundary is fractal (P3) — there is no hill
to climb, and whichever grid cell happens to land inside a convergent island is a sampling
accident, not an optimization result the gate's margin/wall-gain arithmetic was built to score.

Leg 160's own finding is worth naming as a second-order check on this leg's P1/P3 pairing: leg 160
identified a structural tension where fitnesses satisfying P1/P5's nonzero-spread requirement tend
to carry a floor that costs P3's small-eps linearity, and vice versa (`experiments/journal/
leg_160.md`, "P3 is not measuring the fitness"). This leg's finding is a stronger, prior claim —
the NK-convergence predicate fails P1/P5 and P3 for entirely different, non-competing reasons (a
degenerate/undefined range vs. a converged-state type mismatch), so the tension leg 160 measured
between two properties that are both at least DEFINED for its fitnesses does not even get a chance
to bind here; both properties are inapplicable to this predicate's shape before any tension between
them could matter.
