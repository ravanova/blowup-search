## (b) — the three residual paths, characterised

Leg 200's shape is adopted: the mechanism named at source level, a swept magnitude, and **a
control column that could report the other answer**.

### R1 — `leading_order_solve` is sign-blind in `c_l`

`prev = (rhs[i] - a*prev)/denom` sweeps `i` upward with `a = c_l/drho`, i.e. the **backward**
radial difference, unconditionally. For `c_l < 0` the advection is inward and that stencil is
**anti-upwind**, so the routine returns the exact inverse of a matrix its docstring does not
name — finite, correctly shaped, no exception, no flag. Leg 217 repaired the *dtype* defect
in this same function (M3, a one-token cast) and left this, M1's structural twin.

Leg 200's fixture (`nr=16`, `drho=0.1`, `c_diag=-1.2`, seed 3) **reproduced exactly**:

| `c_l` | rel. err vs the **advertised** operator | vs the operator it **assembles** (control) |
|---|---|---|
| +3.0606 (the live constant) | 6.24e-16 | 6.24e-16 |
| +0.5 | 1.59e-16 | 1.59e-16 |
| 0.0 | **0.0** | 0.0 |
| −0.001 | **2.13e-02** | 8.48e-17 |
| **−0.5** | **26.02** | 5.85e-16 |
| −2.5 | 1.94 | 8.22e-16 |
| −3.0606 | 1.83 | 6.43e-16 |

**26.02 at `c_l = −0.5` is leg 200's 26.0, re-derived.** The control column is ≤1.6e-14
across *both* fixtures and every `c_l`: the sweep is arithmetically exact throughout, and all
of the wrongness is in *which* operator. `c_l = 0` carries no radial coupling and is exact in
either direction — the analogue of leg 217's bit-identical `s_rho ≡ 0` branch.

**The magnitude is exponential in the grid, and the curve is not monotone.** The per-row
amplification is `|a/(c_diag − a)| = |a|/(|a| − |c_diag|)`, raised to `nr`. It exceeds 1 only
once `|a| > |c_diag|` and tends to 1 *from above* as `|a| → ∞`, so it **peaks at a marginal
breach**, `|c_l| ≈ drho·|c_diag| ≈ 0.101`, and decays toward both ends — a gross negative
`c_l` is *safer* than a slight one. Banked lesson 88 from the other side, and the same
non-monotonicity leg 200 measured for M1 (worst at `s_rho = −0.4`, not at `−3.0`).

Consequently a magnitude here is meaningless without its grid, so both are given and neither
is borrowed for the other (leg 53's lesson; leg 217 restated it when it split its own residue
table by fixture). At the **live 200-node radial resolution** the same defect at `c_l = −0.5`
is **7.42e+18**, against leg 200's 16-node **26.0** — a factor of 2.9e17 between two honest
reports of one mechanism.

`first, last = rows[0], rows[-1]` — never keyed on `m`. `krylov_ladder` appends in the
caller's `dims` order and never sorts. So reversing `dims` maps the published gain `g → 1/g`
and the work ratio `w → 1/w` on **identical measurements**, with no error, no NaN, no flag.
Leg 217 repaired M4 in these same two lines — the NaN comparison `flat = bool(gain < 2.0)` —
and left this.

### R3 — `pack`/`unpack` validate only the TOTAL size

`pack` is `np.concatenate([np.ravel(o), np.ravel(e), np.ravel(x)])`; `unpack` is three
`reshape(self.shape)` calls. Neither validates a **per-field** shape. A wrong *total* length
is caught — by `reshape`, not by a check.

| fixture | rel. err vs the intended field | clean round trip |
|---|---|---|
| 6×4 (leg 200's own) | **1.3204** | 0.0 |
| **200×48 (the LIVE grid)** | **1.4184** | 0.0 |
| 32×32 (square) | 1.4133 | 0.0 |

**1.3204 is leg 200's 1.32, re-derived.** And a correction to leg 200's note on it: leg 200
recorded *"the transposition survives only because nr·nb is layout-independent"*, which reads
as a squareness caveat. **It is not one.** `nr·nb ≡ nb·nr`, so the live 200×48 grid is
exactly as exposed as a square one — measured above, all three probes SILENT, not argued.
