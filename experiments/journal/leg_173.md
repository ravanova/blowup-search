## The sharpest form of the negative

**Xu's method reaches exactly one operator — the `a = 0` CLM linearization — and reaches
it so completely that no certificate is needed there.** Theorem 2 is closed-form and
unconditional: the whole point spectrum over `ℂ` on the odd realization is `{0, 1}`, via
the explicit family `u_λ = y^{1−λ}/(y + i/2)²`, with no embedded eigenvalues. Every
operator this repository actually targets — `a > 0` gCLM, `HL_S2_nonsymmetric`, Chen's
`γ = 2` dissipative gCLM — lies outside the exactness of the reduction, and **Xu says so
himself** (§8): *"the closed-form scalar reduction of Theorem 2 being exact only at the
single-pole `a = 0` profile."*

So there is **no distance to quantify.** The method is not *far from* the target; off its
anchor it stops being defined. It succeeds precisely where nothing was needed.

## Farthest from usable: gap (2), trace-ideal membership of the kernel

Xu's own three recorded gaps, verbatim (§3.2, restated §7): *"a uniform
large-imaginary-part bound, trace-ideal membership of the kernel, and quadrature-error
bounds in the trace norm"*. Gap (2) is farthest, for three reasons, in order of severity:

1. **It has no subject.** The Evans-determinant strand contains **zero numbered
   equations, zero numbered lemmas and zero numbered propositions.** The paper never
   writes the far-field splitting, the weight, the kernel, or the contour. §3.2 says only
   *"Splitting `L_a` against its far field and forming the associated determinant on a
   weighted space in which the essential line is displaced left of the strip."* You cannot
   verify a trace-ideal hypothesis about an object that has not been defined.
2. **The naive candidate is provably excluded on `X`.** The only nonlocal term a splitting
   could isolate is `Ω Hφ`, and Xu **proves it non-compact, twice**: §3.1, *"the Hilbert
   term `Ω Hφ` is not relatively compact (a coefficient vanishing at both endpoints times
   an order-zero singular integral is not compact)"*; and §4.6, *"the Mellin symbol `m_H`
   of `H` nonvanishing at `ξ = ±∞`, so it is not compact."* Trace class ⊂ compact. The
   weighted space that is supposed to repair this is asserted and never specified.
3. **No external rescue.** Unlike gaps (1) and (3), nothing off the shelf closes it —
   Latushkin–Sukhtayev take trace-class membership as a *hypothesis*, and Bornemann's
   sufficient conditions are all for continuous kernels on a bounded interval.

**Gap (3) is a close second and fails differently, which is the useful part:** its failure
is a *stated, locatable hypothesis mismatch*. Bornemann's Theorem 6.2 is on `[a,b]²`
bounded with the kernel `C^{k−1,1}` (or analytic on a Bernstein ellipse); Xu's kernel is
principal-value Cauchy-singular on `ℝ` — §7 records having to correct *"the principal-value
diagonal of the g-representation Hilbert kernel … to its finite part `−1/(2π)`."* **Gap (3)
IS scopeable; gap (2) is not.** That distinction is the leg's main deliverable.

## What "maturing by orders of magnitude" concretely means: NOT precision

The user's question offered three readings — precision, scope, or infrastructure. Measured:

* **Precision gap: NO.** There is nothing to sharpen. **The Evans strand attaches zero
  real-valued quantities to any of the three gaps** — no trace norm, no quadrature error,
  no imaginary-part threshold. Its entire numerical output is **one integer**,
  `n_disc(a) = 0` for `a ∈ [0, 0.65]`. Xu's own hedges, verbatim: *"This strand is
  exploratory"*; *"it does not enforce these diagnostics as hard gates, and its run outputs
  are not retained"*; *"we report this as exploratory evidence only"*; *"which the code
  computes as diagnostics rather than enforcing as interval bounds."* A precision gap
  presupposes a loose bound. **There is no bound.**
* **Scope gap: YES**, and it has a *named missing lemma*. §8 names it for the `a > 0`
  discrete exclusion: *"a single imaginary-part-independent essential-edge
  (threshold-resonance) estimate."* §4.5 names the missing *framework* for `a > 0`
  exactness and declines to build it — Lockhart–McOwen weighted Fredholm theory, Melrose's
  b-calculus, Lesch's Fuchs-type conormal symbols, Rabinovich–Roch–Silbermann
  limit-operator algebras — *"these frameworks do not compose automatically, and we do not
  carry the argument out here."* **Both named objects belong to T3/T4, not to the Evans
  strand.** The strand the user's framing is about has no named missing lemma at all.
* **Infrastructure gap: YES**, and dominant for the Evans strand. No equations, no public
  code (§7: *"the code is supplied for rerunning"*; Data availability, p. 34: *"available
  from the author upon reasonable request"*), no retained outputs. A port would not be
  porting — it would be constructing the object from a paragraph.

## Infrastructure comparison: the four named solver files cover none of it

| file | supplies | covers any Xu technique |
|---|---|---|
| `solver/holder_norms.py` | Hölder seminorm constants, conformal checks, family op-norms | **none** |
| `solver/hilbert_pointwise.py` | pointwise `H`-transform bounds with explicit quadrature | **none** |
| `solver/op_lower.py` | operator-norm **lower** bounds by sign patterns/ascent | **none** |
| `solver/spectral_certificate.py` | weighted-`ℓ¹` finite section + tail, radii-polynomial constants | **none** |

The reasons are structural, not incidental. `holder_norms` is Hölder/sup and **no Hölder
norm appears anywhere in Xu** (he is `L²`-based throughout: origin-`H²` `X`, Hardy `H²`,
weighted `Y_θ`). `hilbert_pointwise` is the closest thing the repo has to "quadrature error
for a singular kernel" and is still the wrong object twice over — it bounds `|Hψ(θ)|`
**pointwise on the circle**, where Xu needs a **trace-norm bound on an operator on `ℝ`**,
and a sup bound on a function does not bound a Schatten norm of an operator. `op_lower`
points the wrong way (Xu needs resolvent **upper** bounds and a **lower** bound on
`|det|` along a contour). `spectral_certificate` is the ~70-leg lane itself: a Fourier
**coefficient basis on the circle**, where every Xu technique is a Mellin or Hardy
decomposition **on the line**.

A repo-wide grep for `trace class`, `Schatten`, `Fredholm determinant`, `argument
principle`, `winding number` and `Mellin` returns **one line** — `writeup/novelty/leg_127.md:69`,
quoting Xu's abstract. Zero in `solver/`, zero in any runner, zero in any test.

**Two assets outside the four named files are relevant, one of them negatively:**
`solver/interval.py` (outward-rounded interval arithmetic with Rump underflow terms) is
exactly the arithmetic layer Barker gets from INTLAB, and is the one piece of a rigorous
winding count the repo already owns. `solver/rescaled_spectrum.py` is the *same instrument*
as Xu §7(i) — and by Xu's Proposition 2 that instrument renders the **maximal-`L²`
realization**, whose strip is entirely spectrum. Leg RC already banked that from the code
(`experiments/p2_route_rc_v1_realization_audit.py`); this leg claims nothing new there.

**Three false friends are recorded in the JSON** so no later leg trips on them: `hilbert_holder.py`'s
`|cot(t/2)| ≤ 2/|t|` (a kernel on the circle) versus Xu §4.6's Mellin **symbol** `−cot(πs/2)`;
`spectral_certificate.fredholm_sides` (Fredholm **index**, not **determinant**); and
`TECHNICAL_P2_ROUTENGX_V1.md:213`'s *"large-imaginary-part **resolvent** bounds"* — Xu's gap (1)
says no such thing, and §4.4's genuine resolvent bound is a **different technique**, valid
only at `a = 0`. That last conflation would make the Evans strand look like it has explicit
constants. It has none.

## The honest positive, deliberately not dressed as a lane

**One technique is mature, explicit-constant and portable: T3, the §4.4 Hardy–Mellin
resolvent bound.** Lemma 4.5 gives an **exact** operator norm `‖T_z‖_{L²(0,∞)} = 1/α`,
`α = Re z + 1/2`; the constant `c_G = 5/4 + √10 + 2 = 6.4122776602` is explicit; the
majorant is `‖R_0(z)‖_X ≤ C(R,d) α^{−3/2}` uniformly in `Im z`; and `solver/interval.py` is
already the arithmetic layer it would be evaluated in.

**It is not a lane, for a measured reason.** It certifies the `a = 0` resolvent, which
Theorem 2 already supplies in closed form — so a port would yield a rigorous re-derivation
of an already-rigorous result. Zero new mathematical content, at real cost.

## What this leg re-derived rather than asserted (§A of the runner)

Four falsifiable checks on Xu's own constants, all **PASS**:

* **A1** — Lemma 4.5's exact norm. The Mellin symbol modulus `|z + 1/2 − iξ|^{−1}` is
  maximized at `ξ = Im z` with value `1/α`, confirmed on a 400,001-point grid at four `z`.
* **A2** — Lemma 4.5's kernel identity `∫₀¹ sᶻ g(ys) ds = y^{−1−z} ∫₀^y tᶻ g(t) dt`.
  **This is a real control, not a tautology** (lesson 90): the two sides are evaluated by
  *deliberately different* quadratures — LHS by the log substitution `s = e^{−v}`, RHS by a
  graded direct mesh `t = y u⁴` — because the obvious shared power substitution reproduces
  Xu's own change of variables and would make the check a tautology of the code. Verified
  it can fail: the correct exponent gives `3.372e-09`, while the slips `y^{−z}` and
  `y^{−2−z}` give `5.479e-01` and `2.192e-01`, both detected. *(The first draft used
  trapezoid on both sides and A2 FAILED at `Re z = −0.2` by `~1e-4` — endpoint-singularity
  quadrature error, not the identity. Recorded because it is exactly lesson 86's shape: a
  check dominated by its own evaluation error is a statement about the code.)*
* **A3** — the constant `c_G`. **The load-bearing control.** `G'' = b²f'' + 4bf' + 2f` with
  `|b|² ≤ 5/4`, `|b| ≤ √5/2` on `|t| ≤ 1`. The **naive term-by-term** route gives
  `4|b| ≤ 2√5 = √20`, hence `c_G = 7.7221359550`, which **does not match the printed
  constant**. The printed `√10` is recovered only by additionally using the `X₊`
  interpolation `‖f'‖ ≤ ‖f‖_{X₊}/√2` (from `ab ≤ (a²+b²)/2`), giving
  `4(√5/2)/√2 = √10` exactly and `c_G = 6.4122776602`. **Xu's constant is correct**, and
  this check distinguishes two candidate readings of the paper — on the first reading it
  came out the other way.
* **A4** — the `α` bookkeeping, and a genuine reading of the proof: **§4.4 routes *around*
  Lemma 4.5.** The integral actually estimated is `I(y) = ∫₀¹ s^{z−2} G₂(ys) ds`, whose
  exponent is `z−2`; Lemma 4.5 applied there would give `1/(Re z − 3/2)`, not `1/α`. The
  proof instead uses `|G₂(t)| ≤ |t|^{3/2}‖G''‖/√3` to reduce to the **scalar** Beta integral
  `∫₀¹ s^{α−1} ds = 1/α`, and Xu says so explicitly: *"the factor `1/α` arising from the
  scalar integral … rather than from any operator norm."* **Consequence for any future
  port:** the exact-norm lemma is *stated but not load-bearing*; what would have to be
  ported from §4.4 is the Taylor-remainder control, not the Hardy operator norm.
