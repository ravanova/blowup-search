## S1 — DIES, and the mechanism is convergent, not singular

The stage-V ban names three realizations (`ell^1_w` coefficient basis, leg 54;
collocation basis, leg 56; origin-`H²`, legs 163/176). Leg 260's algebraically weighted
space is not one of those three by name — but it is **not hypothetical either**: three
independent existing lanes, one of them an 11+-leg *already-built* attempt, each realize
an algebraic weight in a different way, and **each has already died, for three different
mechanisms.**

### S1_A — the sup-norm/collocation lane (Route-D) has already been built and exhausted

`solver/decay_grading.py` / `solver/decay_collocation.py` / `solver/holder_norms.py`
implement exactly an algebraically-graded weighted-Hölder sup-norm CAP attempt for the
same gCLM/HL_S2_nonsymmetric certificate problem. Leg 126's exhaustive audit
(`experiments/journal/leg_126.md`) covers **1,686/1,686** configurations with no gap:
`0 ≤ s < 0.394` admissible (theorem on `A21=0`, measured otherwise), `0.394 ≤ s < 1.0`
inadmissible (target leaves its own space), `s ≥ 1.0` inadmissible twice over (target
out, and the tail kernel leaves as the cokernel functional enters the dual). Best case
at theoretical optimum: `Z1 ≥ 6.0424` — **6.04x short of closing.** This is `plan_of_
record.py`'s stage-B entry, DONE, gate NO.

### S1_B — the coefficient/`ell^1_w` lane, algebraic weight family, has no window at any exponent

Leg 51 (`PHASE2_P2_NOTES.md` §40) swept flat, nine algebraic exponents, and geometric
weight families on the coefficient basis's tail operator (`sin θ ∂_θ`, a shift/transport
operator, diagonal exactly zero) and found the divergence-exponent curve's minimum
`+0.639` sits at `s = 1.00`, `0.606` exponent units above zero — no point in the swept
range touches zero. Leg 52 (`PHASE2_P2_NOTES.md` §41) then measured the bordering repair
directly: kernel `h_m ~ m^{-2.0024}` is in the weighted space iff `s < 1`, the cokernel
functional `u_m ~ m^{+1.0012}` is bounded iff `s ≥ 1` — **the two failure modes swap
exactly at `s = 1`, with no exponent where both hold.** This leg's own closed-form check
(`experiments/p2_route_algw_v1_scoping.py::s1_ell1w_crossover`) confirms the two
measured exponents bracket `s = 1` to within `0.002` on both sides — consistent with an
exact crossing, not a numerical accident. **Re-attempting this exact sweep — either
tuning `s` toward `1`, or sweeping another weight family without first bordering the
tail — is itself explicitly banned in `plan_of_record.py`** (lines 876/882/904, lift
condition: never / "T"). This leg does not attempt it; it transcribes the existing
result.

### S1_C — origin-`H²` is already algebraically weighted, and still dies (orthogonal reason)

`experiments/journal/leg_176.md`: Xu's Mellin-transform norm
`‖φ‖²_X ∝ ∫₀^∞ (1+ξ⁴)|φ̂|² dξ` **is already an algebraic (polynomial) weight**, not

### S1_D — does the CAP apparatus have a coherent formulation in an algebraic weight?

Yes — and that is exactly the point. Leg 331's finding (§0.1 above) is evidence about
the *opposite* combination (algebraic operator tail against a Gaussian *space*), but it
reads as a general statement about **lesson 87**, banked at `PHASE2_P2_NOTES.md` §40:
*"a certification method has a shape, and the shape is a property of the operator, not
the object."* The Gauss-Hermite/Laguerre quadrature exactness Breden–Chu's `Y`/`Z`
bounds depend on is tied to the Gaussian weight's specific algebraic structure
(polynomial × Gaussian is exactly integrable; polynomial × algebraic-tail is not). A CAP
apparatus matched to an algebraic weight would need its own matched discretization —
and that is **precisely what Route-D is**: a sup-norm collocation CAP formulation built
for an algebraically-graded space. So the question "does a coherent formulation exist"
is not open — it exists, it has already been built across 11+ legs, and §S1_A already
reports it dead at full strength (`Z1 ≥ 6.0424`, exhaustively, `a=0`-only).

## S2 — the NRS/Tsai composition DISSOLVES under re-derivation

Leg 261's composition used `u ~ |x|^{-3}` (`C3`, Biot–Savart velocity, measured
`experiments/journal/leg_261.md:124`) — but that exponent was measured **on a
Gaussian-decaying `H²(µ)` witness** (Breden–Chu's own basis function), a fast-decaying
test object whose vorticity moments converge, giving the classical dipole falloff. It is
a property of the witness, not of leg 260's actual DSS target.

Re-derived here on the target's own, already-computed decay rate: leg 260's Chae–Wolf
Type-I bound gives `|U(y)| ≤ C/(1+|y|)`, i.e. `σ = 1` (`experiments/journal/leg_260.md:
56`), **three powers slower** than the Gaussian witness's `σ = 3`. Recomputing the `L³`
tail: `|u|³r² ~ r^{-3σ+2}`, integrable at infinity iff `-3σ+2 < -1` iff `σ > 1`. At
`σ = 1` (the target's own rate) the tail exponent is **exactly `-1`** — the classical
log-divergent boundary, not integrable. This is not a new measurement: it is the same
crossing leg 260 already computed by an independent route (shell integrals, ratio
`1.000027` at `p = 3` / `s = 1`, `experiments/journal/leg_260.md:47–52`), now confirmed
by a second, closed-form route in `experiments/p2_route_algw_v1_scoping.py`. Leg 260's
own §1 already states the reason this must be so: *"the property that makes the object
survive [the DSS screen] is the same property that makes it hard to represent"* — the
object survives *because* it sits outside `L³`, at exactly the logarithmically divergent
side of the boundary.

**Verdict: DISSOLVES.** The `u ∈ L³` hypothesis leg 261's composition needed is not
established when re-derived on the target's own algebraic-weight-native decay rate; it
was an artifact of assuming a Gaussian witness's fast Biot–Savart falloff. In leg 260's
own vocabulary: **a wall shown to be a weight artifact is a map correction, not
movement.**
