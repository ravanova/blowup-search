## §1 The one instrument decision worth recording

`PB1`'s finding F8 (leg 411) says the tool-output channel silently drops words from long
outputs, so a unit retyping a "verbatim" quote off screen can transcribe a sentence its source
does not contain. **This leg re-confirmed that live**: rendering a 224-character quotation from
`arXiv:physics/0312102` through the output channel returned it with roughly a third of its
function words missing, while `len()` on the same string in the same process returned 224.

Consequence, adopted before a line of the draft was written: **no quotation in `DRAFT.md` was
typed by this unit.** `inject_quotes.py` extracts each one from the fetched source by
(start marker, end marker) and writes it into the file; the draft is authored with `{{TOKEN}}`
placeholders and the script fails loudly on any token it cannot resolve. Repository quotations
(`ORCHESTRATION.md` §6 clause 3, `L6`'s banked `why` string) are injected the same way, from the
file and the JSON field rather than from memory.
