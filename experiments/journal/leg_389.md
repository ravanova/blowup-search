## I.3 The certified T2 column's exact meaning — declared before it is computed

From an enclosure row on the window `[R₀, R₁]` at tolerance δ:

| enclosure verdict | certified T2 reading |
|---|---|
| `INTERVAL` with `p_lo > 0` | `CERTIFIED-DECAYS` |
| `INTERVAL` with `p_lo <= 0` | `REFUSE` (`reason = non-positive certified lower endpoint`) |
| `EMPTY` | `REFUSE` (`reason = EMPTY`, i.e. a PROOF that no exponent in the bracket fits — which is **not** a decay verdict) |
| `INCAPACITY` | `REFUSE` (`reason = INCAPACITY`, bracket-limited or enclosure touching zero) |
| no certified input supplied | `REFUSE` (`reason = NO-CERTIFIED-INPUT`), hypothesis `UNDECLARED` |

**Two things this column does NOT claim, stated before any number exists:**

1. **A nonempty enclosure is not a proof that the profile is a power law.** It is an outer
   bound on `P_cert`: no exponent *outside* it can be one. So `CERTIFIED-DECAYS` is
   **conditional on the power-law-on-window-within-δ hypothesis**, and that conditionality is
   written into the row's `conditional_on` sentence, appended to (never replacing) the
   enclosure's own.
2. **The window is bounded, so neither column certifies a limit at infinity.** The certified
   statement is about `[R₀, R₁]`; "U → 0 at infinity" is an extrapolation off the end of the
   window. The *fitted* column has exactly the same limitation and does not say so. This
   column says so, in the row. This is recorded as decision information on §6 item 1 either
   way the gate answers.

## I.4 δ — which reading, pre-registered, and the nominal-vs-realised trap

Leg 386's trap, named before it can catch this leg: *a nominal parameter reading can say
ADMISSIBLE while the realised `α_centre` says otherwise.*

* **Primary δ = 0.0** on every field. Justification, not convenience: δ is an **input the
  caller owes** — the relative accuracy to which the caller's own profile is certified — and
  for an analytic profile evaluated in outward-rounded interval arithmetic over whole cells,
  and for a sampled profile whose per-sample error bars are already inside the cell enclosures,
  **that accuracy is exact and the honest input is zero.** δ is never tuned until something
  passes.
* **Every verdict in this leg is decided on the REALISED row** — the `verdict` / `p_lo` /
  `p_hi` / `width` actually returned by the call at that δ. `predicted_width_exact_power_law`
  is **NOMINAL**, is recorded for contrast, and **decides nothing**. Pre-registered here so it
  cannot be re-read afterwards.
* **The window is named on every width.** All six fields are certified on `[10, 1000]`, the
  same window `fitted_far_field_decay_exponent` fits on (`np.logspace(1,3,12)`). Leg 386's law
  `width = 4·log(1+δ)/log(R₁/R₀)` gives `4/log(100) = 0.8685889638065035` per unit `log(1+δ)`
  **on this window**, and would double on `[10,100]`. No half-width is quoted here without its
  window.
* A **secondary δ ladder** `{0, 1e-9, 1e-6, 1e-3, 1e-1}` is recorded per field for the width
  law and for `δ*`. It is reportage; it decides no gate clause.
* Leg 386's measured consequence is expected to bite and is **not** a shortfall when it does:
  the tolerance buys **zero** headroom on a threshold (30 rows, 0 exceptions, a step and not a
  slope), so a field the enclosure refuses at δ=0 is not rescued by widening δ *into a
  verdict this leg would report*. Refusals are the gate's success condition where predicted.

## I.6 The demonstrated RED path — pre-registered, and run BEFORE any green is reported

**NO GREEN WITHOUT A DEMONSTRATED RED PATH.** The agreement check is exactly the kind that
passes vacuously if the certified column silently returns the fitted value. Three planted reds,
each of which must be *shown* to go red:

* **R1 — the impostor column.** An `_impostor_certified_from_fitted()` that manufactures a
  certified-looking row from the fitted exponent is substituted for the real one, and the
  agreement+refusal check is re-run. It **must go RED**, on the fields where the true column
  refuses (C4, C6): the impostor claims a verdict where no certificate exists. If this does not
  go red, the whole check is vacuous and the gate answers NO on that ground alone.
* **R2 — the mismatched profile.** The certified column is handed the `r^{-2}` profile while
  the screen runs C1's `1/r` field. The containment check **must go RED** with a reported
  magnitude ≈ 1.0 in the exponent.
* **R3 — the false hypothesis.** Leg 385's `planted_node_aligned_wiggle` is fed through the
  adapter under a **declared but false** `monotone` hypothesis. The row is expected to certify
  anyway — as it must, since the hypothesis is the caller's and is unverifiable from samples —
  and the check that must go red is the *consumer's*: a check demanding the discharged
  `EXACT-INTERVAL-EVALUATION` hypothesis must reject that row while accepting C1's. This is
  leg 385's X3 lesson made operational: a certificate can be bit-narrow and false, and **only
  the recorded hypothesis separates it from a true one**.
