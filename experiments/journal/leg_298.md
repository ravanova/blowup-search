## The one defect class found: §21.2, sites 1 and 2 — `DIRECTION.md` line-number drift

§21.2's table cites `DIRECTION.md:9856` (site 1, "directive sentence, DM's own Phase-1 prose
block") and `DIRECTION.md:13722` (site 2, leg 303's dispatched thesis) as the locations of two
`[CORRECTED …, over-read closure #5: …]` markers the DM inserted at cycle 6. Direct lookup found
both had drifted from unrelated `DIRECTION.md` edits made since:

* `sed -n '9856p' DIRECTION.md` → unrelated prose (`"leg 174's own occupancy matrix…"`); the
  actual `[CORRECTED 2026-08-11, user steer item 1, over-read` marker is now one line later, at
  `:9857`.
* `sed -n '13722p' DIRECTION.md` → unrelated prose (`"Phase 1's premise rests on…"`); the actual
  site (`"only HL_S2_nonsymmetric specifically. [CORRECTED 2026-08-11, user steer item 1, over-
  read closure #5: …"`) is now 7 lines later, at `:13729`.

This is the exact failure mode §16.1 already documents and fixes for a different pair of sites
(`DIRECTION.md`'s `6.855x` gate text) — `DIRECTION.md` is edited by the DM essentially every
cycle, so any bare line-number citation into it has a short shelf life. §21.2's two pointers
were written at leg 328's landing (2026-08-12, per its own dispatch date) and had already gone
stale within the same day, purely from the volume of subsequent `DIRECTION.md` edits.

**Fixed, in `writeup/CORRECTIONS.md` only** (no edit to `DIRECTION.md` itself — it is DM/
integration-owned territory, never opened for writing by this leg): both table cells now carry
a `[LOCATOR CORRECTED 2026-08-12, leg 298: …]` annotation naming a grep-stable text anchor
(`grep -n "user steer item 1, over-read"` and `grep -n "only HL_S2_nonsymmetric specifically"`
respectively) alongside the current line number as observed at this leg's check, following the
exact precedent §16.1 already set for the sibling case. The original wording and status columns
are untouched; this is purely a locator-precision fix, not a content correction — nothing about
what happened, what was corrected, or which leg did it changes.
