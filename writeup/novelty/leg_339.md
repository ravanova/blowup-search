adjudication already been performed anywhere in the record, and would this leg be redoing it?*

The load-bearing negative in this pass is Q1's **absence** of the phrase outside three files, and
Q9's **zero** for `closure #5` in `CORRECTIONS.md`. Both are grep zeros, so both get a control:

* **Positive control for Q1's instrument:** the identical grep for `three ways` (Q2) returns many

  corpus, not of the search. Additionally `git log -S` (Q3) is a *different* instrument over a
  *different* corpus (history, not the worktree) and it agrees.
* **Positive control for Q9:** `grep -n "closure" writeup/CORRECTIONS.md` returns 17 lines
  (the register preamble and the pattern paragraphs), so the file is being read; only the

* **MF1 (spelling variants) does not bite here** — the strings searched are this repository's own
  ASCII prose, not paper titles; there is no `Navier--Stokes`-style hyphenation channel in
  `closed three ways`. Recorded because the rule is a test, not a ritual: it was considered and
  found inapplicable, rather than silently skipped.
