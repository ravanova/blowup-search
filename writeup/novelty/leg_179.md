# Leg 179 — ROUTE-PUB1 novelty pass, run and logged BEFORE the note was drafted

**Branch** `leg/179-pub1-v1`. **Route** PUB1 (exploration/writeup, not critical path).
**Verdict: `PROCEED_AS_SYNTHESIS_ONLY`.**

This leg claims **no mathematical novelty of its own**. It is a bundling leg: every
mathematical statement in the note it produces belongs to an earlier leg of this repository
or to a published author. The novelty pass therefore has a different job than usual, and it
has two halves:

1. **Provenance.** Every claim the note will make is read back from *its own banked source*
   — the producing leg's journal, its curated JSON, or the module it landed — and the number
   is checked, not remembered. A publication-scoping note that misstates a banked result is
   exactly the drift this repository's discipline exists to catch, so this half is the gate.
2. **External novelty, carried not re-derived.** Each bundled item already had its own
   external-novelty pass. This leg **carries those verdicts verbatim** and re-runs none of
   them. Where a bundled item's own pass forbade a claim, the note inherits the prohibition.

Links, not counts (leg 53 logged counts, could not be audited, and was withdrawn).
