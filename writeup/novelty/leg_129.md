## What a REPAIR leg's novelty pass is actually for

Leg 120's pass (`writeup/novelty/leg_120.md`) already settled the prior art for the **defect**:
Bowman 2013 for the strict dealiasing boundary, Johnson 2011 (Algorithm 1) for the Nyquist
treatment, leg 91's inherited `NaN`-propagation vocabulary. **None of that is re-derived here;
it is cited.** A repair leg has three *different* questions, and they are the ones asked below:

* **(R1)** Does any published source prescribe the **non-strict** cut — i.e. would changing
  `k <= n/3` to `k < n/3` put this repository *out* of step with a standard rather than into
  step with one? A single authority retaining `k = n/3` would make this repair contested, and
  it would then not be this leg's to land.
* **(R2)** Is the specific repair *form* — `wavenumbers(n) <= (n - 1) // 3` — the community's
  own idiom for "the largest integer strictly below `n/3`", or is it an invention of this
  repository that a reader would have to take on trust?
* **(R3)** What is the in-repo repair template? Which precedent does this leg follow, and has
  either target module been repaired before (so that this is a second repair of an already-
  touched file rather than a first)?

**Finding for (R2): the corpus states the rule in the loose form and gives no integer idiom.**
Every source here says "retain 2/3 of the modes" / "zero `max(|k_i|/k_{i,max}) > 2/3`". None
writes the retained set as an integer expression, so **`(n - 1) // 3` cannot be cited to any of
them** — and this leg does not cite it to them. It is justified *arithmetically* instead, and
the justification is executable rather than rhetorical: `(n - 1) // 3` is the largest integer
strictly below `n / 3` for every `n`, which the runner checks exhaustively over `n = 1..5000`
rather than asserting. That is the honest status of the form: **not published, but proved on
the range in use, and equal to the current mask at every `n` not divisible by 3.**

**Finding for (R1), and it is the decisive one — an INDEPENDENT, 2026 confirmation of the
strict cut, thirteen years after Bowman.** The paper's cubic-truncation prescription is:

> "The cubic truncation, Fig. 2(a), zeroes all modes for which any single wavenumber component
> satisfies `|k_i| >= (2/3) k_N`"

With `k_N = n/2` the Nyquist wavenumber, `(2/3) k_N = n/3` exactly, so the mode `|k| = n/3` is
**zeroed**, and the retained set is `|k| < n/3` — **strict, and exactly the repair.** This
matters more than a second citation usually would, because it is the one direction in which
this leg could have been wrong: had any source retained `k = n/3`, the repair would have been a
contested convention change rather than a defect fix, and the leg would have parked.

**Finding for (R1), partial, and a recorded AMBIGUITY rather than a clean confirmation.**
FourierFlows.jl states the rule as *"filter out all wavenumber modes with `k > N/3`"* — which
read literally **retains** `k = N/3` and would contradict Bowman and the 2026 paper. A follow-up
fetch of that page was made specifically to resolve it (below); the page documents the cutoff
only as a *fraction* (`aliased_fraction = 1/3`, "zeroing out the highest-`aliased_fraction`
wavenumber components") and never as an index expression, so **it does not actually decide the
boundary case** and cannot be read as prescribing retention. It is recorded here at exactly
that strength: an ambiguous secondary source, not a counter-authority.

**This is why the leg does not rest on citation at all.** The boundary is decidable by an
argument that needs no authority, and by a measurement this repository already banked. The
argument: on an `n`-point grid with largest retained wavenumber `K`, a quadratic nonlinearity
produces modes up to `2K`, which alias to `2K - n`; contamination of the retained band is
`|2K - n| <= K`, i.e. `n <= 3K`. Alias-freedom therefore requires **`n > 3K`, strictly.** The
measurement: leg 120's battery D1 put the field on mode `K`, squared it and read mode `K` back
— **exactly 0.25 at all 11 tested grids with `3 | n`, and `<= 4.83e-16` at all 12 with `3 ∤ n`.`
No textual ambiguity survives a spurious coefficient of one quarter.

**Finding: the ambiguity is not resolvable from the documentation, and is therefore not a

   quoting only the two that agree. FourierFlows.jl's loose wording is reported, chased, and
