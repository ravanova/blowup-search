**Why this module is worth the pass.**  `ACollocation.newton_gauged` is the solve whose

returned step size **is** `Y_0`.  A convergence flag that can be true on a wrong answer here
is a convergence flag on a number the Route-D bound layer consumes directly.

| `FINITE` | finite and *correct* — the case is handled. |

Findings and magnitudes are in §2; the answer in the gate's own wording is §3.

**61 cases.**  `SILENT_WRONG` 8 · `SILENT_EMPTY` 7 · `NONFINITE` 12 · `RAISED` 9 · `FINITE` 25.
Curated data: `writeup/data/p2_route_cna_v1_adversarial.json`.  Banked regression battery:
`test_collocation_newton_adversarial.py` (12 checks, 7 of them `KNOWN GAP`).

**What "silently wrong" was allowed to mean, decided before the run.**  The module makes
exactly two validity claims of its own, and the gate is decided on those, not on taste:

1. `converged`, in both solvers.  Corruption **iff** `converged is True` *and* the returned
   profile is not a solution of the problem the docstring says is being solved — measured as
   either (a) a nodal residual row above `1e-6` anywhere **including the dropped row**, or
   (b) a profile outside the decay class the whole Route-D pair lives in, measured by
   `||Ω||_X` at α = 2 against the exact anchor's `1.0000`.
2. `critical_radius` / `zero_order`.  Corruption **iff** a finite, plausible value comes back
   where the true answer is `inf` / `(nan, 0)`.

A big honest number is not corruption; a small dishonest one is.

## 2. Findings — three mechanisms, and how far each one actually reaches

### M1. The convergence flag is blind to the one row it drops

`newton_gauged` builds `F = [gauge row ; residual rows except drop]` and sets
`converged = hist[-1] < 1e-11` from that `F` alone.  The dropped row — the one the docstring
itself calls *"the one row it does not see"* — is recomputed afterwards into `dropped_defect`
and then never consulted.  So `converged is True` is **structurally guaranteed** for any root
of the (J−1)-row subsystem, however large the missing row's residual is.  The flag and the
defect are two independent outputs and only one of them is a boolean.

Measured, from `om0 = 0.1 × anchor` at J = 60:

| quantity | value |
| --- | --- |
| `converged` | **True** |
| `kept_sup` (rows Newton enforced) | 9.20e-15 |
| `dropped_defect` (the row it cannot see) | **3.3438** |
| `sup|R|` over **all** rows | 3.3438 |
| `weighted_defect` (the Y₀ ingredient) | **33.12** |
| `‖Ω‖_X(α=2)` | 4.55e+03 against the true 1.0000 |

This root is *loud* in every field except the boolean: a consumer that reads `dropped_defect`
or `weighted_defect` sees the problem at once.  A consumer that reads `converged` does not.

### M2. The one-gauge system has a second root, and it is reported converged **and** clean

`Ω ≡ −1` satisfies the gauge row `Ω(θ=0) = −1` **and** every collocation residual row, to
`2.80e-13` sup — because `H(constant) = 0` and `Ω_X = 0`, so `R = Ω·H(Ω) − c Ω_X` vanishes
identically.  It is a genuine root of the system `newton_gauged` solves, and it is not a
profile: it does not decay, so it is outside the decay class `‖h‖_X = sup (1+X²)^{α/2}|h|`
that every Route-D bound is stated in.

| J | `converged` | `‖Ω‖_X(α=2)` | true anchor | inflation | `weighted_defect` | true |
| --- | --- | --- | --- | --- | --- | --- |
| 40 | True | 2.5942e+03 | 1.0000 | 2.59e+03× | 1.117e-12 | 7.682e-14 |
| 60 | True | 5.8364e+03 | 1.0000 | 5.84e+03× | 1.724e-11 | 2.382e-13 |
| 80 | True | 1.0376e+04 | 1.0000 | 1.04e+04× | 2.769e-11 | 7.627e-13 |
| 160 | True | 4.1501e+04 | 1.0000 | 4.15e+04× | 7.762e-12 | 4.943e-12 |

The inflation grows like `X_max^α ~ (2J/π)^α`, i.e. it **diverges with resolution** — refining
the grid makes the returned object worse, not better, which is the opposite of every
convergence intuition a reader brings to a `converged` flag.

**This is the dangerous one, and the reason is the last column.**  Unlike M1, M2 is quiet
*everywhere*: `kept_sup = 1.09e-14`, `dropped_defect = 2.34e-12`, and the certificate-visible
defect `weighted_defect` is **1.72e-11** on the solver's own iterate (4.65e-10 on the exact
constant) against the true anchor's **2.38e-13** — 72× to 1950× larger in ratio, but in
absolute terms still a defect that no bound layer would flag.  The module hands over a
`converged` flag, a machine-zero residual, *and* a plausibly small Y₀ ingredient, for a
profile that is wrong by O(1) at every node.

Reached from `om0 = zeros`, `om0 = ones`, and `om0 = 1e-8 × anchor`.

**The mechanism, isolated by its own control.**  The sibling `newton` is immune from the
*identical* start: its second gauge, `Ω` at the node nearest `X = 1` equals `−1/2`, misses
the constant by 0.50 and drives `converged` to False (relres 2.54e-02).  One gauge kills the
scaling symmetry; it does not kill the constant.  Two gauges do.  `newton_gauged` is the one
with a single gauge, and it is also the one whose matrix **is** the certificate's `A`.

### M3. `critical_radius` has no magnitude test on the sign change

Its entire crossing test is `np.diff(np.sign(E)) != 0`.  With `E ≡ 0.5` and **one** entry
dipped to `−1e-16` — a relative perturbation of 4e-16 — it returns a finite, entirely
plausible radius where the truth is `inf`:

| dip depth | −1e-16 | −1e-12 | −1e-8 | −1e-3 |
| --- | --- | --- | --- | --- |
| returned `X_c` | 15.025019 | 15.025019 | 15.025019 | 15.024919 |

The answer moves by **1.0e-04 across thirteen orders of magnitude of dip depth**, so the
returned radius carries essentially no information about whether the crossing it reports is
real.  Chained onward, `zero_order` converts the non-existent radius into a plausible
exponent: **p = 0.232454 from 141 points**, where at the true `inf` it correctly returns
`(nan, 0)`.  An `E` of pure alternating sign noise likewise returns its first flicker, 0.2010,
as "the radius where the profile ends".

### Reachability — measured, and it is the reason this is a report and not an escalation

None of the three fires on the path production actually walks, and saying so is part of the
finding:

- `experiments/p2_route_d_v12_defect.py` calls `newton_gauged(c=…)` with `om0=None`, which
  starts at the anchor and lands on the true anchor: `dropped_defect = 4.31e-15`,
  certificate defect `3.50e-14`.  M1 and M2 need a caller-supplied `om0`.
- M2's basin is *under-scaled* starts only.  `λ × anchor` lands on the true anchor for
  λ ∈ {0.3, 0.5, 0.6, 0.7, 0.75, 0.8, 0.9, 1, 2, 5}, on the **third** spurious root (M1's,
  `dropped_defect` 3.34) at λ = 0.1, and on the constant for λ ≤ 0.01 — so the two spurious
  roots sit side by side just below the anchor's amplitude, and the transition is at
  λ ≈ 0.1, not at 0.  140 draws of `anchor + ε·noise` at ε from 1e-12 to 0.3 hit the
  constant **0 times**.
- M3 needs an `E` field whose crossing is at roundoff scale.  Real converged `E` fields do not
  provide one: the tangency margin is `min(E) = +1.101e-03` at a = 0.131 on the J = 60 grid —
  about 1e+13 times the roundoff floor — and 40 draws of relative noise up to 1e-08 never
  flipped `X_c` from `inf` to finite.

The gaps are therefore **latent, not live**.  `om0` is nonetheless a documented public
parameter whose most natural degenerate value (`zeros`) triggers M2, and `critical_radius` is
consumed at three sites in `solver/turning_point.py` and five in
`experiments/p2_route_d_v12_defect.py`.

### The smaller findings (`SILENT_EMPTY`, 7 cases)

- **`relres` is not a relative residual.**  At `c = 0` (and a = 0) the residual *is* the
  source, `R = Ω·H(Ω)`, so `relres = rms(R)/rms(src)` is **identically 1.000000000000**
  however well the solve converged (`kept_sup = 2.79e-15`, `converged = True`).  The
  `float(...) or 1.0` fallback silently rescales the same field in the degenerate branch.
- **The two return shapes differ.**  Both solvers' `LinAlgError` early-exit dict omits the
  normal path's result keys (`newton`: `relres`, `residual_rms`, `iterations`, `nodal_sup`).
  `continuation` indexes `r["relres"]` unconditionally, so the module's own documented
  failure path takes it down: `continuation([nan], J=40)` → `KeyError('relres')`.
- **`newton_gauged(max_iter=0)` raises `IndexError`** on `hist[-1]` over an empty list, where
  the sibling `newton(max_iter=0)` returns cleanly — an asymmetry, not a design.
- **`E ≡ 0` is indistinguishable from a healthy non-crossing field.**  `sign(0) = 0` for every
  entry, so `critical_radius` reports `inf` — "the profile never ends" — for an effective
  speed that vanishes at every radius.
- **θ outside (0, π) is accepted silently** by `velocity_integrals` (θ = −1 → 0.2612, θ = 10 →
  2.5199), which is exactly where `X = tan(θ/2)` stops being the compactification the module
  is built on.
- **`dtype` is an unguarded public kwarg.**  The docstring's own warning that the recursion
  loses `eps·k²` is not enforced: a `float32` call at K = 200 returns a plausible number
  silently off by **3.48e-03 relative** against the longdouble default.
- **The docstring's gauge claim is off by O(grid spacing).**  `newton` says both gauges are
  "satisfied by the exact a = 0 anchor"; the second is satisfied only to 6.68e-04 at J = 60,
  which is why `newton(max_iter=0)` reports `converged=True` and `newton(max_iter=1)` reports
  `False` on the same input.

### What held (25 `FINITE`, 12 `NONFINITE`, 9 `RAISED`)

NaN/Inf in `om0`, `c` or `a` never come back as a converged finite answer — all four poisoned
solves report `converged=False` with a non-finite `kept_sup`.  `weighted_defect`,
`velocity_integrals(θ=π)` and `critical_radius` propagate poison rather than swallowing it.
Seven structural adversaries (wrong-length `om0`, `drop` ∈ {J, −1, 1000}, negative K, an empty
refined grid, an empty `theta_eval`) all raise.  And `zero_order` — the one function in the
file carrying a guard — is genuinely robust: it recovers the constructed exponent
**3.000000 exactly** under 1%, 20% and **95%** NaN poisoning, because the survivors still lie
on the power law, and it reports the surviving point count honestly (191 → 12).

## 3. The gate, answered in its pre-committed wording

> *"Under an adversarial battery of degenerate or poisoned inputs, does
> `solver/collocation_newton.py` ever report a converged solution or plausible residual that
> is silently wrong?"*

**YES.**  8 silent corruptions in 61 cases, three independent mechanisms.  The sharpest single
case: from `om0 = zeros`, `newton_gauged` returns `converged = True` on `Ω ≡ −1` — an exact
root of its one-gauge system, outside the decay class by a factor **5.84e+03** at J = 60 that
**grows with resolution** (4.15e+04 at J = 160) — with `kept_sup = 1.09e-14`,
`dropped_defect = 2.34e-12`, and a certificate-visible defect of **1.72e-11** against the true
anchor's 2.38e-13.  Every number the module reports about that answer looks healthy.

Per the gate's YES branch: **reported, not patched.**  `solver/collocation_newton.py` is
untouched by this leg, as its territory pre-commits.  The battery is banked as
`test_collocation_newton_adversarial.py`, 12 checks, 7 of them labelled `KNOWN GAP` and
asserting the wrong behaviour *as measured*, so that a later bench repair fails this file and
is forced to invert those checks at the same thresholds rather than quietly weakening them —
the convention leg 92 established for `solver/gclm.py`.

**Escalation status: not one of the four (ORCHESTRATION.md §8).**  This changes no banked
result, lifts no ban, touches `plan_of_record.py` not at all, and claims nothing about the
Clay chain.  It lands on `main` like any other leg, with the repair left to a bench leg.

**What this does and does not say about the collocation death certificate.**  It does *not*
reopen it.  Leg 110 audits that conclusion at the data level; this leg audits the code that
produced it, and the production path — `om0=None`, the anchor start — is measured clean here
(`dropped_defect = 4.31e-15`, certificate defect `3.50e-14`, real `E` fields crossing with a
1.10e-03 margin).  The collocation realization's death is not attributable to any of M1–M3.
What the leg establishes is narrower and still worth having: the module's `converged` flag is
**not a safe input** to a bound layer, because it is computed from a subsystem that excludes
the row the certificate cares about, on a system with a second root that satisfies everything
the flag can see.
