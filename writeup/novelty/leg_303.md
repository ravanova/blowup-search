## 0. What "the Grade-A/fluid cell" is — read from the repo, not re-derived

The occupancy matrix lives in `solver/viscous_novelty.py::PRECEDENTS` (leg 174's grading,
extended append-only by leg 197). Its two axes:

- **Grade axis — where the dissipation sits relative to the certified object.**
  *Grade A* = the dissipative term is **inside the equation the computer encloses**, so the
  certificate itself is a statement about a dissipative problem (`arXiv:2410.05480`,
  Dahne–Figueras CGL: `eps` sits at leading scaling order in the certified profile equation;
  verdict `PRE_EMPTS`). *Grade B* = the certified object is the **inviscid** reduction and
  dissipation is reached afterwards by domination/perturbation (`arXiv:2208.09445`,
  Buckmaster–Cao-Labora–Gómez-Serrano: interval arithmetic encloses the profile of the
  inviscid system (1.5); §7 restricts `r` "where the self-similar profile dominates the
  dissipation"; verdict `EXCLUSION`, `grade: "B"`).
- **Model axis — fluid transport model or not.** CGL/NLS/nonlinear-heat/viscous-Burgers are
  not fluid transport models; gCLM / Hou–Luo / Boussinesq / Euler / Navier–Stokes are.

The four cells, as the ledger currently stands:

| | non-fluid | fluid |
|---|---|---|
| **Grade A** (dissipation inside the certificate) | `arXiv:2410.05480` (CGL), `arXiv:2404.04054` (viscous Burgers, nonlinear heat; `ADJACENT`) | **EMPTY** |
| **Grade B / no certificate** | — | `arXiv:2208.09445` (B), `2210.07191`+`2305.05660`, `2509.14185`, `2207.07548`, `1908.09385` |

Leg 174's own phrasing for the empty cell is that it is empty **"for want of a target, not a
method"** — the machinery (interval arithmetic, Newton–Kantorovich, radii polynomials) exists
and has been run on dissipative equations; nobody has pointed it at a *fluid transport* model
with the dissipation inside the enclosed object. **Phase 1's premise — "no certified viscous
blow-up exists in any model, in any dimension, today" — is exactly the claim that this cell is
empty.**

## 4. Pre-committed classification rule (so a hit cannot be graded after the fact)

A returned entry is a **HIT** iff, from title+abstract alone, it plausibly claims *(a)* a
computer-assisted / rigorous-numerics certificate, *(b)* of a blow-up or singular self-similar
profile, *(c)* where the dissipative term sits **inside the certified object**, *(d)* for a
fluid transport model. Fewer than all four -> **NEAR** (recorded with the failing clause
named) or **OFF** (not recorded). A HIT is recorded as a pointer only: **this leg does not do
the adversarial full-text read — that is reserve leg 309.** A hit that appears to *fill* the
cell is an escalation, not a merge.
