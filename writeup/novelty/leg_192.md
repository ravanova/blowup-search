## 1. The primary source, read directly

* **Xu, arXiv:2607.19762** — <https://arxiv.org/abs/2607.19762>, PDF pulled fresh this leg
  (`Papers/fetch.sh`'s Tier-1 list; `Papers/` is gitignored so the file is not committed).
  Read at full text for the pieces leg 176 depends on:
  * **eq. (4.21)**, `L₀⁺ = −1 − y∂_y + i/(y + i/2)` — the scalar first-order reduction on
    `H₊²` at `a = 0`, via the single-simple-pole identity `HΩ − iΩ = i/(y+i/2)`.
  * **eq. (4.23)**, the resolvent kernel: `u = −b(y)^{−2} Φ`, `Φ = I(y) + c₀ + c₁y`,
    `I(y) = ∫₀¹ s^{z−2} G₂(ys) ds`, with `G = b²f`, `G₂(t) = G(t) − G₀ − G₁t`,
    `G₀ = G(0)`, `G₁ = G′(0)`, `c₀ = G₀/(z−1)`, `c₁ = G₁/z`.
  * the sentence immediately under (4.23): *"A direct substitution verifies `(L₀⁺ − z)u = f`
    (an exact identity in sympy; floating-point substitution residual 3 × 10⁻¹⁶)."* — **Xu
    states his own float residual**, and it is the number leg 176's conjunct 2 is implicitly
    being compared against.
  * **eq. (4.22)** `|G₂(ζ)| ≤ C_K‖f‖_{X₊}|ζ|^{3/2}`, and **eq. (4.25)** the origin-Taylor
    coefficient `A := ∫₀¹ t^{z−2}G₂(t)dt` — the object that is bounded on `X` balls and
    unbounded on `L²` balls.
  * **Prop. 4.6** — `{Re z > −½}\{0,1}` is resolvent set at `a = 0`, with majorant
    `‖R₀(z)‖_X ≤ C(R,d)α^{−3/2}`, `α = Re z + ½`. Note `z = 0` is **excluded** from the
    proposition; leg 176's object is the *bordered* operator at exactly that excluded point.
  * **§4.6 "Remark (realization dependence)"** and **eq. (4.32)** `u_λ(y) = y^{1−λ}/(y+i/2)²`,
    **eq. (4.33)** `φ_λ := B₊ − SB₊` — every point of the open strip `−½ < Re λ < 3/2` is a
    genuine eigenvalue of the **maximal `L²` realization**. This is the literature statement
    that leg 176's control C4 turns into a magnitude, and it is the thing C4 must not
    contradict.
* **Lemma 4.5** (exact Hardy–Mellin norm, `‖T_z‖ = 1/α`) — read, and *not* used here: it is a
  norm identity for the Hardy operator, not for the bordered operator at `z = 0`.

## 4. What this leg's re-derivation must be independent OF, declared in advance

Leg 176's chain has four links, and a verification that reuses any of them is not a
verification of it:

1. **The Laguerre tridiagonal realization** `L₀⁺ℓ_n = −(n/2)ℓ_{n−1} + (1/2)ℓ_n + ((n−1)/2)ℓ_{n+1}`,
   the border row `ℓ_n = i(−1)ⁿ(1−2n)`, and the symmetry modes in `span{ℓ₀,ℓ₁}`.
   → to be re-derived **symbolically** (exact rationals), not by quadrature. Leg 176's own
   E1 cross-check is a 60-node Gauss–Laguerre quadrature, so a second quadrature would not be
   independent; exact symbolic integration is.
2. **The `X` Gram** `G = I + J⁴`. → to be re-derived as `∫₀^∞(1+ξ⁴)ℓ_mℓ_n dξ` directly.
3. **The closing quantity** `σ_min` of the range-untruncated bordered section in the `X`
   metric. → to be recomputed with a different linear-algebra route than
   `_sym_sqrt`-whitening, and **in extended precision**, because leg 176 itself attributes its
   `N = 1024` row to a float floor and stops its reliable window at `N = 512`. That
   attribution is a claim about arithmetic and is checkable by doing the arithmetic better.
4. **Xu's closed form**, which leg 176 evaluates through exact Taylor coefficients plus
   geometrically graded Gauss panels. → to be re-derived by the **integrating-factor solution
   of the ODE from scratch** and evaluated in **extended precision** with a general-purpose
   adaptive quadrature, so that neither the Taylor machinery nor the panel grading is reused.

Two classical Laguerre identities (`∫₀^x L_n = L_n − L_{n+1}`; the `ξL_n`/`ξL_n′`
recurrences) are used by leg 176 and disclaimed by it. This leg disclaims them too, and in
fact avoids them: the symbolic re-derivation integrates the definitions rather than invoking
the identities.
