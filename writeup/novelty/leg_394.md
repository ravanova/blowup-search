## 1. Instrument repair R1 — a would-be fabricated zero, caught and recorded

Run 1 used `search_query=id:<id>`. That returned `opensearch:totalResults=0` for the old-style id
`math/0005247` while returning `1` for every new-style id. **This is leg 387's failure shape exactly.**
It was caught because the same paper's *full text* fetched fine in the same run (32 pages, 91 978
chars) — the two independent endpoints disagreed, and a disagreement is a signal.

Fix, committed as `ea4c97e` with the reasoning in the message rather than silently patched:

1. switch to the documented `id_list=` parameter, which is what old-style ids require;
2. add a hard rule that an `HTTP 200` + namespace-served + `totalResults=0` for an id whose full text
   *is* retrievable is banked `ARTEFACT` — **an instrument artefact, never an absence and never a
   zero.**

A query that fails to reach the service is `THROTTLED`/`FAILED`. **No zero was banked this leg.**

## 4. The two undercuts, and what they do to the record

**`arXiv:1902.00384` (U3)** — the certified solutions of Theorem 1.1 are homogeneous in `x₃` with
`u₃ ≡ 0`; the authors call them "(essentially) 2D" and give the reason as *memory*, not mathematics.
`WALLS.md`'s W2 crack described this object as "natively 3D". It is not. **The viscous term genuinely
is inside the certified equation** and the domain genuinely is `𝕋³` — the undercut is on
three-dimensionality alone. Separately and materially for Ruling C1: the paper's Theorem 2.15 is a
`Y₀/Z₀/Z₁/Z₂` radii-polynomial contraction with a bounded approximate inverse — **inside** C1's ban,
not the Galerkin-plus-tail closure C1 left outside it. Unit `T4` is running against this paper in the
same wave. **Reported, not ruled.**

**`arXiv:2409.09234` (U4, U1)** — by its own conclusion it does not guarantee anything about the
Navier–Stokes solutions; the rigorous theorem is about a 1D return map fitted to ~2500 DNS Poincaré
crossings. It closes **no** tail-domination estimate, so it is not an instance of the technology leg
348 was censusing, and its domain carries no-slip walls rather than periodicity. Leg 348's
`domain_census` over-counts by one.

**The obstruction leg 348 named is not refuted.** No full text supplied a counter-instance either —
no tail-domination estimate closed against an algebraic far field for a time-periodic target in more
than 1D. What changed is the **evidence base**, which is thinner than the record states.

## 5. The near-miss that was recorded rather than dropped

`arXiv:2308.01528` §1 characterises **Chen–Hou [CH22]** as a computer-assisted proof of asymptotically
self-similar blow-up for 2D Boussinesq / 3D axisymmetric Euler — i.e. computer-assisted certification
reaching **more than 1D on an unbounded domain with algebraic decay**. That is the shape of a
counter-instance and it was probed deliberately (K4). It does **not** fire trigger U6: U6 requires a
**time-periodic** target and CH22's is a stationary self-similar profile, and CH22's apparatus is
energy estimates with computer-assisted constants, not a Galerkin-plus-tail dynamical closure. Banked
as a **narrowing observation**, not as a verdict — but it is the single most promising thread for any
future unit that wants to attack the "compact domain only" obstruction head-on.
