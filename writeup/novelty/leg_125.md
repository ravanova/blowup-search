## Verdict

* **(N1) NOT FOUND.** No CAP or validated-numerics certificate of any **dissipative**
  self-similar gCLM profile appears in the searched literature. So the sub-goal DIRECTION.md
  named — "even the measured `Y_0` is a novel data point" — stands: nothing pre-empts a
  measurement here.
* **(N2) ANALYTIC, CONFIRMED.** Chen arXiv:1908.09385 is an analytic energy-method proof
  (weighted `L²` + weighted `H⁴`); no computer assistance anywhere in it. This **confirms**
  `Papers/MANIFEST.md`'s 2026-08-04 entry ("checked and it is **analytic**, no computer
  assistance. Not a CAP precedent; it is an exclusion") — that entry was made at index depth
  and is now verified at full-text depth. It is an exclusion, not a precedent.
* **(N3) FOUND, and it decides the leg.** The literature states the profile is the **inviscid**
  a = 1/2 pole-dynamics solution. Verified verbatim in the full text (Chen §2.6, final line:
  *"Since ν(t) converges to 0, such profile is the same as the inviscid profile associated
  with a."*).

**Consequence for the construction, pre-committed here.** The narrow novelty question is
clean, so the leg proceeds — but the object it constructs must be **the profile Chen's
theorem actually converges to**, which N3 says is the inviscid one, not a γ = 2 dissipative
profile. The numerics in `solver/dissipative_profile.py` therefore have to *test* the
existence of a γ = 2 steady profile rather than assume it, and that test is the leg's
measurement. Written down before the module existed.

**Standing ban discharged.** `capabilities.py` was grepped before anything was built
(`grep -n -i -E "gclm|dissipat|laplac|gamma|profile" capabilities.py`). It found
`solver/gclm_family.py` (gCLM a-family rescaled steady residual, validated: the exact a = 0
profile −4X/(1+4X²) nulls R to RMS 2.2e−7), `solver/line_hilbert.py` (whole-line Hilbert
matrix), `solver/gclm_rescaled.py` (`sinh_grid`), and `solver/nk_bounds.py` (`budget`, the
radii-polynomial budget). **All four are imported, none is rebuilt.** The new module adds only
what does not exist: the dissipative term, the self-similar dissipation-consistency
functional, the Newton solve, and the `Y_0` measurement.
