## §4. The external standard — links, and it is not this leg's discovery

The guard is not invented here and is not novel. It is the textbook form of the bound:

* **Rump, "Error estimation of floating-point summation and dot product", BIT Numer. Math.
  52:201–220 (2012)** — <https://link.springer.com/article/10.1007/s10543-011-0342-4>,
  author's copy <https://www.tuhh.de/ti3/paper/rump/Ru11.pdf>. The underflow-aware restatement
  that carries an explicit `η` term alongside the relative ones. **Already cited in
  `solver/interval.py:49-52`** as the authority for leg 69's fix — this leg adds no new source,
  it extends the reach of one the repository already relies on.
* **"An Interval Arithmetic for Robust Error Estimation", arXiv:2107.05784** —
  <https://arxiv.org/pdf/2107.05784>. States the matrix-product error bound in the form
  `|RN(A·B) − A·B| ≤ RN((n+2)u·Γ + η)`: **the absolute `η` sits beside the relative `u·Γ`
  term, not inside it.** This is the independent statement that the missing term is *required*
  and not a conservatism — a purely relative bound is not the standard form.

The reading is therefore the one leg 201 already recorded and this pass does **not** upgrade:
**a documented standard our module did not meet**, in one routine, because the routine is a
clone that missed a fix. The literature name for that is a *missing bug-fix in a code clone*
(Poehlmann et al., ECEASST; Islam et al., SANER 2016/2019 — located by leg 201). **Bookkeeping,
not a discovery.**

## §5. Two decisions taken BEFORE the code was written, recorded here so they cannot be retrofitted

**(a) Patch the clone; do NOT delete it.** Leg 201's second, structural recommendation is that
whoever takes the repair "should consider **deleting** the clone rather than patching it" —
routing `matmul_point_interval` through `interval.matvec`. **This leg deliberately does not do
that, and the reason is the gate's own second clause.** Deleting the clone changes the *shape*
of the computation: `matvec` is a vector routine over an `Interval` object, `matmul_point_interval`
is a **matrix** routine returning bare `(lo, hi)` endpoint arrays, and re-expressing one as the
other reorders the BLAS calls. **A reordered accumulation is not bit-identical**, so the
structural fix would forfeit exactly the property this gate requires be preserved. The minimal
`η` term preserves it. The structural consolidation is a **separate leg** with a **different**
gate, and it is recorded as such rather than smuggled in. (Discipline 75: two defects in the
same problem are not the same defect — and here, two *repairs*.)

**(b) No escape hatch.** Leg 130 shipped `on_unsound='extrapolate'` because its violating band
*was* a shipped configuration that still had to return a number. Here the violating band is
**292.9 decades away from any live operator** (leg 201's measurement), so **nothing needs the
defective value back**, and the runner reproduces the pre-repair behaviour out of git anyway. A
public mode that reproduces a known non-containing enclosure on a certificate module is a
footgun. Following leg 151's decision, on the same reasoning.

## §6. What would make this leg answer NO

Pre-committed, so the gate cannot be read as unfalsifiable. This leg escalates rather than
banking if **any** of:

* any case in leg 201's battery still escapes containment after the guard, or a **new** case
  escapes that did not before;
* **any** clean-input float moves — `==` on float64 hex, not `allclose` — on the declared
  bit-identity surface (the `capabilities.py:238` banked constants, `test_interval_certificate.py`,
  leg 98's 14 adversarial gates, and the live `BorderedCLM`/`BorderedHL` operators);
* the guard fires on any live configuration, i.e. the `η` term is ever a **visible** fraction
  of a live radius rather than being absorbed below half an ulp.

**Nothing is retuned to make the gate pass.** If the analytic `(m/2 − 1) η` escape leg 201
derived is not covered by `_ETA_TERMS_PLAIN = 2` at some `m`, that is reported as the case that
resists, at its magnitude — not fixed by raising the constant until the battery goes green.
