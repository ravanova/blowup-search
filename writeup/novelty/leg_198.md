## The gate, declared verbatim, both branches, BEFORE any number is computed

`DIRECTION.md` carries no section 198 (its last word on the subject is line 117, "Next fresh
leg number for any future candidate is 198"), so following sibling legs 142/143/144 which
were dispatched into the same gap, the gate is declared here in the dispatch's own wording:

> "Under adversarial and degenerate inputs (including a degenerate or near-singular matching
> condition), does `bordered_hl.py` ever silently return a wrong value rather than reject or
> visibly propagate the defect?"

- **YES** → name the exact mechanism and magnitude; push the branch only, escalate, do **not**
  patch `solver/bordered_hl.py` (read-only under this leg's authority, under either outcome).
- **NO** → bank the battery as a permanent regression suite, append the pass to
  `capabilities.py`, land to `main`.

**"Silently" is defined before the run**, following leg 80's precedent of fixing the
predicate in advance. A return is **SILENT-WRONG** iff:

1. the function returns normally (no exception, no warning emitted), **and**
2. every returned value is finite (a returned `NaN`/`Inf` is *visible propagation*, which the
   gate explicitly excludes), **and**
3. the returned value is materially different from the honest value for the input as given —
   for the certificate constants, *materially* means **understated**, since an understated
   `Y_0`/`Z_1`/`Z_2` is the direction that fabricates a certificate. An **overstated**
   constant is conservative, is recorded with its magnitude, and does **not** decide the gate.

## Pre-registered probe families (fixed before any number was computed)

- **A. Fabrication-acceptance on `A`** — plant a corrupted approximate inverse and ask whether
  `Z_1 = ||I - AJ||` actually notices. Includes the adversarial choice `A = J^-1` computed at
  a *different* state than the `z` being scored.
- **B. The matching condition, degenerate and near-singular** — border rows made dependent
  (`Drow0` collinear with `e_{i0}`), pins set to `NaN`/`Inf`, wrong-arity pins, and
  `set_pin_from` applied to a garbage state.
- **C. NaN/Inf pass-through** — poisoned `z`, poisoned `A`, poisoned weights, through every
  one of the eight uncovered symbols.
- **D. Degenerate / zero-measure input** — zero state, constant state, `n` at its floor,
  zero-width grid, `p` at extreme values, zero and negative scalar weights.
- **E. The exact-quadratic identity under adversarial `v`** — the module's own known-answer
  check, driven at magnitudes where it should fail, to confirm it can fail.
- **F. Controls (lesson 90)** — every family carries at least one case that *should* pass, so
  a family reporting all-clean is distinguishable from a family that is not measuring
  anything. A family with no discriminating control is reported as inconclusive, not clean.

Lesson 74 is honoured: all suspects are tested in one pass, not serially.
