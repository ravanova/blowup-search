## 2. Pre-committed inclusion rule and predicate — fixed before any classification

Written before a single row was scored, because a population question is decided by who is let
in, and post-hoc admission is how a negative result gets manufactured.

**A paper is IN the MS population iff all three hold:**

1. **BLOW-UP.** It claims a *proof* (not a numerical discovery) of finite-time blow-up that is
   self-similar, asymptotically self-similar, or nearly self-similar.
2. **INVISCID.** The equation certified carries **no dissipative term** — no `−νΔ`, no
   fractional `Λ^α` damping — in the equation the theorem is about. (3D/2D Euler, 2D Boussinesq,
   compressible Euler, CLM / De Gregorio / gCLM, the Hou–Luo model all qualify; nonlinear heat,
   CGL, Landau, Navier–Stokes do not.)
3. **CERTIFIED.** The proof is computer-assisted: some step is discharged by rigorous numerics
   (interval arithmetic or equivalent) rather than by pen and paper alone.

**Peer-review status is recorded per row, and is NOT used as a filter.** A filter on
publication status is exactly the knob that could exclude a falsifier; instead every row carries
its `journal_ref` as reported by the arXiv API (or `NONE`), and the gate is answered twice —
once over all rows, once over the peer-review-confirmed subset — so the reader can see whether
the answer depends on that cut.

**The predicate, fixed here:**

```
uses_diagonal_tail(row) == row.tail_treatment == ELL1_MULTIPLIER_TAIL
    #  i.e. the linearized operator's unbounded part is inverted on a Fourier/sequence tail
    #  by dividing through by a diagonal symbol, with the finite block handled by an
    #  approximate inverse -- the radii-polynomial / Newton-Kantorovich shape.

falsifies_lesson_87(row) == row.in_population and uses_diagonal_tail(row)
```

**Lesson 90 is honoured explicitly.** Two classes of row exist that make the predicate able to
report the other answer: (a) **real** dissipative rows that DO satisfy `uses_diagonal_tail` and
fail only on clause 2, and (b) a fictitious `SYNTHETIC_CONTROL` row that satisfies both
conjuncts. Admitting the synthetic row flips the gate to **yes**. Without those, a "no" would be
a property of the script rather than of the literature.

**Every classification must carry a locator** — section/equation number plus a verbatim
sentence, or an explicitly-labelled negative string search over the full text. Leg 53 lost a
claim by reading an abstract; that is a test here, not a habit (`unlocated_rows()` must be
empty).
