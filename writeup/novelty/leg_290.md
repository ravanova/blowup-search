# Leg 290 — ROUTE-D1XN — novelty / prior-art pass

**Committed BEFORE the formal runner exists.** Branch `leg/290-d1xn-v1`, cut from `origin/main`.
Date 2026-08-07.

**Role: does D1's N-dependent coefficient have its own closed-form law?** Leg 289 found
`D1(κ) = C(N)·κ^{-1/2}` predicts held-out `κ` points to machine precision *within* a fixed `N`,
but `C(N)` itself moved by `1.90e-05` (relative) between `N=256` and `N=512` (leg 289's P2b).
Leg 289 did not test whether `C(N)`'s `N`-dependence follows a simple closed form. This leg
does, using **zero new certificate compute** — the same discipline leg 289 used.

## 1. Prior-art / data search (before any curve fit)

The brief names leg 249's and leg 281's banked sweeps as the source. Checked directly:

- **Leg 249** has no `D1` data at any `N` (confirmed already by leg 289's own novelty pass —
  leg 249 sweeps the border weight for `σ_min`/`A1`, not `D1`). Re-confirmed here.
- **Leg 281**'s `S4_group_D_dual.D1_ell_dual_norm_N512` block carries `D1` at a **single** `N`
  (`N=512`) — an 11-point `κ`-sweep at that one discretization, not an `N`-ladder. On its own
  this is **one** `N` value, which cannot constrain any curve in `N` at all.
- **Leg 288**'s `p2_route_canon_v1_convention.json` adds a second `N` (`N=256`, `P2_large_kappa_
  probe.dual_norm_D1_N256`, already used by leg 289 as its P2b cross-`N` check). Two points can
  always be fit exactly by any one-parameter family through them (e.g. any single `(A,p)` pair
  in `C_∞ - A/N^p` reproduces 2 points for a free choice of `p`) — **not a test of a closed form**
  on its own; a real test needs a third, independent `N`.
- **Widening the read (read-only, no new compute) to other already-banked JSON that leg 281's
  own file cross-references:** `writeup/data/p2_route_h2c_v1_construction.json` (leg 176,
  `C8_border_row_dual_norm.ladder`) and `writeup/data/p2_route_xun_v1_convert.json` (leg 277,
  `Q4_border_row_dual_norm.ladder`, `"repo"` column) **both already carry the same `X*`-dual-norm
  coefficient at `N ∈ {64, 128, 256, 512}`** — a genuine 4-point `N`-ladder, not 1 or 2 points.
  Cross-check: their `N=512` entry (`0.8873620087421942`) is bit-identical to leg 281's own
  `"quoted"` fitted constant for `D1`'s law, and their `N=256` entry (`0.887345112546454`) agrees
  with leg 288's independently-fit `N=256` coefficient (`0.8873451208021278`) to `8.3e-9`
  relative — three orders of magnitude below every effect tested below, so it is a legitimate
  second measurement of the same quantity, not a different one. **This is a materially bigger
  banked dataset than the brief anticipated** (4 points, not 2), and it is used here because it
  is already-banked, read-only, and zero new certificate compute — same standard as leg 289's use
  of leg 288's probe.
- **Mechanism hint already in leg 176's own text** (`C7_galerkin_inconsistency.reading`, banked
  before this leg existed): "the exact solution's Laguerre coefficients decay only like `C/n`
  ... a LOG SINGULARITY at the Mellin origin." This flags `p=1` (a `1/N` truncation term) as the
  mechanistically-motivated candidate, not an arbitrarily chosen one — it is the certificate's
  own stated truncation-decay rate for this construction, referenced in the task brief.

## 2. Candidate closed forms and falsifiable predictions, committed before running the formal script

Data available: `C(64)=0.8872380425355713`, `C(128)=0.8873117900938475`,
`C(256)=0.887345112546454` (h2c) / `0.8873451208021278` (leg288, cross-checked above),
`C(512)=0.8873620087421942`. All four values are monotone increasing in `N`, consistent with a
convergent (not divergent) truncation series — candidates below all assume convergence to a
finite `C_∞`.

- **F1 — pure power-law truncation, `C(N) = C_∞ − A·N^{−p}`, exponent free.** The
  mechanistically-motivated value is `p=1` (§1's Laguerre `C/n` decay), but the check estimates
  `p` from the data itself via the ratio of consecutive differences
  (`r = [C(4N)−C(2N)]/[C(2N)−C(N)] = 2^{−p}`) using two overlapping triples of the ladder
  (`(64,128,256)` and `(128,256,512)`). **Prediction: if a single named closed form of this
  family holds, the two independently-estimated `p` values agree with each other, and the
  3-point exact fit from one triple predicts the 4th (held-out) point to the precision these
  legs report elsewhere for genuine "exact" laws — `1e-10`–`1e-16` relative, matching leg 281's
  `fit_max_relative_residual = 1.11e-16` and leg 289's own `≤1.5e-16` held-out results.
  Falsified if:** the two `p` estimates disagree by more than a few percent of each other, OR
  the held-out prediction's relative error exceeds `1e-6` (three orders above every genuine
  "exact" law this leg family has banked, and the same falsification threshold leg 289 used).
- **F2 — `p=1` fixed (matches §1's stated mechanism), global 4-point least-squares fit.**
  **Prediction:** same precision bar as F1 (`≤1e-6` relative residual at all four points, ideally
  `1e-10`–`1e-16`) if `p=1` is the genuine underlying law rather than merely the best-fitting
  exponent among several tried. **Falsified if** the max relative residual across all four
  points exceeds `1e-6`.
- **F3 — other fixed low-integer/half-integer exponents (`p ∈ {0.5, 1.5, 2}`)**, tested as
  negative controls — included because a pattern-matched exponent (e.g. `p=1/2` echoing the
  `κ^{-1/2}` law itself, or `p=2` echoing a second-order discretization error) is a plausible
  a·priori guess that must be checked and reported even if it loses, not silently dropped.
  **Falsified (as the winning law) if** any of these has *strictly worse* max relative residual
  than F2's `p=1` fit — reported regardless of outcome.

## 3. Gate mapping

- **YES** (bank the extended law) requires: some single member of {F1 with a stable, ladder-
  consistent `p`; F2's fixed `p=1`} fits **all four** already-banked `N` values to a max relative
  residual **at or below `~1e-6`** (three orders tighter than the very effect being explained —
  the `1.90e-05` P2b gap leg 289 measured — and consistent with the `1e-10`–`1e-16` precision
  every other "exact law" in this leg family has been held to). Superseding leg 289's
  `N`-restriction by citation, not by editing leg 289's own report.
- **NO** (bank the negative) if no candidate reaches that bar: name the exact residual of the
  best-fitting candidate, in relative terms, at **every** `N` value, not just the worst one —
  "at full strength" per the task brief, not glossed over.
