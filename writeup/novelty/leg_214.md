# Leg 214 — Route-EGMB — novelty / primary-source pass

**Committed BEFORE any edit to leg 141's or leg 165's prose.**

This leg alters prose that three earlier legs banked. The one thing that could make that
alteration wrong is trusting leg 190's transcription instead of the paper. So the novelty
pass here is not a literature search — the citation is already located, read and banked by
legs 141, 165 and 190 — it is an **independent re-read of the same primary source**, done
before touching anything.

## 1. What is being changed, and on whose authority

Leg 190 (`e72842c`) re-verified Elgindi–Ghoul–Masmoudi, arXiv:1906.05811, Prop. 2.1 from the
arXiv **LaTeX e-print** rather than the PDF, and reported that the bracket is

    -(1/2 - C|a|)     — the gap DEGRADES as |a| grows

not

    (-1/2 - C|a|)     — the gap IMPROVES as |a| grows

which is what legs 141 and 165, and leg 190's own prior novelty pass, had carried. Leg 190
flagged **six** sites and patched only the one inside its own territory (its §2, corrected in
its §8). The remaining five are this leg's territory.

Leg 190's diagnosis of the mechanism: `pdftotext -layout` silently drops `\Big(` … `\Big)`,
so the PDF appears to show the minus inside the bracket. The ar5iv HTML mirror, which leg
190's earlier pass had accused of being wrong, is correct.

## 2. The independent check — this leg fetched the source itself

Leg 190's say-so is not sufficient authority to rewrite three legs' banked quotes. This leg
fetched the e-print independently:

    curl -sL https://arxiv.org/e-print/1906.05811   ->  OSWModel_Final.tex (48494 bytes,
                                                        dated 2019-06-13)

`OSWModel_Final.tex` line 356, inside the `\begin{proposition}\label{proposition:spectralgap}`
block — which is the **first proposition of `\section{Coercivity}`**, i.e. Prop. 2.1 — reads,
byte for byte:

```
\int_\RR f\MM f \phi(y)dy&\leq-\Big(\frac{1}{2}-C\,|a|\Big)\int_\RR f(y)^2 \phi(y)dy.
```

The minus sign is **outside** the `\Big(`. The bracket is `(1/2 - C|a|)`. **Leg 190's
transcription is confirmed against the primary source by this leg, not assumed.**

The same `.tex` corroborates it four more times, all consistent with a gap that degrades:

| line | text | reading |
|---|---|---|
| 356 | `\leq-\Big(\frac{1}{2}-C\,|a|\Big)` | Prop. 2.1 itself |
| 531 | `\leq -\Big(\frac{1}{2}-C\|a\|\Big)\|q\|_{L^2_\phi}^2` | §Energy, applying the proposition |
| 535 | `\leq -\Big(\frac{1}{2}-aC\Big)\|yq_y\|^2` | *"using Proposition \ref{spectralgap}"*, explicitly |
| 548 | `\leq -\Big(\frac{1}{2}-C\|a\|\Big)\|yq_y\|^2`, with *"`C` … independent of `a` (when `a` is small enough)"* | same shape |
| 608 | `\geq (\frac{1}{2}-C\alpha)\|q\sqrt{\phi_*}\|^2` | §6's `C^α` analogue — degrades in `α` identically |

Five independent occurrences, one reading. The proof structure forces it too, as leg 190
noted: EGM split `M_a = (a=0 operator) + a M̃_a` and bound `|∫ f M̃_a f φ| ≤ C ∫ |f|² φ` — an
**absolute value**, so the `a`-part can only *add* to `−1/2`, never subtract from it. And
their hypothesis *"if `a` is small enough"* is exactly the condition `1/2 − C|a| > 0`, which
is vacuous under the wrong reading.

## 3. What does NOT move

**Zero banked numbers.** The two readings agree exactly at `a = 0`:

    -(1/2 - C*0) = -0.500000  =  (-1/2 - C*0)

and `a = 0` is the only value legs 141 and 165 ever evaluated at (the CLM case, `γ = 4`,
against leg 111's `D_φ(0) = (3 − γ)/2 = −0.5`). Leg 190 quantified the divergence off axis as
`2C|a|`: `0.0000` at `a = 0`, `0.0200` at `a = 0.01`, `0.2000` at `a = 0.1`, `0.4000` at
`a = 0.2` (with `C = 1`). Invisible on axis, wrong in direction everywhere else.

So this is a **prose-fidelity repair, not a numerical correction**. No JSON, no figure, no
solver constant, no gate is affected. `solver/literature_gates.py`'s `EGM_PRIMARY_READ` row
is already correct (leg 190 wrote it correctly) and is **not touched by this leg**.
