## 5. PRE-REGISTERED: the classification predicate, and the controls that let it answer NO

Written here, before the runner exists. Lesson 90: a predicate that cannot come out the other
way is a tautology of the code presented as a finding.

**Predicate.** For a banked dead finding `F` with degree of freedom `d`, call `F`
**REALIZATION-DEPENDENT** iff the banked record contains a *different choice within `d` itself*
for which the **verdict** — not merely the magnitude — comes out differently, with both sides'
numbers banked. Three tiers are recorded separately and must not be conflated:

1. **VERDICT-DEPENDENT** — a different choice within `d` is banked in which the certificate/
   gap/bound **closes**. This is the only tier that answers the gate YES.
2. **MAGNITUDE-DEPENDENT, VERDICT-INVARIANT** — a different choice within `d` is banked which
   moves the headline number by orders of magnitude while the verdict survives. Reported as its
   own tier; it does **not** answer the gate YES.
3. **REALIZATION-INVARIANT** — every choice within `d` that the record actually tried agrees,
   on verdict and on order of magnitude.

**Falsification controls, fixed now:**

- **C1 (the audit is void if it cannot say NO).** Legs 52 and 53 are the required negative
  cases: both vary a parameter *inside the single `ℓ¹_w`-at-`s<1` realization* that leg 127
  already showed is the space-dependent one, so their internal variation is **not** a second
  realization. If the predicate returns tier 1 for all four rows, it is a tautology and the
  result is withdrawn rather than shipped.
- **C2 (the predicate must be able to say YES).** Leg 127's own row is the positive control:
  fed through the same predicate it must return tier 1 (Xu's origin-`H²` gap `1/2` against
  `σ_min → 0` in `ℓ¹_w`), since that is the finding the gate takes as given. If leg 127 does
  not come out tier 1, the predicate is mis-specified.
- **C3 (no borrowing across degrees of freedom).** A different **operator** (`μ > 0`
  dissipative, legs 53/111/126) is **not** a different realization of the same operator and may
  never be counted as tier 1. It is recorded in a separate column so the distinction is visible
  rather than assumed.

**Prediction, recorded before the runner is coded** (so the run can embarrass it):
**52 → tier 3, 53 → tier 3, 56 → tier 2, 111/141 → tier 1.** Two NOs are predicted; if they do
not appear, C1 fires.
