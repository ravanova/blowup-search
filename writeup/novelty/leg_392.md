## 0. What kind of pass this is

This leg makes **no new mathematical claim about Navier–Stokes at all.** It is a *literature*
leg: it asks whether somebody has already published a theorem that excludes the object Lane T
would have to build. The novelty verdict on the mathematics is therefore **nil by construction**,
and the only thing that can be new is **repository-local**: this repository has never searched the
periodic/torus rigidity literature (leg 390 §5 item 2), so the *state of that literature relative
to the §2 screen's four rows* is unrecorded here.

Because the deliverable is a search, the failure mode is not "claiming someone else's theorem" —
it is **fabricating a zero**. That is not hypothetical in this repository:

* **Leg 387** listed opensearch namespace `1.0` while arXiv serves `1.1`, so its harness REFUSED
  every response. A `len(entries)` implementation would have reported *"0 results, no prior art"*
  on precisely the question the leg existed to answer. Leg 387 also hit **HTTP 429**.
* **Leg 315** banked six all-zero ANDed queries as evidence for an endpoint defect that leg 314
  could not reproduce; leg 318 later measured 429-under-3s-delay as the likely cause.
* **Leg 348** initially misdrafted **2 of 7** located links as new to the repository; they were
  already here (`1902.00384` at leg 245, `2308.01528` at legs 125/163/318). Exact-id grep fixed it.

So the instrument rules below are pre-registered, not chosen after seeing results.

## 2. The instrument rules, pre-registered

1. **Every battery carries a positive control and a negative control, both fired and both logged,
   before any substantive verdict.** Positive = a query known to return many hits. Negative = a
   nonsense phrase that must return exactly 0.
2. **The AND operator is measured, not assumed** (leg 318's MF3 test): a pair of exact phrases
   known to intersect must return > 0, or every ANDed zero in the run is uninterpretable.
3. **The opensearch namespace actually served is recorded verbatim from the raw feed** — the
   leg-387 defence, made executable. The parser is namespace-agnostic by construction (regex on
   `opensearch:totalResults`), and the observed `xmlns:opensearch` URI is banked so a future reader
   can see which version answered.
4. **MEASURED-ZERO vs DID-NOT-MEASURE is a per-query field.** A query is `MEASURED` only on HTTP
   200 with `totalResults` parsed. A 429 that survives backoff, a timeout, a non-200, or a parse
   failure is `THROTTLED` / `FAILED` and **is never rendered as a zero**, in the JSON or in prose.
5. **≥ 12 s spacing** between arXiv calls (leg 348's spacing), exponential backoff on 429.
6. **Links, not counts** (MF2): every query banks the arXiv ids of its top hits.
7. **MF1**: `Navier-Stokes` is issued in both the hyphen and the LaTeX double-hyphen spellings
   wherever it appears in a battery.
8. **Every candidate identifier is grepped against this repository before being called new**
   (leg 348's own correction).
