## Instrument check (MF1/MF4 discipline, done first)

`https://export.arxiv.org/api/query` was live (probe `all:test` → 200) but produced two
different failure modes this leg had to tell apart:

1. **Transient rate-limiting** (`Rate exceeded.` plain-text body, not XML) on the very first
   attempts at `all:%22weighted+radii+polynomial%22` and `all:%22algebraically+weighted%22+
   AND+all:%22Navier-Stokes%22` — both empty. **Not trusted on the first read.** A positive
   control (`all:%22radii+polynomial%22`) run immediately after returned 7 live entries, so the
   endpoint itself was up; retried with backoff (8 retries, ~2 min) and the compound
   self-similar/Navier–Stokes query then returned 8 entries, confirming the zeros above were
   an instrument artifact, not a measurement, and are **not banked as absences**.
2. A later, controlled zero **was** trusted: `all:%22algebraically+weighted%22+AND+
   all:%22computer-assisted%22` → 0, with BOTH single-phrase controls run and confirmed
   non-empty (`all:%22algebraically+weighted%22` → 8; `all:%22computer-assisted%22+AND+
   all:%22weighted+Sobolev%22` → 2). This zero is banked as a genuine absence: nothing on
   arXiv combines "algebraically weighted" with "computer-assisted" in title/abstract text at
   this query's resolution.
