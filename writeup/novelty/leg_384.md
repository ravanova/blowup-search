physics. It does three things, all of them *reading*:

   against their own named landed records (not transcribed by eye);

   published rules.

**Honest novelty verdict on the mathematics: nil, deliberately so.** No new object, no new
bound, no new estimate. **No link of the `L1 → L4` chain moves. Clay stays ~0.05%. CEILING:
TIER 2 in both gate branches; `CLAY_OBLIGATIONS.md` §6's two no-method obligations stay OPEN

## 4. External source, and the honest risk

§7's check needs the Clay Institute's **rules of the Millennium Prize Problems**, which is a
different document from the problem statement leg 381 read. External endpoints in this
repository have been returning **HTTP 429** this cycle (legs 326 and 330 both banked refusals
with status codes). **Pre-committed here, before the fetch runs: if the rules page is
unreachable, the refusal is banked verbatim with its status code and §7 is recorded UNVERIFIED
— never as a pass, and never quietly dropped.** That is the gate's `no` branch and it is a
legitimate outcome, not a failure of this leg.

## 5. Instrument-integrity pre-commitment (the standing repo lesson)

A leg this cycle found a **fabricated zero in its own instrument** — a variable initialised to
`0.0` and never written. This leg's headline number is a mismatch count, and a mismatch count of
zero is exactly that failure shape. **Pre-committed: the runner carries a planted-mismatch
control.** Every check is re-run against a deliberately corrupted copy of the document text and
of the landed records; the control is only satisfied if the corrupted run reports a strictly
positive mismatch count on the same rows the clean run reported zero on. A green light that
cannot go red is not evidence, and this leg's JSON records the red light alongside the green.
