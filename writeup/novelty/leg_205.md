### 0.4 The dealiasing-mask class (legs 129 / 188) — checked, and it is a *different* module

Legs 129/188 raise the dealiasing-mask question for `solver/boussinesq.py`, which is
FFT-based: `grep -rn "dealias"` puts `dealias_mask2d` in
[`test_boussinesq_postrepair.py`](../../test_boussinesq_postrepair.py) and `dealias_mask` in
[`solver/spectral_utils.py`](../../solver/spectral_utils.py) / `phase2_spike0_probe.py`.
**`solver/boussinesq_rescaled.py` imports neither, and contains no FFT, no spectral
truncation and no mask of any kind** — its transport is 3rd-order upwind finite differences in
physical space on the log-polar grid, and its only spectral object is the angular DST-I of the
sibling velocity module, which is an exact bijection on grid fields (`S @ S = (M/2) I`).
The mask question is therefore carried into the battery as an **input** (family F5 below:
does any reduction in this module lose information silently?), exactly as the directive
specifies, and it is *a priori* unlikely to be the defect found here.  If the defect this leg
finds is the leg-99 origin-fit-window class instead, it is a **genuinely different defect**
under the gate's own disjunction and escalates separately.

### 0.5 In-module guards — there are none

`grep -n "raise\|assert\|isfinite" solver/boussinesq_rescaled.py` returns **one** `isfinite`,
in `RescaledBoussinesq.run` (the divergence break `if not np.isfinite(res) or res > 1e8`), and
**zero** `raise` statements in the entire 280-line file.  There is no validation of grid
occupancy, of field shape, of `c_l` finiteness, or of fit-window rank.  The module's only
protection against a degenerate grid is inherited *accidentally* from the sibling
`u_x_at_origin`'s leg-99 guard, which uses a **different window** (`r_window=0.1` vs
`r_win=0.4`) and a **different parameter count** (2 vs 3) — so the inherited guard cannot be
tight, and the size of the gap it leaves is a quantity this leg must measure, not assume.

### 0.6 Live in-repo callers of the unguarded path

The unguarded reduction is a **public** function and is called directly, outside `modulation`,
by [`experiments/p2_route_l_v1_precond.py`](../../experiments/p2_route_l_v1_precond.py)

## 2. Result — the gate answers **YES**, two mechanisms, one nine-line reduction

81 cases, **18 `SILENT_WRONG`**, 32 `OK`, 11 `RAISED`, 9 `NONFINITE`, 9 `RETURNED`, 2
`NO_REFERENT`. Every case is in `writeup/data/p2_route_bvr_v1_adversarial.json`. Both defects
live in `odd_field_x_slope` (`solver/boussinesq_rescaled.py:140-162`); they are **not the same
defect** (lesson 75), and §2.3 measures why rather than arguing it.

### 2.1 Defect A — leg 99's class, second occurrence, at the line leg 99 named

`coef, *_ = np.linalg.lstsq(A, d1[m], rcond=None)` with no occupancy and no rank check.

> Empty fit window → `(0, 3)` design matrix → `lstsq` returns `[0., 0., 0.]` at rank 0 without
> raising or warning → the function returns **exactly `0.0` against a truth of `2.0`**:
> absolute error **2.000**, relative error **100.0%**, **2000×** the module's own acceptance
> tolerance of `5e-4`. Minimal reproducer:
> `PolarGrid(n_r=200, n_beta=16, r_min=0.5, r_max=40.0)` with the module's own manufactured
> field `2·x·exp(−r²)`. Also reachable on the fully-resolved 400-node grid through the public
> `r_win` argument alone. One node against three parameters returns the minimum-norm solution
> as if it were the fit: **1.9061 vs 2.0**, relative error **4.694e-2**, **93.9×** tolerance.

The fabricated `0.0` is indistinguishable from a true answer at the call site — the zero field
genuinely has zero origin slope, and the battery confirms `odd_field_x_slope` returns `0.0`
there **correctly**. Verbatim the reading [leg 99](leg_99.md) gave the sibling's `-0.0`.

**This discharges leg 99's §4 note 2 as CONFIRMED.** It is a second occurrence of a known
class, not a new discovery, and it cross-references leg 99's escalation rather than duplicating
it.

### 2.2 Defect B — new, and it needs no degenerate grid at all

`r_win=0.4` is a hard-coded **absolute** length that never references the field's own radial
scale, and the least-squares residual that would expose the misfit is **discarded by the `*_`
on the same line**. On a **fully resolved** grid — 177 window nodes in every row — with a
smooth, in-contract, odd-in-x field `2·x·exp(−λr²)`, truth exactly `2.0`:

| field scale `1/√λ` | returned | rel. error | × tolerance |
| --- | --- | --- | --- |
| 1.0 | +2.000940 | 4.698e-4 | 0.9 — **inside**; the module's own gate lives here |
| 0.5 | +1.997847 | 1.077e-3 | 2.2 |
| 0.2 | +1.767750 | 1.161e-1 | 232.3 |
| 0.1 | +0.886782 | 5.566e-1 | 1113.2 |
| 0.05 | +0.269302 | **8.653e-1** | **1730.7** |

**It corrupts `c_l` at the coupled entry point.** `modulation` returns
**`c_l = +0.188423` against a truth of `1.4`** (rel. error **8.654e-1**, **1730.8×** tolerance)
when `omega` and `eta` carry different radial scales — finite, plausible, no warning, no
exception. The module docstring claims "the projection's quadrature bias **CANCELS** in the
ratio (same basis both reads)"; that holds only when the two fields share a radial scale.

**Why it survived to leg 205:** the module's only correctness gate,
`test_boussinesq_rescaled.py::test_odd_field_x_slope`, uses `exp(-r²)` — `λ = 1`, the single
scale at which the read is accurate — with a loose `3e-2` tolerance. `λ=1` reads 4.70e-4;
`λ=400` reads 8.65e-1, **1842× worse**, and is never run.

### 2.3 B is not A — measured, not argued

Across the whole failing sweep the `lstsq` **rank is 3 in every row** and the **condition
number is constant at 5.537e2**, while the discarded relative residual tracks the slope error
across four decades:

| λ | rel. residual (discarded) | slope rel. error | rank | cond |
| --- | --- | --- | --- | --- |
| 1 | 1.198e-5 | 3.863e-5 | 3 | 5.537e2 |
| 4 | 7.498e-4 | 1.507e-3 | 3 | 5.537e2 |
| 25 | 9.466e-2 | 1.165e-1 | 3 | 5.537e2 |
| 100 | 5.459e-1 | 5.568e-1 | 3 | 5.537e2 |
| 400 | 8.644e-1 | 8.654e-1 | 3 | 5.537e2 |

**Leg 99's occupancy+rank guard is provably blind to B.** Porting the sibling's fix verbatim
closes A and leaves B untouched. Only the residual — already computed, already thrown away —
sees it.

### 2.4 The recovery control, and the fix direction as a measurement (lesson 90)

Same field, same grid, same code; **only `r_win` varies**:

`0.4 → 0.269302` (86.5% wrong) · `0.1 → 1.766702` · `0.02 → 2.000941` (**inside tolerance**,
112 nodes) · `0.005 → 2.000999` (82 nodes).

Occupancy stays healthy throughout, so occupancy is not what changes. The function is fully
**capable** of the right answer; it lacks any way to notice its default window is the wrong
size, and any way to tell the caller. A control that comes out the other way, and does.

## 3. What the battery did NOT find — banked, with magnitudes

- **The rank-deficient-but-nonempty window is not a live defect at `modulation()`.**
  `u_x_at_origin`'s window (`r<0.1`, 2 params) is a **strict subset** of this module's (`r<0.4`,
  3 params), so an empty window here always trips leg 99's guard first. 136 gap grids
  enumerated; over **80 scored pairs** the worst `c_l` error is **1.899e-6** = **0.0038×**
  tolerance. *(A first cut of this family reported 1.45e-2 — from fields whose **resolved**
  control was itself 55.7% off, i.e. defect B leaking in. "When a control contradicts the
  mechanism, suspect the control's REALIZATION" caught it; the family was rebuilt paired, and
  160 of 240 pairs were rejected on exactly that criterion.)*
- **Nothing is swallowed on the field path.** NaN/Inf in `omega`, `eta` or `xi`, inside or
  outside the window, always reach the returned RHS (contaminated fraction 1.0 for `omega`
  plants; 6.25e-4 and 7.29e-4 for the localized `xi`/`eta` plants). All six `NONFINITE`.
- **The legs 129/188 dealiasing-mask class has no site here.** No FFT, no truncation, no mask.
  Angular DST-I round-trip relative error **3.64e-15** (random field) and **5.57e-15** (highest
  representable mode `n=16`, not annihilated). The control can report the other answer.
  **So this leg's YES is a genuinely different defect and escalates separately**, per the
  gate's own disjunction — §0.4's prediction, now measured.
- **Degenerate parameters raise rather than fabricate:** `c_l = 0/0` → `ZeroDivisionError`;
  `n_r=1`, `n_beta=1` → `IndexError`; `run(max_steps=0)` → `UnboundLocalError`; reversed radial
  interval refused at construction. 11 `RAISED`.
- **`grad_xy` and `advection_speeds` are clean** (`f = x` → `f_x` within 7.52e-4, `f_y` within
  2.58e-4; `u=v=0` → `s_rho − c_l = 0.0`, `s_beta = 0.0` exactly). The escalation stays scoped
  to the one reduction.
- **2 `NO_REFERENT`** (constant field, even-in-x field): precondition violated, no truth exists,
  so lesson 73 applies and they do not decide the gate in either direction.

## 4. Escalation notes for the orchestrator

1. **Defect A: cross-reference, do not duplicate.** Second occurrence of leg 99's class in the
   sibling leg 99 flagged and leg 104 did not patch. Same two-line fix, with **3** as the
   parameter count rather than 2. Belongs to the module owner.
2. **Defect B: escalate separately.** Measured **not** to be the legs 129/188 mask class (§3),
   so the gate's yes-branch directs a separate escalation rather than a merge into #4. The
   guard is the residual the code already computes; gate on it, size the window from the field,
   or document the precondition — a module-owner decision, not this leg's.
3. **Blast radius, flagged not claimed.** The reduction is public and called outside
   `modulation` by `experiments/p2_route_l_v1_precond.py:222-229` (which *divides* by it) and
   `writeup/3_spikes/spike1_stepB_evidence.py:84-85`; `RescaledBoussinesq.run` calls it twice
   per `renorm=True` step. **This leg re-ran no banked result and claims no banked number
   moves.** The Spike-1 profiles use `exp(-r²)`-class envelopes — the safe scale — which is a
   reason to *expect* no movement but is not a measurement of it. That needs its own leg.
4. **The battery is banked as a characterization suite**
   (`test_boussinesq_rescaled_adversarial.py`): it passes against the current unpatched module
   and pins both defects with their magnitudes. Its docstring names the four tests whose
   expectations must flip **in the same commit as any fix** — leg 99's precedent, leg 104's
   execution. `capabilities.py` is untouched: recording a passing battery there is this gate's
   **no** branch, and the gate answered **yes**.
