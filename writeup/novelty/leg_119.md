# Leg 119 — Route-HHA novelty pass (run and committed BEFORE construction)

**Date:** 2026-08-06. **Agent:** LEG-P. **Branch:** `leg/119-hha-v1`.
**Verdict: `PROCEED_AS_SOUNDNESS_AUDIT`.**

This leg builds no new mathematics, sharpens no bound, and claims no novel mechanism. It
audits one *direction* property of `solver/hilbert_holder.py`: whether the weighted-Hölder
majorant on `psi = H(h)` can ever be **exceeded** by the true weighted increment ratio, on a
case where both sides are computable. `solver/hilbert_holder.py` is READ-ONLY under this leg,
under either branch of the gate. The plan-of-record ban *"another Route-D bound-sharpening
leg" (lifted by: B, not yet reached)* is respected literally: **nothing here makes any
constant smaller**, no `b_sup`, `b_semi`, `C_Q`, `‖A‖`, `Y_0`, `Z_1` or `Z_2` value is
re-derived as an improvement, and no new majorant is proposed. The direction under test is the
safe one — the leg can only ever report that the existing bound is weaker than advertised,
never that it is stronger.

## 1. What the object is, and where the soundness surface lives

`solver/hilbert_holder.py` bounds the **codomain** seminorm — the weighted Hölder seminorm of
`psi = H(h)` itself, not of `h` — which is the last constant `C_Q` needs (module docstring,
lines 1-20). Its two pair-level building blocks:

* `increment_pair_bound(theta1, sigma, alpha, gamma, n_quad, eps)` — `(u_S, u_T)` with
  `w_{1-gamma}(th_inner)|psi(th1)-psi(th2)|/d^gamma <= u_S*S + u_T*T`, valid only where
  `near_padding` accepts the pair (`increment_regime`); built from `_increment_env`'s
  point-by-point choice `take_T = (cT <= cS)` between a **seminorm-account** envelope `cT`
  and a **sup-account** envelope `cS`, exactly the same shape of rule as
  `hilbert_pointwise.py`'s `take_T = rho*cT <= cS` that leg 106 found unsound — except here
  there is no `rho`, the comparison is always at unit weight, and the two accounts are the
  same `cS`/`cT` forms (`cS = cos^alpha(a_phi/2)+cos^alpha(a_ref/2)`,
  `cT = dphi^gamma * cos^(alpha-gamma)(inner)`).
* `pointwise_pair_bound(theta1, sigma, alpha, gamma, curves)` — the wide-pair fallback, built
  from `solver.nk_seminorm.hilbert_split_bound` (a *different* module, out of this leg's
  territory and not itself re-audited here — only its composition inside `hilbert_holder.py`
  is in scope).

`hilbert_holder_constant` assembles both routes over a pair grid into `(b_sup, b_semi)`, and
`quadratic_constant_full` / `cq_sup_split` carry that into the full `C_Q`. **Every one of
these is bound-bearing** and in this leg's territory to test (read-only).

Because `cS` does **not** vanish as the pair separation `dphi -> 0` (same structural fact leg
106 used: `cS -> 2cos^alpha(inner/2) != 0`), the near-singularity region is only tamed if the
comparison actually selects the `cT` route there, which needs `dphi^gamma -> 0`, i.e.
**`gamma > 0`**. So the a-priori suspect channel, named before any code was run, is:

  **gamma <= 0 (or gamma non-finite) lets the near-pole mass get charged to the sup account,
  whose integral is log-divergent — and `increment_pair_bound`'s quadrature starts at
  `s = eps*lo`, not `0`, so a finite-looking `(u_S, u_T)` may be nothing but an eps-truncation
  of a divergent integral.**

That is a direct structural analogue of leg 106's V2 (`gamma = 0` on the *pointwise* bound),
transplanted to the *codomain-seminorm* bound with its own kernel, its own pair geometry
(`E_N + E_F + G`), and no `rho` parameter to poison instead.

**The thesis was right about the direction and about where.** The novelty pass named the
`_increment_env` routing rule as the structural analogue of leg 106's `take_T = rho*cT<=cS`,
and predicted `gamma <= 0` would be the live channel — it was, on the first configuration
tried, with no `rho`-style parameter needed. Unlike leg 106's pointwise sibling (which had a
genuinely marginal `gamma = 0.01` where its eps-drift diagnostic disagreed with the exact
predicate), this module's diagnostic and its `gamma > 0` predicate never disagreed at any
`gamma` tried, including `0.05`, the closest positive approach.

**The unexpectedly clean positive result**: the shipped and production configurations do not
merely dominate, they dominate with the SAME sign of asymptotics as `delta -> 0` that V1/V2
lack — the ratio falls toward zero rather than approaching one, because `gamma > 0` makes the
reported `T` grow faster than the true increment as the adversary's feature narrows. This is
a qualitatively different (safer) margin structure than leg 106 found on the pointwise
sibling, where the shipped configuration's margin was asymptotically saturated (ratio
`0.9999` as θ→π) rather than falling away.

**Non-claims honoured.** No constant was improved, no majorant sharpened, no `b_sup`,
`b_semi`, `C_Q`, `‖A‖`, `Y_0`, `Z_1` or `Z_2` re-derived; `solver/hilbert_holder.py` is
byte-identical to what this leg found. The soundness predicate is stated (`gamma > 0`) but
the guard is left for whoever has the authority to land it.
