## R2 — the independence requirement, and how it is met

The failure mode a verification leg exists to catch is **leg 241's runner agreeing with
itself**, and here specifically **leg 241's prose agreeing with leg 241's prose**. Re-running
`experiments/p2_route_pcrc_v1_cleanup.py` would prove nothing, and re-reading line 49 would
prove almost nothing. So:

1. **The decisive check never reads the runner's source at all.** It re-derives every stall
   number **order-immune**, from the banked JSON, keyed on `m` (`min(rows, key=m)` /
   `max(rows, key=m)`) rather than positionally, in code written here, and compares against
   the **published** `stalls` / `ranked` blocks under exact `==` on raw float64. If the
   published numbers *are* the order-immune numbers, Route-L's headline is unaffected for a
   reason that does not depend on trusting any source line, any literal, or leg 241.
2. **The source audit is mechanical and exhaustive, not a citation.** Every `dims=` argument
   and every `krylov_ladder` call site in Route-L's runner is enumerated by **AST parse**,
   not by grep or by eye, so the ascending-literal property is established over *all* call
   sites including line 180, which leg 241's table does not cover.
3. **All 11 banked ladders are audited**, not the 5 leg 241 measured.
4. **The headline is decomposed before it is judged.** The exact sentence in
   `TECHNICAL_P2_ROUTEL_V1.md` is quoted, each number in it traced to the banked key it comes
   from, and each classified as order-sensitive or order-invariant — so "unaffected" is a
   statement about named numbers, not about a route name.
5. **A control column that can report the other answer (lesson 90).** The same audit is run
   against a deliberately descending ladder built here. If the audit cannot flag that one, it
   has not tested anything, and this leg's YES would be worthless.
