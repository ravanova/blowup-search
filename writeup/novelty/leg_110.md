**Date:** 2026-08-06. **Agent:** LEG-C. **Branch:** `leg/110-l1r-v1`.
**Verdict: `PROCEED_AS_BOOKKEEPING`.** This leg claims **no new science**. It re-derives
already-banked headline numbers of the two `L1` death certificates (coefficient basis, leg

Per `writeup/novelty/README.md`: **links, not counts.** Every query string below is verbatim

## Why a pass at all, when nothing new is claimed

The proposition "`L1` is dead in both realizations" now carries more load than any other
negative in this repository: it gates the plan of record's sequence, it is the stated lift
condition on stage `V`'s ban (*"unless the question is re-posed for a FLUID transport model,
which needs `L1` first"*), and it is the framing premise of `NG`. So the pass asks the one
class of question that could **lift** that ban from outside this repository:

* **(a)** has anyone published a radii-polynomial / `ℓ¹`-Fourier certificate whose *unbounded*
  part is an off-diagonal **shift** (no diagonal to invert) — the exact structural obstruction
  legs 51–54 measured (lesson 87)?
* **(b)** has anyone published a **sup-norm collocation** certificate that carries a discrete
  Hilbert-transform consistency defect inside a `Y₀`-style budget — the exact obstruction leg
  56 measured?
* **(c)** is there a standardized methodology for the thing this leg *does* — a forensic
  re-derivation of a published paper's own quoted numbers from its archived data — that this
  leg should follow rather than invent?

## Queries, verbatim, with the links returned

### Q1 — for (a)
`radii polynomial certificate unbounded part off-diagonal shift operator inviscid self-similar transport ell^1 Fourier tail estimate`

- https://www.sciencedirect.com/science/article/abs/pii/S0167278916000294 /
  https://www.researchgate.net/publication/274374610_Automatic_differentiation_for_Fourier_series_and_the_radii_polynomial_approach
  — *Automatic differentiation for Fourier series and the radii polynomial approach*: the
  standard framework, and it assumes the diagonal-multiplier tail throughout. **Confirms the
  assumption is standard**; it is the same null legs 51/52 recorded.
- https://arxiv.org/pdf/2404.15995 — Vishik nonuniqueness for forced 2D Euler; the linearized
  operator is split into a **transport** operator plus a compact operator, which is the same
  structural reading as lesson 87 — but this is not a radii-polynomial certificate and supplies
  no tail estimate for the shift part.
- https://arxiv.org/pdf/2502.10274 — unstable vortices / sharp non-uniqueness for SQG; same
  comment: transport-plus-compact structure, no `ℓ¹`-Fourier tail bound on the shift.

**On-topic for (a): none.** No result exhibits a certificate whose unbounded part is a shift
with a non-decaying tail inverse. This is the same null leg 57 banked as an executable ledger
(4 papers, 15/15 gates). **Nothing lifts the coefficient-basis death from outside.**

### Q2 — for (b)
`sup-norm collocation validated numerics Hilbert transform discrete consistency defect certified blow-up profile 1D model`

- https://arxiv.org/pdf/2201.06780 — neural-network self-similar profile for 3D axisymmetric
  Euler; the Hilbert-transform-type nonlocality is handled with **third-order Lagrange
  interpolation** to cut truncation error. Adjacent in mechanism (interpolation order sets the
  defect rate, exactly leg 56's order-4.01 spline finding) but it is **not certified** — no
  admissible-`τ` budget is claimed, so it cannot discharge leg 56's gap.
- https://link.springer.com/article/10.1007/s00211-020-01125-z — validated blow-up via
  quasi-homogeneous compactification; https://arxiv.org/pdf/2103.12390 — saddle-type blow-up
  with computer-assisted proofs. Both are **finite-dimensional vector fields** with Lyapunov
  validation; neither carries a nonlocal operator whose discretization must be consistent with
  a derivative in the same norm.
- https://arxiv.org/pdf/1910.12472 — rigorous numerics for nonlinear heat equations in complex
  time; local (no Hilbert transform).

**On-topic for (b): none.** Nothing in print carries a certified sup-norm collocation
realization for a Hilbert-transport operator. **Nothing lifts the collocation death either.**

### Q3 — for (c)
`reproducibility audit computer-assisted proof published numbers re-derived from archived data discrepancy validated numerics`

- https://arxiv.org/html/2607.25589v1 — *Forensic Reproducibility Audit of a Radiology
  Vision-Language Model Benchmark: From Intended Protocol to Released Artifact.* **The closest
  methodological prior art for what this leg does**: a from-the-artifact audit of a published
  result's own numbers. Its own stated limitation — a single case cannot estimate the base rate
  of such failures — is exactly the ceiling this leg must respect: leg 60 found 3/114 in one
  pair of writeups, and that says nothing about the rate here.
- https://arxiv.org/pdf/2606.09500 — *Deterministic Integrity Gates for LLM-Assisted Clinical
  Manuscript Preparation.* Extracts numerical claims from prose and matches them against locked
  analysis tables **by deterministic script**, reporting exact / partial / untraceable buckets.
  This is the same three-bucket shape leg 60 used (re-derives / substantive / last-digit), which
  is mild independent support that leg 60's ledger design is the right one to reuse — **and the
  reason this leg reuses it rather than inventing a tolerance rule.**
- https://dthain.github.io/papers/repro-survey.pdf — *Reproducibility in Scientific Computing*
  survey; https://cacm.acm.org/opinion/incentivizing-reproducibility/ — general incentives.
  Background, no method to adopt.
- https://computational-science.mpsd.mpg.de/docs/reproducibility.html — reproducibility archives
  organized so numerical data + scripts regenerate reported figures and tables; this is the
  structure `writeup/data` + `experiments/*_evidence.py` already has.

**On-topic for (c): yes, two.** Neither pre-empts a claim (this leg makes none); both say the
practice is real and that the **tolerance rule must be fixed before the comparison**, which is
the one design decision this leg inherits from leg 60 verbatim: the tolerance is **half a unit
in the last digit of the string the document actually prints**, derived from that string, with
no global relative tolerance anywhere.

## What this pass settles

Nothing lifts either half of the `L1` death from outside, and nothing in print pre-empts either
negative. The leg proceeds as **pure bookkeeping**: re-derivation only, no new measurement, no
new claim, no ban lifted under either branch. The only thing that can come out of it that is not
already banked is a **discrepancy** between the prose and the stored data — and a discrepancy is
a defect report, not a novelty claim.
