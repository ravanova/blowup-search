## Part 1 — how the candidate set was closed (methodology, not conclusion)

Two independent enumerations, so the candidate set is closed by construction rather than by
whichever query happened to fire.

**(A) arXiv API author queries, full listings, newest first, read entry by entry** — not
keyword searches, so a follow-up with an unexpected title cannot be missed:

* `http://export.arxiv.org/api/query?search_query=au:"Cao-Labora"&max_results=40&sortBy=submittedDate&sortOrder=descending`
  — **11 entries**, complete career listing, newest `arXiv:2608.05114` (2026-08-05, Schiffer's
  conjecture).
* `http://export.arxiv.org/api/query?search_query=au:"Gomez-Serrano"&max_results=60&...`
  — **46 entries**, newest `arXiv:2605.18699` (2026-05-18). One false positive by name
  (`2108.11284`, Vicente Gómez-Serrano, battery chemistry) — noted, not counted.
* `http://export.arxiv.org/api/query?search_query=au:"Buckmaster"&max_results=60&...`
  — newest math entry `arXiv:2511.22819` (2025-11-28); the listing is polluted by an unrelated
  Dennis/Gabriel Buckmaster (agriculture, gaze-contingent AI), which is why the narrower
  `au:"Buckmaster_T"` form was **discarded — it returned only 2 entries and would have hidden
  everything after 2016**. Recorded because a query that silently under-returns is the failure
  mode this repository keeps re-learning.

**(B) The author-maintained publication list**, which carries journal status the arXiv listing
does not: <https://sites.brown.edu/jgs/papers/> — every paper 2022→2026 with journal reference
and submitted/published status. Cross-checked against (A); no entry appears in one and not the
other.

**(C) Targeted web queries**, to catch anything not on either list (a journal-only paper, a
different arXiv account, an announcement):

1. `Buckmaster Cao-Labora Gomez-Serrano imploding Navier-Stokes viscous term interval arithmetic 2026`
2. `computer-assisted proof enclosing viscous term compressible Navier-Stokes implosion follow-up`
3. `arXiv 2208.09445 cited by Navier-Stokes implosion viscosity "interval arithmetic" 2026 new computer-assisted`
4. `Cao-Labora Gomez-Serrano 2026 compressible Navier-Stokes self-similar profile computer assisted proof viscosity enclosed`

These surfaced **one** paper on exactly the object that neither listing carries, by a
**different** group — <https://arxiv.org/abs/2501.15701> — which is out of the gate's scope but
is read anyway below, because it is the sharpest available control on the mechanism.

## Part 3 — the prior-art verdict

**No leg of this repository has previously asked whether `2208.09445`'s group upgraded the
viscous treatment.** Leg 172 held `2310.05325` and read its *abstract*; leg 174 built the
Grade-A/Grade-B matrix on `2208.09445` alone; leg 197 banked the row. This leg's contribution —
`2310.05325` read at **full text specifically for its viscous-term treatment**, plus the closed
candidate enumeration — is novel to this repository.

Against the external literature the leg claims **no** mathematical novelty: it constructs
nothing, and its output is a characterization of published work. That is the intended shape of a
literature-typed leg.

**Bans checked before starting** (`plan_of_record.py` run first, output read in full): no gCLM
measurement, no Route-D sharpening, no DSS re-ask, no GA compute, no ℓ¹-Fourier or collocation
machinery, no re-claim of leg 51's finding, nothing built without grepping `capabilities.py`,
`solver/viscous_novelty.py` **read-only** (leg 197 owns it; this leg does not edit it). The
stage-`V` tripwire is **not** tripped: no certificate is built and no parameter is floated
against any margin.
