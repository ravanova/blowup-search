## What is being checked

obstructions at equal strength. The third is the only *theorem*: **Chae–Tsai**, carried at

This pass asks three things before any adjudication is attempted:

1. **Which paper is it?** Leg 313 banked the item by author names and a description, with

3. **Is there any other rigidity result** on backward DSS/NS that leg 313's net missed, which

## Instrument controls (run first, both directions)

* **Positive control, arXiv export API over HTTPS.** `search_query=all:electron&max_results=1`
  → HTTP 200, 2938 bytes, one `<entry>`. Instrument alive.
* **Negative/route control on the same endpoint over HTTP (not HTTPS).**
  `http://export.arxiv.org/api/query?...` → empty body, silently. **Banked as an environment
  fact: the plain-`http` export endpoint returns nothing here; use `https`.**
* **429 is an error, not a zero.** `au:"Chae" AND au:"Tsai"` on the export API returned
  **HTTP 429** on nine consecutive attempts across `curl` and `urllib` with backoff, while the
  `all:electron` control returned 200 in the same window. **Nothing was banked from those
  attempts** — a 429 is a refusal to measure, not a measurement of absence. (Leg 313 hit the
  same 429 wall and abandoned the lane; this leg records *why* it is not an absence.)
* **The arXiv web search UI was used instead, and it was controlled.**
  `"discretely self-similar"` alone → **129 results**, non-empty. Compound
  `"discretely self-similar" "backward"` → **5 results**, non-empty, and it contains the two
  papers the single-phrase query would have buried. **So ANDed quoted phrases DO return
  results on this endpoint** — the struck MF3 clause is refuted here a second time,
  independently of leg 314's export-API refutation.
* **MF1, measured, and it bit exactly where the brief predicted.** The query
  `"discretely self-similar" Navier--Stokes nonexistence backward` (LaTeX **double** hyphen)
  → **0 results**, with arXiv's own page volunteering the diagnosis ("A likely cause is the
  double hyphen"). The single-hyphen variant
  `"discretely self-similar" "Navier-Stokes" nonexistence backward` → **also 0**, and the
  two-phrase control above → 5. **So the double hyphen is a real hazard on this endpoint, and
  this particular zero is a term-conjunction artefact, not an absence: the same subject matter
  is reachable in 5 hits from the controlled two-phrase query.** Banked as a measurement of
  the *instrument*, not of the literature.
* **A generic author query is a broken instrument and is recorded as such.** `Chae Tsai` on
  the web UI → 76 results, almost all unrelated (LIGO collaborations, NTIRE challenges,
  Gemini model cards) because it matches *any* author named Chae **or** Tsai. It reports
  **"Coauthored by both Dongho Chae and Tai-Peng Tsai: none"**, which is **FALSE** — the
  targeted query below finds the paper immediately. **Recorded as a false negative from an
  unconstrained query; nothing was banked from it.**
* `https://arxiv.org/a/tsai_t_1.html` → a *different* Tsai (Tsung-Hsuan Tsai, group theory);
  `https://arxiv.org/a/tsai_t_2.html` and `https://arxiv.org/a/chae_d_1.html` → **HTTP 404**.
  The author-listing lane is unusable here and nothing was banked from it.
