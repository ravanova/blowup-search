## 2. External half — is there any published reading under which `n = 3` survives?

Leg 120's own pass (`writeup/novelty/leg_120.md`) and leg 129's (`writeup/novelty/leg_129.md`,
read this pass off the parked branch via `git show`, **read-only**) already settled the prior
art for the *rule*. **Neither is re-run; both are carried**, with their two standing findings
intact: (i) **no published source prescribes the non-strict cut** — leg 129's (R1); (ii) the
repair *form* `(n-1)//3` is **UNPUBLISHED**, so it is justified arithmetically and not cited —
leg 129's (R2), which its runner proves exhaustively over `n = 1..5000` rather than asserting.

What neither pass asked, and this one must, is the **small-`n` end**: does the literature say
anything about a grid so small that the alias-free band is empty?

### Q1
`2/3 rule dealiasing minimum number of modes N=3 degenerate only mean mode retained pseudospectral`

- https://www.math.umd.edu/~tadmor/references/files/Hou%20&%20Li%20filter%20vs%202-3%20rule.pdf
  and https://www.sciencedirect.com/science/article/abs/pii/S0021999107001623 — Hou & Li,
  *Computing nearly singular solutions using pseudo-spectral methods*.
- https://fourierflows.github.io/FourierFlowsDocumentation/stable/aliasing/ — FourierFlows.jl, *Aliasing*.
- https://kth-nek5000.github.io/kthNekBook/_md/spectral/pseudo.html — KTH, *Pseudo-spectral method and aliasing errors*.
- https://arxiv.org/abs/math/0701337 — Hou & Li.
- https://arxiv.org/pdf/2603.08892 — *Aliasing and phase shifting in pseudo-spectral simulations of the incompressible Navier–Stokes equations*.
- https://www.researchgate.net/publication/290229199 — *The need for de-aliasing in a Chebyshev pseudo-spectral method*.

### Q2
`Orszag two-thirds rule alias-free condition N >= 3K+1 strict inequality smallest admissible grid`

- https://math.jhu.edu/~feilu/notes/DealiasingFFT.pdf — Fei Lu (JHU), *De-aliasing in Fast Fourier Transform*.
- https://publications.aston.ac.uk/id/eprint/16380/1/The_rule_for_dealiasing_in_the_split_step_Fourier_methods_for_n_wave_interactions.pdf
  — *The (n+1)/2 rule for dealiasing in split-step Fourier methods for n-wave interactions*.
- https://arxiv.org/pdf/2302.08694 — *A Fourier spectral immersed boundary method with exact translation invariance*.
- https://arxiv.org/pdf/2511.21891 — *GANDALF*.
- https://arxiv.org/pdf/2506.06200 — *Accurate N-body simulations with local primordial non-Gaussianities: initial conditions and aliasing*.
- https://www.cfd-online.com/Forums/main/104795-orszag-2-3-rule.html — CFD-Online, *Orszag 2/3 rule*.

**Finding (E1): the small-`n` end is UNADDRESSED in the corpus.** Not one source discusses a
minimum admissible `N`, a degenerate retained band, or what a solver should do when the
alias-free band contains only the mean mode. Every source states the rule as an asymptotic
resolution statement (*"retain 2/3 of the modes"*, *"effective resolution 2N/3"*). **So there
is no published authority to appeal to on the specific question of `n = 3`** — which means the
gate cannot be settled by citation and must be settled by derivation. That is recorded now so
the analysis is not later credited with a literature result it does not have.

**Finding (E2): the one recorded loose-wording codebase does NOT rescue `n = 3`.** Leg 129's
pass flagged FourierFlows.jl's looser wording as *unresolved rather than as a counter-authority*.
Fetched this pass: it specifies `dealias!` as *"zero-out the highest-`aliased_fraction`
wavenumber components"* with `aliased_fraction = 1/3` by default, and the docs **"do not
explicitly state the mathematical inequality"** (strict vs non-strict). It stays unresolved as
an inequality — but as a **fraction-of-modes** rule it is not a reading under which `n = 3`
keeps a non-constant mode either: one third of three modes is one, and the two non-constant
modes `k = ±1` are the highest. This is checked arithmetically in the runner, not asserted
here. arXiv:2603.08892's form (zero `|k| >= (2/3)k_Nyquist`) is likewise **strict-side**.
