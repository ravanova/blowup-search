### 4b. The decay-class predicate |Ω(θ=π)| is measured dead

The natural threshold-free-looking guard for M2: the gauge fixes `Ω(θ=0) = -1`, so
`|Ω(θ=π)| = |Σ (-1)^k A_k|` is the interpolant's value at `X = ∞`, exactly 0 for the a=0 anchor
and exactly 1 for the constant. It separates at J=60 — and then closes at higher resolution:

| case | `|Ω(π)|` |
| --- | --- |
| clean a=0.0, J=60 | 2.290e-16 |
| clean a=0.5, J=60 | 6.806e-03 |
| clean a=0.5, J=120 | 2.024e-03 |
| **clean a=0.5, J=240** | **1.051e-01** |
| clean a=0.55, J=60 | 6.414e-02 |
| **spurious, M1's third root (om0=0.1·anchor)** | **7.786e-01** |
| spurious, the constant (om0=zeros/ones) | 1.0000 |

A **clean, production-reachable** input (a=0.5, J=240) sits at 0.105, within **7.4×** of M1's
spurious 0.779. There is no threshold here that does not move a clean result. **Rejected.**
`norm_domain(·, α=2)` — the quantity leg 114's own M2 pin uses — fails the same way: clean a=0.5
J=60 gives **32.53** against the a=0 anchor's 1.0000, and clean a=0.55 gives **369.6**.

### 4c. The M3 "sustained crossing" predicate is measured dead

For `critical_radius`, the tempting fix is to require the sign change be sustained (the adversary
is a *one-point* dip). Measured run lengths after the first crossing:

| field | sustained run | depth after crossing / max|E| |
| --- | --- | --- |
| **real, a=0.15** (Xc=51.8456) | **1** | 1.229e-01 |
| real, a=0.2 | 2 | 4.332e-01 |

A **real** crossing at a=0.15 has run length 1 — identical to the adversary. A run-length test

*"a magnitude threshold on the crossing relative to |E|"* — the **relative depth**: 1.229e-01
(worst real) against 2e-03 (worst adversary), a 61× gap.

### 4d. What survived: the module's own full-residual quantity

`newton_gauged` already computes `relres = rms(R) / rms(Ω·HΩ)` over **all J rows, including the
dropped one** — and then never consults it when setting `converged`. It separates:

| case | `relres` |
| --- | --- |
| clean, worst over a ∈ {0…0.5} × J ∈ {60,120,240} | **5.05e-02** (a=0.5, J=60) |
| spurious, M1's third root | **1.257e+01** |
| spurious, the constant from `om0=zeros` | 1.322e+01 |
| spurious, the constant from `om0=ones` | 1.314e+01 |

**249×**, two-sided, at the *relative* strength leg 114 asked for and the absolute form of §4a
cannot deliver. This is the adopted M1/M2 predicate, and it is the clause-(a) OR-branch
literally: *report a residual that accurately reflects non-convergence*.

One honest caveat recorded **before** construction: for the constant, `relres` is a ratio of two
quantities that are both at the noise floor (`Ω·HΩ ≡ 0` for a constant, so the denominator is
roundoff). Lesson 86 applies — a quantity dominated by its own evaluation error is a statement
about the code. The repair therefore needs an explicit **referent test** on the denominator
(lesson 73: when a quantity has no referent, say so instead of bounding it) rather than the
current `or 1.0` fallback, which fabricates a referent of exactly 1.0 out of a zero scale. That
same fallback is the mechanism behind `KNOWN GAP` #5 (`relres` identically 1.0 at c=0).

## 5. Literature — no mathematical novelty is claimed by this repair

All three remedies are standard numerical-software practice. Located, with links, so the leg
claims nothing:

- **Farrell, Birkisson & Funke, "Deflation techniques for finding distinct solutions of nonlinear
  partial differential equations", [arXiv:1410.5620](https://arxiv.org/abs/1410.5620), SIAM J.
  Sci. Comput. 37(4), 2015.** States as the baseline that a nonlinear PDE system "may permit
  several distinct solutions" and that the standard approach is many starting guesses in
  different basins. So the *existence* of M2's second root is textbook, not a discovery; what
  leg 114 found and this leg repairs is that the module returns it with `converged=True` **and**
  a small certificate-visible defect.
- **Press et al., *Numerical Recipes*, ch. 9 (Root Finding and Nonlinear Sets of Equations),
  [PDF](http://cosmos.phy.tufts.edu/~danilo/AST51/Material/RootFinding.pdf).** Records that a
  bracketing sign test can have "opposite signs at points that bracket a singularity rather than
  a root", i.e. a bare `sign` change carries no magnitude information — M3 exactly, and the
  standard remedy is the magnitude test §4c adopts.
- **"Robust Zero-crossings Detection in Noisy Signals",
  [arXiv:2301.07703](https://arxiv.org/pdf/2301.07703).** Independent statement that bare
  zero-crossing detection is known-insufficient under noise.
- **scipy [issue #6379](https://github.com/scipy/scipy/issues/6379)** — function-value (residual)
  convergence criteria as a recognized design axis in production root-finders, i.e. §4d's
  "consult the residual you already computed" is a known pattern, not an invention.

Searches run: *"Newton convergence criterion computed on deflated subsystem misses dropped
equation spurious root gauge condition"*; *"root bracketing sign change detection without
magnitude test spurious root robustness numerical software"*; *"arXiv 1410.5620 deflation
nonlinear PDE spurious solutions Newton convergence"*. No published treatment of the specific
combination — a **gauged collocation** system whose dropped row is simultaneously the row the
certificate's `Y_0` is made of — was located; that combination is not claimed as novel either,
because it is a property of this repository's construction, not of the literature.
