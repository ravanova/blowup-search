## 4. The sweep's robustness, and its blind spots

Robustness is a **claim about the instrument**, so it is stated as one. Case-insensitive
(`re.IGNORECASE`, all 13 patterns); wrap-immune (whole-file stream, all whitespace **and**
wrapped-blockquote markers collapsed before matching, so the 100-column hard wrap cannot hide a
phrase); hyphenation-tolerant (intra-phrase spaces written `[-\s_]+`; module names match across
`[-_.]`). **1,236 files.**

The blind spots are part of the result and are recorded in `CORRECTIONS.md` §9: five text
extensions only, `*`/backtick/`|` treated as separators, and no coverage of a paraphrase carrying
none of the patterns' anchors. **One pattern was found to backtrack catastrophically and was
rewritten** (`six[-\s_]+(?:[-\s_]+\w+){0,3}` → `six[-\s_]+(?:\w+[-\s_]+){0,3}`, an ambiguous
overlap) — a sixth instrument failure in the same family, logged rather than hidden, since it
would have produced a silent no-result had it merely been slow enough to abandon.
