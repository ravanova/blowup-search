# Novelty pass — leg 419, unit `U3` (`ORCHESTRATION.md` §3c, §3k)

**Run BEFORE construction, and committed before the module it gates existed.**

## What this unit builds

`solver/arc6_residual_ledger.py` — an **exact-rational scaling ledger** for the momentum residual
of a concentrating axisymmetric blow-up ansatz, parameterised by one exponent `h`, together with
the pulse-amplitude balance, the energy/dissipation conditions, the correction-cycle exponent
recursion, and a **contrast column for this repository's own route-4 DSS object**.

**Every quantity is a linear polynomial `a + b·h` over `Fraction`.** No floating point appears in
any exponent, so a balance either holds **exactly** or fails, and there is no tolerance to widen.
That is deliberate: `ORCHESTRATION.md` §3f names *"exact/rational arithmetic where the problem
admits it"* among the few defences that survive solo mode, and an exponent ledger admits it.

## Is it already built — here?

**No.** `capabilities.py` was grepped before a line was written (`dss`, `residual`, `scaling`,
`exponent`, `similarity`). What exists:

| existing module | what it holds | why it is not this |
|---|---|---|
| `solver/dssp_step.py` | the rescaled-vorticity Galerkin ODE `c' = αc + βc²`, `α = −19/16` exact | a **dynamical** truncation of one mode. Carries no exponent algebra and no residual ledger. |
| `solver/dssp_screen.py` | `l3_norm_ladder`, `fitted_far_field_decay_exponent`, the rigidity ledger | measures a **realised field numerically**. Its exponents are *fitted*, not exact, and it screens against published theorems rather than balancing a residual. |
| `solver/dssp_biot_savart.py` | the closed-form Type-I witness `Ω_B`, `u_B`, `α = 1` | the **object** this unit's contrast column is about. Unmodified and imported read-only. |
| `solver/decay_grading.py`, `solver/finite_support.py` | decay grading, support machinery | neither carries a momentum-residual term ledger. |

**Nothing in this repository has ever written down the term-by-term scaling of a
Navier–Stokes momentum residual as exact arithmetic.** `WALLS.md` `W4`'s numbers — leg 381's
`α > 1.5` bill against an a-priori `α = 1.0`, deficit `0.5` — are *one* exponent comparison,
recorded as prose. This unit makes the comparison a computation with controls.

## Is it already built — outside?

**The mathematics is not claimed novel and is not this unit's.** The scaling relations are read
off OpenAI's manuscript (§§2–3, fetched and hashed at leg 417) and **re-derived here rather than
transcribed**: the module recomputes each balance from the geometry and the profile exponents and
**checks the manuscript's stated value against its own**, so a transcription error surfaces as a
failing assertion rather than as agreement.

What is new **to this repository** is (i) that the ledger exists as executable exact arithmetic
at all, and (ii) the **contrast column** — the same ledger applied to this repository's own
route-4 object, which is where `W4` lives. Both are facts about **this record**, not about the
literature, so no external novelty search was required for them.

**No external novelty claim is made, therefore no external search was run.** Similarity-variable
scaling ledgers for concentrating vortices are standard practice in the blow-up literature
(Giga–Kohn onward); this repository would not claim one as new and does not.
