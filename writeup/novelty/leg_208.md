### Q2 (run 2026-08-06)

**Honest limit of Q2, stated rather than papered over:** the returned surface text confirms the
`Y_0 / Z_1(r) / Z_2(r)` bound structure but **does not** print the sign hypotheses verbatim, and
**this leg did not fetch and read any of these at full text** — `Papers/` holds no cached copy
(only `fetch.sh` and `MANIFEST.md`). So the audit does **not** rest on a literature claim about
sign hypotheses. It rests on something local and checkable instead: `Y_0`, `Z_1`, `Z_2` are
defined **in this module's own comment** as the norms `‖A F(x)‖`, `‖I − A DF(x)‖`,
`‖A(DF(v) − DF(x))‖` — norms are non-negative by definition, so a negative value for any of them
is not a regime, it is **input that cannot arise from the quantities the code says it takes**.
That is the standard the battery holds `radii_polynomial` and `y0_budget` to, and it is derived
from the module, not asserted about a paper this leg did not read.
