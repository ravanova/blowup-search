the committed sequence. A same-count, different-content pairing is exactly the condition under

## 4. Lesson 90 applied in advance — what could make this audit report the other answer

A hygiene audit whose predicate cannot fail is a tautology of the code (lesson 90). Stated
before the runner is written, the concrete ways this leg's gate could answer **YES** (no
drift): every `DIRECTION.md` open question and every parked branch resolves to a matching
`PROGRESS.md` item under the item-matching predicate, and every `PROGRESS.md` item resolves
back. Two independent matching predicates will be evaluated, not one — a STRICT
keyed match on the item's own named anchors (leg number, route tag, branch name) and a LOOSE
substring match — and any item where the two disagree is reported **BORDERLINE**, never
silently counted. If both predicates agreed on everything by construction, there would be no
measurement; the loose predicate is present precisely because it can return a different answer.
