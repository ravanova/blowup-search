## What is being checked

* **(N1)** Does any source assert **existence or non-existence of a steady γ = 2 (full
  Laplacian) self-similar profile** for gCLM — the object leg 125 called "Object B"?
* **(N2)** Is the **dilation covariance of the viscous profile equation** — that
  `Ω(X) → Ω(X/μ)` maps a solution at `ν` to one at `μ²ν` with `a` unchanged, so `ν` is not
  an independent parameter of the profile equation — stated anywhere in the gCLM literature?
  Leg 125 wrote this covariance down itself (`m7_gamma2_branch` docstring) and used it only
  as a *check*; if the literature states it as a *structural* fact, that changes how leg
  125's stall must be read.
* **(N3)** Is there a standard published diagnosis of Newton/continuation stalls on
  self-similar profile equations (fold detection, basin sensitivity, gauge degeneracy) that
  this leg should be using rather than inventing?

## Verdict

* **(N1) NOT FOUND, either way.** No source in this pass asserts existence *or*
  non-existence of a steady γ = 2 self-similar gCLM profile. So there is **no external answer
  key**: leg 125's stall cannot be adjudicated by citation, only by diagnosis. That is what
  makes this leg worth running, and it also means a "genuine non-existence" verdict here
  could not lean on the literature and would have to carry its own evidence.
* **(N2) NOT FOUND in print for gCLM, but the *discipline* it violates is universal.** No
  returned source states the `Ω(X) → Ω(X/μ)`, `ν → μ²ν`, `a` fixed covariance for the viscous
  gCLM profile equation. But every dynamic-rescaling paper returned in Q3 fixes the profile's
  scaling freedoms by explicit **normalization conditions** — so the *class* of defect this
  leg is going to look for is textbook, even though its instance here is not in print.
  Pre-committed consequence, written before any number was computed: **if the diagnostic finds
  the stall is an unfixed scaling freedom, that is a solver artifact, not a discovery about
  gCLM, and it must be reported at that altitude.**
* **(N3) NO published protocol** for stall classification in this class; the standard
  diagnostics named in `DIRECTION.md` §185 (residual-trend shape, Jacobian conditioning /
  singularity structure, initial-guess sensitivity at the same target) are the ones this leg
  will use, and they are generic numerical-analysis practice, claimed as nothing more.

**Standing ban discharged.** `capabilities.py` grepped before anything was written
(`grep -n -i -E "dissipat|gclm|profile|newton|condition|jacobian" capabilities.py`). This leg
**builds no solver module at all**: it imports `solver.dissipative_profile` read-only (leg
125's, closed territory) and adds only the diagnostic driver in `experiments/`. Nothing is
rebuilt because nothing new is built.

**Ceiling, pre-committed.** Diagnosing a Newton stall is not movement on `L1→L4` and not
Clay; Clay stays ~0.05%. The most this leg can produce is a correct classification of one
solver's behaviour on one profile equation, plus whatever that implies for leg 174's catalog.
