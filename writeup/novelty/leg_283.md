## 4. The sweep instrument, declared in advance

The hardened standing scoping rule, in the form this repository's own correction history
(legs 272, 279, 282) produced:

* **case-insensitive** — every pattern matched with `re.IGNORECASE`;
* **wrap-immune** — each file read as a single stream with all whitespace, plus wrapped-markdown
  leaders (`>`, `#`, `|`, list bullets), collapsed to single spaces *before* matching, so a
  phrase broken at the 100-column hard wrap still matches;
* **hyphenation-tolerant** — every intra-phrase space written `[-\s_]+`, and the numeric
  patterns are written as **bare digit runs with optional separators** (`8[-\s]?175[-\s]?25`),
  with **no** sign, decimal point or leading zero required — so `−0.00817525`, `-.00817525`,
  `0.00817525` and a hyphen-broken rendering all match the same pattern.

Anchoring on bare digit runs rather than on prose is deliberate: it is the one class of pattern
that cannot be defeated by rewording, and the refuted quantities are all numbers.
