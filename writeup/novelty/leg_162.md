## 0. THE BINDING FINDING — THE LEG'S OWN PREMISE IS FALSE AS WRITTEN

`DIRECTION.md` §162 states, as the reason this leg exists:

> "…the review's own independent check found no record of this repository ever having tried
> it."

**That is wrong, and the in-repo grep says so in three places.** This repository has already
built a certificate object in a **global even-Chebyshev basis on a compactly supported
profile's own support interval**, and it has been landed for many legs:

| where | what it is | status |
|---|---|---|
| [`solver/first_integral.py`](../../solver/first_integral.py) | `ReducedProfile`: the gCLM two-scale profile reduced to its **own support** `[0, X_c]`, `e = (1-v^2) s(v)` with `s` an **even Chebyshev series**, closed under the **finite** (interval) Hilbert transform `Hpv` on `[-1,1]`. `even_cheb`, `_even_cheb_raw`, `graded_grid`. | LANDED, `capabilities.py` line ~357: *"the profile on its own support (SUPERSEDES `solver/finite_support.py`)"* |
| [`solver/reduced_certificate.py`](../../solver/reduced_certificate.py) | *"The float rehearsal of the certificate in the reduced space"* — `Y_0`, `Z_0`, `Z_2` assembled on `[0, X_c]` in that same even-Chebyshev basis | LANDED (Route-D v15) |
| [`solver/finite_support.py`](../../solver/finite_support.py) | the first, direct compact-support Chebyshev build (`even_cheb`, `cheb_quad`) | **SUPERSEDED — do not use**, kept so the name resolves to a warning |

So the corner is not untried. **What has never been done is the one number this leg's gate
asks for**, and `solver/reduced_certificate.py`'s own docstring says so in its item (4),
verbatim:

> **(4) `Z_1` IS NOT COMPUTED.**  It is the infinite-dimensional tail — the part of the
> operator outside the `K`-mode subspace — and it is the whole content of a real
> computer-assisted proof.  Nothing here bounds it and nothing here should be read as if it
> did.

**Restated novelty claim for this leg, after the pass:** not "a basis nobody here tried", but
**the `Z_1` of a compact-support/global-Chebyshev certificate, measured in leg 54's exact
convention (`Z1 = colmax(I − A L)`), which no leg of this repository has ever computed in any
basis on a finite support interval.** The construction is largely a re-use; the measurement
and its coverage classification are the new part. This is a measurement on an object this
repository already owns, not a method.

**Second premise correction, banked by this repository's own earlier full-text read.**
`DIRECTION.md` §162 attributes to HTW compact support "for the `a=1` (De Gregorio) profile".
Leg 112 read [arXiv:2603.25104](https://arxiv.org/abs/2603.25104)v2 at full text and banked
(`experiments/p2_route_as2_v1_lit.py`, F-rows and the sec-21/23 reading):

> Theorem 7.10(3) (p. 45) proves it is compactly supported **exactly on `0 < a < 1`** … sec 23's
> *"at `a = 1` the edge is a CORNER, `a > 1` is a cusp"*.

`a = 1` is the **boundary** case where the edge degenerates to a corner, not the interior of the
compact-support regime. The corner this leg builds therefore lives on `0 < a < 1`, and the
construction is parameterized there. Recorded because building at the one `a` the theorem
excludes is exactly a premise-slip failure mode.

## 3. What the pass changed about the plan, before any code was written

1. **The gate's clause (a) is now answerable from the JSON, not from a judgement call.** Leg
   126's `realization` axis is an explicit three-element list on disk. The classification is a
   membership test, not an argument.
2. **The construction is parameterized on `0 < a < 1`, not at `a = 1`** (§0, premise 2).
3. **A `support_transfer` audit is added and is load-bearing**, because the operator leg 126
   actually audited is the `a = 0` CLM linearisation, whose profile is `-4X/(1+4X^2)` — algebraic
   `1/X` decay, and `a = 0` is *outside* HTW's `0 < a < 1`. Whether the corner even has a domain
   on leg 126's own object is a question this leg must measure rather than assume.
4. **`even_cheb` is called with an explicit `on_outside` policy everywhere** (leg 107).
5. **A dissipative positive control is mandatory** and must reach `Z_1 < 1` in *this* basis, or
   the negative is uninterpretable (leg 53's template; leg 126 `BX3` reached `0.174`).
6. **No GA compute.** Free parameters (support radius, weight exponent) move on a
   pre-named deterministic grid, leg 46/59 precedent.
