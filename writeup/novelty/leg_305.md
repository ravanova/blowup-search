# Leg 305 — Route-DWM novelty / prior-art pass

**Committed BEFORE any construction**, per the contract's §0a. Links, not counts.

**The object.** BCG (`arXiv:2208.09445`, Buckmaster–Cao-Labora–Gómez-Serrano, *Smooth
imploding solutions for 3D compressible fluids*, Forum of Math. Pi 13 e6 (2025)) admit the
self-similar exponent `r` on `1 < r < r*(γ)` (`\eqref{eq:rstar}`, TeX l.352–358) and, for the
**Navier–Stokes** step, additionally require `r > 2γ/(γ+1)` (`\eqref{eq:r:restriction}`,
l.493–495) so that the dissipative forcing carries a decaying prefactor
`e^{-δ_dis s}` (`\eqref{eq:delta:dis}`, l.489–491). At `γ = 7/5` the surviving *dominance
window* is `(7/6, r*)`; the *target window* `(1, 7/6]` — where the forcing is **not**
dominated — is `6.854×` wider (closed form `(7+3√5)/2`, leg 300's re-derivation; leg 266's
transcribed `6.855` is the **known-wrong digit** and is not used anywhere in this leg).

**The question this leg asks, and that the pass is about.** Is that `6.854×` width deficit
**sharp** for BCG's argument, or is it an artifact of one generous intermediate constant?
Equivalently: does anyone already publish a per-constant sensitivity audit of these two
thresholds?

## What is already out there (prior art located, weighted toward OLD per §0a)

**Old prior art — the exponent-as-eigenvalue tradition.** The similarity exponent for imploding
flow is a *nonlinear eigenvalue* fixed by a sonic-point passage condition, not by dimensional
analysis — Guderley (1942), with the numerically definitive tabulations by Lazarus &
Richtmyer (1977) and **Lazarus (1981)**, extended by Hafner (1988), Chisnell (1998) and
[Ramsey et al., *The Guderley problem revisited*](https://www.osti.gov/biblio/970025). That
literature **does** sweep the exponent against `γ` (and against a density exponent) at high
precision — see [arXiv:2305.16400](https://arxiv.org/pdf/2305.16400) and
[arXiv:2106.04971](https://arxiv.org/pdf/2106.04971). **It is the closest thing to a
sensitivity study of this object that exists, and it is forty-five years old.** But it sweeps
the *shock* exponent `λ(γ,d)` for the inviscid Guderley problem; it does not touch a viscous
dominance threshold, and there is no analogue of `δ_dis` in it. Not a pre-emption; a genuine
methodological ancestor, and cited as such.

**The admissible set is discrete, and that is published.** MRRS
([arXiv:1912.11009](https://arxiv.org/abs/1912.11009);
[part II](https://www.ljll.fr/szeftel/fluids-final-part2.pdf)) construct profiles only at
*quantized* speeds `r_n` accumulating at a limiting speed, for almost every `γ` — with `γ=7/5`
one of the values **not** covered, which is exactly why BCG revisited it. BCG's own
Lemma `\ref{lemma:k}` (l.579–583) makes this precise as the bijection `k : [1, r*) → [1, ∞)`,
`r_n := k^{-1}(n)`. **This is prior art for the discrete half of this leg's ledger** and is
cited rather than re-discovered.

**The one recent item that bears on the gate.** Chen–Shkoller–Vicol, *Smooth and stable Euler
implosions*, [arXiv:2605.00808](https://arxiv.org/abs/2605.00808) /
[CSV2.pdf](https://cims.nyu.edu/~vicol/CSV2.pdf) (2026), construct implosion profiles with
**explicit closed-form similarity exponents**, and say in as many words that MRRS and BCG
obtained theirs "only through numerically-assisted or computer-assisted arguments over
*restricted admissible sets*." This is the sharpest external statement that BCG's admissible
set is felt as a restriction. **It does not pre-empt this leg**: CSV's object is
*non-isentropic compressible **Euler***, stability is proved against Euler perturbations, and
there is **no viscous term and hence no `δ_dis` condition at all** — so it removes BCG's `r*`
but says nothing about `2γ/(γ+1)`, which is the endpoint this leg's deficit is measured
against. Recorded as the live alternative architecture, not as a discharge.

**Adjacent thresholds, different windows.** Chen–Liu–Zhu's degenerate-viscosity threshold
`0 < δ < δ*(γ)` for `ρ^δ`-scaled viscosity is a genuinely comparable "admissible window with an
explicit endpoint", and the literature's own reading of it is that it is *"explicit but not
obviously optimal"* — i.e. **nobody has audited its sharpness either**. Same for the
incompressible `γ = 1/2` scaling barrier ([arXiv:2602.17570](https://arxiv.org/html/2602.17570),
[arXiv:2405.10916](https://arxiv.org/pdf/2405.10916)).

## The located gap, stated narrowly

**No published work decomposes either endpoint of BCG's viscous admissibility window into its
intermediate constants and measures which one costs the width.** The exponent-sweep tradition
(Guderley→Lazarus→Ramsey) sweeps `γ` on an inviscid shock eigenvalue; CSV replaces the
architecture rather than auditing it; MRRS/BCG state the endpoints and move on. What this leg
produces — a per-constant width ledger with each constant classified as an *exact identity* or
an *estimate* — is, so far as this pass can establish, absent.

**Claimed strength.** This is a **shape-of-the-obligation measurement on an existing published
argument**, not a new theorem and not a certificate. Wall 1 and Wall 2 stand; measuring the
shape of an obligation is not discharging it. The object is 3D **compressible** Navier–Stokes
(BCG, `γ=7/5`), which is **not** the incompressible system the Clay problem asks about — the
source leg flagged this and it is restated here. **Clay odds are ~0.05%, unchanged.**
