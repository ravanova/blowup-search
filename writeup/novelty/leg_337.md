## 2. What was verified, against what

Both corrections are **direct measurements against this repo's own live functions**, not
literature claims:

* Mechanism: ran `alpha_of`, `r_crit`, `delta_dis` exactly as defined in
  `experiments/p2_route_decr_v1_scoping.py`, at the same 45-γ grid FT1 already uses, and
  compared each float64 intermediate value against its `fractions.Fraction`-exact counterpart to
  determine, per operand, how many ulps of rounding error each carries and how that error
  propagates through `delta_dis`'s derivative. This is standard IEEE-754 floating-point error
  analysis (Sterbenz's lemma for exact subtraction, ulp accounting, first-order error
  propagation via the partial derivative), not a claim requiring external verification — the
  full script and numeric outputs are in `experiments/journal/leg_337.md`.
* Control: read the existing boolean expression, identified it as a logical tautology
  (`not X or True ≡ True` for all `X`, elementary propositional logic), rewrote it to `X` itself,
  and re-ran the script to record the corrected control's pass/fail.

Nothing here could be "scooped" by external literature, and nothing here is a statement any
literature search could confirm or refute — it is a same-repo, same-function re-measurement, the
kind explicitly in scope for a correction leg.
