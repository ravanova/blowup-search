## R0 — the defect shape being censused, stated precisely

Leg 202 (Route-PNA, escalated, parked, not merged) found a shape distinct from every other
audit-family item this cycle. The others are all **guard-class**: "a guard fails to
validate adversarial input", i.e. the defect is only reachable by feeding the module data
no landed call-site actually feeds it. Leg 202's is different:

> **the rejecting signal already existed in the caller's own data and was never used.**

Concretely (verified in this repository's source at pass time, not quoted from the
journal): `experiments/p2_route_d_v11_anchor.py` line 104 computes the row verdict as
`"converged": bool(r["relres"] < 1e-8)`, while line 82 writes `weighted_defect` into the
**same row dict** and no code path anywhere in the runner branches on it. The banked
`writeup/data/p2_route_d_v11_anchor.json` therefore carries rows that are simultaneously
`converged: true` and carrying a `weighted_defect` that has left the plausible range by
many orders of magnitude. That is the shape: **caller-computed diagnostic, present in the
banked artifact, contradicting the verdict the same artifact asserts, with no wire between
them.**

## R3 — external prior art on the shape itself (light, one pass)

The category is not new to software engineering and this leg does not claim it is. The
shape is a special case of what the fault-tolerance literature calls an **unchecked
error-detection signal** — a system computes an indicator sufficient to reject an output
and does not route it into the acceptance decision. It sits near, but is not, three
better-known named things, and the distinctions are why it needs its own name here:

- **Unused-variable / dead-store analysis** (any linter). Wrong instrument: the field is
  *not* dead — it is written to a banked JSON and quoted in prose. Nothing static would
  flag it. This is precisely why 22 legs of audit tooling did not catch it.
- **Ignored return value / `CWE-252`**. Adjacent, but that is about a *callee's* status
  code being discarded by a caller. Here the callee's status (`converged`) is honoured;
  what is discarded is a quantity the **caller itself** computed, which no callee ever
  claimed was a check.
- **Oracle problem / metamorphic testing**. Related in spirit — the diagnostic is a latent
  oracle — but that literature is about *constructing* oracles, not about finding ones a
  program already computes and throws away.

No published tool or paper located in this pass censuses *research artifacts* (banked JSON
+ its producing runner) for this shape. That is not a novelty claim of any weight: it is a
statement that the check had to be written here rather than imported, and that the finding,
either way, is about this repository and not about the state of the art.
