## 2. The observation this leg is built on, read off leg 210's ALREADY-BANKED table

This is not a result of this leg; it is arithmetic on numbers leg 210 already published, done
before writing any code, and it is what makes the pre-registration below falsifiable.

The sinh grid is `X = c sinh(rho)`, `c = 0.5`, `rho` uniform on `[-8, 8]`, so the grid spacing
**at the origin** is `h := h_X(0) = c * 16/(n-1) = 8/(n-1)`.

Leg 210's two *converged* points at `a = 1/2` in its own scheme, with `c_l = 1/2` imposed, and
the diffusive length `ell := sqrt(|nu| / c_l)` of the `nu Omega_XX` vs `-c_l X Omega_X` balance:

| n | h = 8/(n-1) | leg 210's `nu` | `ell = sqrt(2|nu|)` | **`ell / h`** | amplitude | `amp / h` |
|---|---|---|---|---|---|---|
| 401 | 0.0200 | -8.293e-04 | 0.040726 | **2.036** | 0.2260 | 11.30 |
| 801 | 0.0100 | -2.025e-04 | 0.020125 | **2.012** | 0.1092 | 10.92 |

`ell/h` is **2.04 then 2.01**, and `|nu|` falls by **4.095x** for a **2x** grid refinement.
Both are consistent, to a few percent, with a single statement:

> **H1 (the grid-locked-layer hypothesis).** The root Newton finds at `a = 1/2` is not a
> continuum solution at all. It is a **boundary layer at the origin whose width is locked to
> two grid spacings** — the narrowest structure the 6th-order stencil can carry — with `nu`
> not measured by the equation but *set by the mesh*:
>
> **`|nu(n)| = c_l * (2h)^2 = 2 * (8/(n-1))^2 = 128/(n-1)^2`**, i.e. **`nu -> 0` at rate `h^2`.**

The gauge `Omega_X(0) = -8.70929686` is what keeps this object from being the trivial null:
it forces a fixed slope at the origin, so a collapsing solution cannot go to `Omega == 0`; it
goes to a **spike of vanishing width and vanishing amplitude** instead. That predicts
`amp ~ K |g| * 2h` with `K` a shape constant; leg 210's two points give `amp/h = 11.30` and
`10.92`, i.e. `K = 0.649` and `0.627`.

H1 explains every symptom leg 210 reported and could not name: the non-monotone span (the two
schemes lock at different multiples of *their own* `h`), the amplitude collapse by 0.483
(exactly the 2x grid ratio), the failure of the dilation-covariance recovery at `a = 1/2`
(a mesh-set length scale is not dilation-covariant — that is the sharpest consequence), and
why the `a = 0.30` control is clean (there `nu > 0`, `ell = 0.19 = 9.4 h` at `n = 401`, the
layer is genuinely resolved and has nothing to lock onto).

**H1 is a hypothesis, not a finding.** It is stated here so it can be *refuted* by the run.

## 3. PRE-REGISTERED: how the ladder is extended

Leg 210 ran `n in {201, 401, 801}` at `a = 1/2`. This leg runs, at `a = 1/2`:

**Ladder L.** `n in {201, 401, 801, 1601, 3201}` — `h = 16/(n-1)` in `rho` halves **exactly**
at each rung, so Richardson has a constant refinement ratio `r = 2`. Two rungs beyond leg 210.

**Starts.** Both of leg 185's (`nu0 = 0.3`, `nu0 = 0.01`), plus a third selection rule that is
new here:

**Instrument C — pseudo-arclength continuation in `a`.** The decisive methodological change.
Legs 185 and 210 both *restarted Newton from the Chen profile at each `(n, a)`*, so which root
they landed on was a basin accident. This leg instead starts from the **converged, refined,
independently confirmed root at `a = 0.30`** and continues the branch in `a` by
pseudo-arclength — unknowns `(Omega_odd, nu, a)`, equations `(R_odd, gauge, arclength)` — so
folds in `a` are traversable and are *detected* rather than mistaken for failure. This asks the
question neither prior leg asked: **does the `a = 0.30` branch reach `a = 1/2` at all?**

**Ladder T (truncation).** `rho_max in {7, 8, 9}` at `n = 1601`, at `a = 1/2` — the check leg
185 ran only at `a = 0.30`.

**Controls (lesson 84 — a known-answer probe has a window).**
* `a = 0.30` is run on the **same extended ladder L**, so the instrument is shown to return
  "converged" on this leg's own criterion where the answer is known. If it does not, the
  criterion is too strict and the `a = 1/2` "no" is worthless.
* `a = 0.45` (leg 185 banked it too; leg 210 measured it as the worst point, amplitude
  collapsing 160x) is run as a second negative-side point, to test whether H1's law holds
  *there* as well or is peculiar to `a = 1/2`.
* **The anti-plateau guard, stated explicitly.** A sequence converging to `nu = 0` at rate
  `h^2` would satisfy naive Richardson tests beautifully — `nu = 0` is a perfectly stable
  "plateau" and would be exactly the coincidental agreement lesson 84 warns about. It is
  therefore **excluded in advance by clause K1 below**, not after the fact.

## 4. PRE-REGISTERED: the convergence criterion (the gate's yes/no)

`nu(1/2)` is declared **GRID-CONVERGED** iff **all six** clauses hold. Each is a magnitude and
each is reported with its measured value whether it passes or fails.

* **K1 — the root must not be grid-locked.** At the three finest usable rungs,
  `ell/h = sqrt(|nu|/c_l)/h >= 8` (the layer resolved by at least 8 points at the origin), AND
  `ell/h` must **grow** by at least 1.5x per grid doubling (a true continuum length is fixed in
  `X`, so `ell/h` doubles; a mesh-locked one is constant). This is the clause that makes
  "converges to 0 like `h^2`" a **failure**, not a success.
* **K2 — solve quality.** Relative residual `< 1e-10` at each of the three rungs used (leg 210's
  own `CONVERGED_RELRES`, carried unchanged so the two legs' bars are identical).
* **K3 — monotone.** `nu(n)` monotone across those three rungs.
* **K4 — Richardson.** Observed order `p` from the three finest rungs lies in `[1.5, 8.0]`
  (the scheme is nominally 6th order in `rho` with 4th/2nd tapering, so anything in this window
  is credible; outside it, the fit is not measuring a convergence rate).
* **K5 — extrapolation tight.** `|nu_inf - nu_finest| / |nu_inf| < 1e-3`, and successive
  relative differences shrink by `>= 2x` per doubling.
* **K6 — start- and truncation-independent.** The two `nu0` starts and the continuation-selected
  root agree to `< 1e-3` relative at the finest common rung, and ladder T moves `nu` by
  `< 1e-2` relative.

**Gate mapping, fixed now.**
* **YES** — all of K1..K6 hold. Bank `nu(1/2)` with the ladder, and re-pin `a*` from the
  continued branch.
* **NO** — any clause fails. Bank the non-convergence at full strength, with **which clause
  failed and by how much**, and with the mechanism test of §5 as the "why". The sign-only
  catalog state becomes permanent for this scheme.

I expect **NO**, by K1, and I am recording that expectation here so that a YES would be a
genuine surprise rather than a criterion tuned to the answer.

## 5. PRE-REGISTERED: the mechanism test, with POINT PREDICTIONS

The gate says *"WHY (which term resists) is itself the finding."* H1 names the term: **the
`nu Omega_XX` term itself**, whose coefficient is the very unknown being solved for, so the
equation's only intrinsic length scale is `sqrt(|nu|/c_l)` — and on the negative side nothing
prevents the solver from shrinking that length onto the mesh. H1 is scored by **four
falsifiable predictions, with numbers fixed before the run**:

**P1 — the `h^2` law, as point predictions.** `|nu(n)| = 128/(n-1)^2` at `a = 1/2`:

| n | **predicted `nu`** | status |
|---|---|---|
| 401 | -8.000e-04 | leg 210 observed -8.293e-04 (ratio 1.037) |
| 801 | -2.000e-04 | leg 210 observed -2.025e-04 (ratio 1.012) |
| **1601** | **-5.000e-05** | **PREDICTED HERE, not yet run** |
| **3201** | **-1.250e-05** | **PREDICTED HERE, not yet run** |

**Scored as: P1 PASSES iff observed/predicted lies in `[0.8, 1.25]` at BOTH new rungs.**

**P2 — the amplitude law.** `amp = K |g| 2h` with `K` calibrated from leg 210's two points
(`K = 0.638 +- 0.011`), i.e. `amp = 10.98 h = 87.8/(n-1)`: predicts **0.05486** at `n = 1601`
and **0.02743** at `n = 3201`. **Scored as: PASSES iff observed/predicted in `[0.85, 1.18]` at
both.**

**P3 — the near-null direction is the layer.** The smallest singular value of the augmented
(odd-reduced, `nu`-bordered) Jacobian at the found root, normalised by its largest, must
**degenerate with `n`** at `a = 1/2` and **not** at `a = 0.30`; and the corresponding right
singular vector must be **localised at the origin**, with `>= 50%` of its mass inside
`|X| <= 4 ell`. **Scored as: PASSES iff the `a=1/2` normalised smallest singular value falls
by `>= 4x` from `n = 401` to `n = 1601` while the `a = 0.30` one changes by `< 2x`, and the
localisation fraction exceeds 0.5 at `a = 1/2` and is below it at `a = 0.30`.**

**P4 — dilation non-covariance is a consequence, not a coincidence.** A mesh-set length is not
dilation-covariant, so leg 210's failed `kappa^2` recovery at `a = 1/2` (error 5.977e-01 vs
3.184e-05 at `a = 0.30`) must persist here and must NOT improve with refinement. **Scored as:
PASSES iff the seeded covariance error at `a = 1/2` stays `> 1e-2` at every rung of ladder L
while the `a = 0.30` error stays `< 1e-3`.**

**If P1 or P2 fails, H1 is refuted and I will say so in the journal rather than rescuing it.**
The point predictions exist precisely so that "the numbers went somewhere else" is a reportable
outcome. H1 being refuted does not by itself flip the gate — the gate is K1..K6 — but it would
mean this leg cannot name the mechanism, and the journal must say that instead of inventing one.

## 6. PRE-REGISTERED: how `a*` is re-pinned (or not)

The gate's yes-branch says "re-pin `a*` if the converged scheme reaches it". `a*` is where
`nu(a) = 0`. Two facts already on record: leg 125 got `a* = 0.3864963972206034` from a
completely different computation (the `Delta(a)` sweep at `nu = 0`); leg 210's independent
sign-change bracket was `[0.36, 0.37]`, which **excludes** it, and leg 185's own two starts
**straddle zero** at `a = 0.3865` (`+3.5e-7` / `-4.25e-3`), so leg 185 never pinned it either.

**Pre-registered rule.** `a*` is quoted only from **the continuation branch**, only between
**consecutive continuation points that BOTH pass K1 and K2**, and only as a **bracket** unless
the bracket width itself converges under ladder L. If `a*` is quoted as a number, it is quoted
with the ladder that produced it and with the Richardson order; **no bisection is used** — leg
210 recorded against itself that its first pass printed a 12-digit `a*` from a bisection that
stepped through non-convergent points (lesson 67), and that failure mode is closed here by
construction, not by care.

If H1 holds, the branch has an **endpoint** near `a*` — for `a` just above `a*`, `nu` is
slightly negative, `ell = sqrt(|nu|/c_l)` is *small*, and the layer becomes unresolvable
immediately. So a *prediction that follows from H1*: **continuation terminates or delaminates
near `a*`, and the terminal `a` is itself the better-posed quantity.** Pre-registered as
**P5: the largest `a` at which the continued branch still satisfies K1 converges under ladder L
to within a bracket of width `< 0.02`.** Scored, and reported either way.
