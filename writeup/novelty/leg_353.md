## Locating the target: which published 2-D Kolmogorov-flow RPO

| query | n | notable hits |
|---|---|---|
| `au:Chandler AND au:Kerswell` | 1 | [1207.4682](https://arxiv.org/abs/1207.4682) "Simple invariant solutions embedded in 2D Kolmogorov turbulence" — the arXiv preprint of Chandler & Kerswell, *J. Fluid Mech.* **722**, 554 (2013); reports the first 5 recurrent flows (equilibria/TWs/RPOs T1,T3,T4,R7,R8) at Re=60, n=4, α=1 |
| `abs:"Kolmogorov flow" AND abs:"periodic orbit"` | 13 | [1406.1820](https://arxiv.org/abs/1406.1820) "Recurrent flow analysis in spatiotemporally chaotic 2-dimensional Kolmogorov flow", Lucas & Kerswell, *Phys. Fluids* **27**, 045106 (2015) |
| `au:Lucas AND au:Kerswell` | 6 | confirms 1406.1820 and its companion 1308.3356 ("Spatiotemporal dynamics in 2D Kolmogorov flow over large domains", *J. Fluid Mech.* **750**, 518 (2014), the DNS source paper) |

**1406.1820 is the target paper.** It runs the SAME Newton–GMRES–hookstep extraction the plan's
B5 gate asks about, on the SAME system (2-D Kolmogorov flow, forcing wavenumber n=4, square
torus α=1, Re=60), and its Table IV catalogues 81 converged recurrent flows with published
`(T, s, m)`. Row 37 (**"UPO 37"**) is highlighted in the paper's own text and figures (§III.B,
Fig. 4, Fig. 5) as "a typical example" of a relative periodic orbit, with fully stated
parameters: **T = 19.334, x-translation shift s = 0.375, discrete y-shift m = 0** (pure
translation RPO, no reflect-shift component), residual `6.26e-9` at convergence, `N = 12`
Newton-unstable directions. This is the object this leg targets: the most explicitly documented
RPO in the paper, with every parameter needed to set up the same dynamical system and check
recovery against reported invariants (T, s, and the dissipation/energy-input loop shown in the
paper's Fig. 4).

**What is NOT available to this leg**: 1406.1820 publishes `(T, s, m)` and qualitative
diagnostics (Figs. 4-5) in the article text, but not the converged Fourier-coefficient vector
itself (that would live in supplementary/online data this leg has no network path to). So this
leg cannot start Newton from *the paper's own bit-for-bit initial guess* — it can only set up
the identical dynamical system (same Re, n, domain, symmetries) and independently recover a
recurrent flow with the same `(T, s, m)` and matching invariants via the same recurrence-flow +
Newton-Krylov procedure the paper used. This distinction is recorded up front so the construction
section states plainly which check ("same system, same catalogued numbers, independently
reconverged") is actually being performed.

## Has the basin-radius measurement itself already been published?

| query | n | notable hits |
|---|---|---|

| `abs:"Newton-Krylov" AND abs:"Kolmogorov flow"` | 0 (controlled) | genuine absence |
| `abs:"phase condition" AND abs:"relative periodic orbit"` | 0 (controlled) | genuine absence |
| `abs:"relative periodic orbit" AND abs:"Kolmogorov flow"` | 3 | 1611.04829, 1406.1820, 1308.3356 — all Bristol-group papers on the *existence* of these orbits, none reporting a Newton-convergence-basin radius |
| `abs:"UPO 37"` | 0 (controlled via component terms above) | genuine absence — expected, this is an internal table label, not abstract text |

**Verdict: `PROCEED`.** No paper on arXiv measures the radius of the Newton basin around a
published 2-D Kolmogorov-flow RPO (i.e. how far the initial guess can be perturbed before
Newton–GMRES fails to reconverge). The papers that produce these RPOs (Chandler–Kerswell 2013,
Lucas–Kerswell 2014/2015) report *that* Newton converges from a DNS-recurrence-derived guess,
never a swept perturbation-radius measurement of the basin itself. This is exactly leg 334's
clause (c-iii) / leg 349's P4 hole the plan's B5 brick was drafted to fill, and nothing external
pre-empts it.
