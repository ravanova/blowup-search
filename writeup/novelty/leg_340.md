- **Also surviving, and load-bearing:** everything in §§1–6 (the prior-art census) is

  this pass that most constrains what the leg is allowed to claim — was written *because*

## 3. Cell 1 — the object. What is already published, with links.

- **Elgindi, Ghoul, Masmoudi, *Stable self-similar blowup for a family of nonlocal transport
  equations*, arXiv:1906.05811** — <https://arxiv.org/abs/1906.05811>. Prop. 2.1 is the
  construction: for `f` odd with `f'(0) = Hf(0) = 0` and weight `(1+y²)²/y⁴`,
  `∫ f M_a f φ ≤ (−1/2 − C|a|) ∫ f² φ`. **At `a = 0` this proposition already asserts the
  coefficient `−1/2`.** This leg's object is that inequality's `a = 0` case; the leg measures
  it, it does not discover it.
- **Xu, arXiv:2607.19762** — <https://arxiv.org/abs/2607.19762>. §3.1: point spectrum of the
  `a=0` linearisation is exactly `{0, 1}`, essential spectrum sits on `Re λ = −1/2`. This is
  the source of `KNOWN_ANSWER_CEILING = 0.5` in `solver/energy_coercivity.py`. Any computed
  gap **above** `1/2 + 1e-9` contradicts a published theorem; any computed gap strictly
  **below** `1/2` on the full constrained class is, by the same theorem, numerical error.
- **arXiv:2603.26715** — <https://arxiv.org/abs/2603.26715>. Returned by both
  `"Constantin-Lax-Majda" AND "coercivity"` and `"spectral gap" AND "Constantin-Lax-Majda"`.
- **arXiv:2604.01244**, **arXiv:2607.28194**, **arXiv:2608.06226** — the latter two from
  `"coercivity" AND "interval arithmetic"`; adjacent computer-assisted coercivity work,
  neither on this operator.

### 7a. The instrument, specified

With `X = tan(θ/2)`, `u = 1 + X²`: `(1+iX)^{2k} = R_k(X) + i P_k(X)` gives
`sin kθ = P_k/u^k`, `cos kθ = R_k/u^k`, `dθ = 2 dX/u`. For `h = Σ_k c_k sin kθ` written as
`A/u^n`, with `Hh = C/u^n` and `h' = D/u^n`, the CLM `a=0` linearisation is
`Lh = [(1−X²)A − 2X(C+D)]/u^{n+1}`. The weights are exactly
`φ_{B4} = u³/(64 X⁴)`, `φ_E = 32 φ_{B4}`, `φ_{A4} = u²/(16 X⁴)`. Every integral is therefore
`∫₀^∞ poly(X) X^{−p} (1+X²)^{−M} dX` with **rational** value for odd exponents and
**rational·π** for even ones, so the Rayleigh quotient is exactly `(r₁+q₁π)/(r₂+q₂π)` with
`r_i, q_i ∈ ℚ`. Rigour comes from enclosing `π` with `solver/interval_mp.mp_pi`.

**Judgement calls made now:** integer/`Fraction` coefficients only — no float ever enters the
exact path; a term whose exponent makes the integral divergent at `X=0` or `X=∞` is a hard
`ValueError`, never silently dropped; the constraint rows are applied in exact `Fraction`
before scaling to integers, so admissibility is exact and not "small".

### 7d. Validity on the operator quantity, argued now

The gate asks whether the bound is valid on the **operator** quantity, not the truncated
matrix's eigenvalue. The argument fixed now, before any number: for **any** admissible trial
vector `x`, `gap_op ≤ gap_trunc ≤ −R(x)`, since the operator's constrained supremum dominates
the truncated one and the truncated maximum dominates any single quotient. An upper bound on
one exactly-evaluated Rayleigh quotient is therefore an upper bound on the operator gap.
**The direction matters and only works one way:** this argument can never certify a *lower*
bound, so it cannot be used to claim a gap is *achieved*.

### 7e. The interpretive obligation, fixed now — the part that binds hardest

If the exact value comes out **at exactly `−1/2`** on the constrained class, then
`Sym(B) = −G/2` there and the quantity clause 5 tests is an **identity**, not a measurement:
it would then hold at every truncation, every `rcond`, every quadrature depth, with **zero**
truncation dependence. In that event this leg is **required** to report both readings side by
side and to suppress neither:

1. the gate's literal question is answered `yes` — the bound does hold at every rung; and
2. clause 5 is a **tautology** on this class, so the "coercivity gap" carries no information
   about the operator (lesson 90 in its purest form), and a flip would be a flip **on an
   identity**.

The leg is **forbidden** from reporting (1) without (2). The decision about parked escalation
#3 remains the user's in either case, and this leg neither takes it nor recommends taking it
in a particular direction.
