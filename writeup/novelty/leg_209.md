## 4. Pre-registered probe families and the silent-wrong predicate — fixed BEFORE measurement

**Predicate (fixed now).** A case is `silent_wrong` iff the module **returns a value** (no
exception, no NaN, no Inf visible to the caller as a defect signal) that differs materially
from the correct value for that input, *or* returns a defect-signalling value that a caller
would read as the **most favourable** answer. Overstatement (a returned bound that is too
*pessimistic*) is **recorded but does not decide the gate**; understatement and
wrong-direction-favourable both decide.

Eight families, declared in advance:

1. **F1 weight-class domain.** `geometric` with `nu <= 0`, `nu = 1`, `0 < nu < 1` (contra the
   documented `nu > 1`); `algebraic` with `s < 0`; `param` NaN/Inf. Both `weight_vector` and
   `log_weight_vector`, which must agree.
2. **F2 non-finite propagation** through `weighted_l1_opnorm`, `weighted_l1_upper`,
   `finite_section_inverse_norm`, `tail_inverse_norm`, `_scaled_tail`.
3. **F3 `l1_bounded_below_constant` under NaN/Inf/singular `Ls`** — the `nrm > 0` guard.
   *Predicted (recorded before running): returns `float("inf")` on NaN input.*
4. **F4 the no-go arithmetic downstream** — `general_class_tradeoff`,
   `counterexample_norm_floor`, `block_upper_triangular_bound` fed F3's outputs.
5. **F5 degenerate index domains** — `M <= K`, `K = 0`, `n = 1` tail, non-integer/negative `K`.
6. **F6 zero-norm normalisation** in `bordered_tail_inverse_norm` (`v/‖v‖` with `‖v‖ = 0`).
7. **F7 float64 vs exact rational** — `finite_section_inverse_norm` against
   `exact_inverse_norm` at the sizes actually shipped, i.e. is the *clean-input* number itself
   sound (lesson 86). **This is the family that decides whether the finding touches banked
   numbers.**
8. **F8 verdict/boolean absorption** — `kernel_membership_ladder`'s `in_l1_w`,
   `nogo_hypotheses`'s `H2_holds_on_the_infinite_tail`, `general_class_tradeoff`'s `holds`
   under adversarial params.

**Positive controls (lesson 90), declared now.** Every family carries a clean-input arm that
must come out *differently*. In particular F3's control is the module's own shipped `Ls` at
`(K, M) = (8, 512)`, where σ_min must be finite, positive and reproduce leg 127's ladder; if
the clean and poisoned arms returned the same number the probe would be a tautology.

## 5. Severity vocabulary, fixed in advance

Theorem NGX's proof is `Z₁ ≥ 1 − ‖A‖_w · σ_min(L)` (folklore, explicitly disclaimed as
not-this-repo's in the module's own §NGX header) plus the **explicit sequence**
`v_M = (z_M; h^(M))` whose entire residual is the single truncation-edge row of size
`|1 − M/2|·|h_M|·w_M ~ M^(s−1)`. That is an **analytic** argument about the infinite tail; the
float path is corroboration of it, not its content.

Therefore this leg commits, before measuring, to reporting on **three separate axes**:

- **(a)** does the module return a silently wrong value on adversarial input? (the gate)
- **(b)** is any *banked* number reachable from the shipped code path by that mechanism?
  (blast radius — the leg 201/204 "LATENT" determination, measured in decades of margin)
- **(c)** does the mechanism touch the **analytic argument** of Theorem NGX?
  A defect in (a) is **not** evidence for (c). (c) requires showing the exact-arithmetic or
  analytic step is wrong, which the module's float paths cannot do on their own. If (c) is
  clean, the leg says so in exactly those words and does **not** let (a)'s headline imply it.
