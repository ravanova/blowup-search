### The disambiguating detail this leg found, that a second-hand read would have missed

The **ar5iv HTML rendering** of the paper (<https://ar5iv.labs.arxiv.org/html/1906.05811>)
transcribes Prop. 2.1's constant as **`−(1/2 − C|a|)`**, i.e. `−1/2 + C|a|`. The **PDF**
does not. Extracted from the PDF's own layout (lines 409–424 of `pdftotext` output), the
displayed inequality (2.1) reads

```
f Ma f φ(y)dy ≤ −
                    1
                    2
                    − C |a|
                             f (y)2 φ(y)dy.
```

i.e. the bracket is **`(−1/2 − C|a|)`** — the two terms are *both* negative, so the gap
**improves** with `|a|` rather than degrading. Leg 141's transcription is **correct**; the
HTML mirror is the one that is wrong. This matters and is recorded because at `a = 0` the
two readings agree exactly (`−1/2`), so the error is invisible at precisely the value this
repository quotes — a transcription error that only bites off-axis is the worst kind.
**This is the one thing this leg's independent read added over leg 141's.**

### Verbatim, from the PDF

Prop. 2.1 (§2 "Coercivity", p. 6), hypotheses and conclusion:

> "**Proposition 2.1.** There exists a universal constant `C > 0` so that if `a` is small
> enough and if `f` is odd, `f′(0) = Hf(0) = 0` and `∫_R |f|² φ(y)dy < +∞`,
> `∫_R f M_a f φ(y)dy ≤ (−1/2 − C|a|) ∫_R f(y)² φ(y)dy.`  (2.1)"

The space and the weight (§1, "Main Theorem"):

> "We introduce first the following weighted space `L²_φ(R) = {f ∈ L²_loc(R) : ∫_R |f|² φ
> < ∞}`, equipped with the norm and inner product `‖f‖²_{L²_φ} = (fφ, f)_{L²}`, where
> `φ = (1+y²)²/y⁴`."

The family, and which member is CLM (§1, p. 2, l. 80 of the extract):

> "Hence, when `a = 2` we get the De Gregorio model and when `a = 0` we get CLM model."

The `a = 0` profile (§1, after (1.7)):

> "When `a = 0`, the profile `F₀` has the form: `F₀(y) = y/(1+y²)`"

The price EGM pay for the origin conditions (§3):

> "Since our coercivity estimate from the previous section relies on `∂_y q(0) = H(q)(0) =
> 0`, we will use that we have the 'free' parameters `μ` and `λ` to fix these conditions."

And EGM re-use the same weight at §6 for the `C^α` version, with the gap degrading in `α`:

> `φ*(Y) := (Y+1)⁴/Y⁴`, and `(q + Y∂_Y q + 2H_α(F₀^{(α)})q, qφ*) ≥ (1/2 − Cα)|q√φ*|²_{L²}`

which is a **second, independent in-paper occurrence of the same `1/2`** — a useful
internal consistency check on the transcription.

## 8. CORRECTION TO §2, WRITTEN BY THE SAME LEG AFTER RE-MEASURING ITS OWN HEADLINE

**§2 above is wrong on one point, and the point it is wrong on is the one §2 advertised as
this leg's contribution.** The resumed session re-fetched the paper before appending the
ledger row — the standing "re-measure your own headline before building on it" discipline —
and pulled not only the PDF but the **arXiv LaTeX e-print** (`arxiv.org/e-print/1906.05811`
→ `OSWModel_Final.tex`, 48494 bytes, dated 13 Jun 2019). The proposition block reads,
character for character:

```latex
\begin{proposition}\label{proposition:spectralgap}
There exists a universal constant $C>0$ so that if $a$ is small enough and if $f$ is odd, $f'(0)=Hf(0)=0$ and
$$\int_\RR|f|^2\phi(y)dy<+\infty,$$
\begin{align}\label{spectralgap}
\int_\RR f\MM f \phi(y)dy&\leq-\Big(\frac{1}{2}-C\,|a|\Big)\int_\RR f(y)^2 \phi(y)dy.
\end{align}
\end{proposition}
```

The bracket is **`−(1/2 − C|a|)`**. The gap **degrades** with `|a|`. §2's claim — that the
PDF says `(−1/2 − C|a|)` and that the ar5iv HTML mirror is the one with the error — is
**backwards**: the HTML mirror was right, and the "PDF evidence" was a `pdftotext` artifact.
`pdftotext` silently drops `\Big(` … `\Big)`, so the extracted layout renders
`−\Big(1/2 − C|a|\Big)` and `(−1/2 − C|a|)` identically. §2 read a missing parenthesis as a
sign.

**Two independent in-paper corroborations, either of which would have caught it without the
source file:**

1. **The proof structure.** EGM write `M_a f = −(2HF₀+1)f − 2Hf F₀ − y f_y + a M̃_a f` and
   bound `|∫ f M̃_a f φ| ≤ C ∫ |f|² φ`. The `a`-part enters through an *absolute value*, so
   it can only **add** to the `a = 0` value of `−1/2`. A term that can only add cannot
   produce `−1/2 − C|a|`. Their "if `a` is small enough" is exactly the condition
   `1/2 − C|a| > 0`.
2. **Their own §6.** The `C^α` analogue, same weight family, reads
   `(q + Y∂_Y q + 2H_α(F₀^{(α)})q, qφ*) ≥ (1/2 − Cα)|q√φ*|²_{L²}` — degrading in `α` in
   precisely the same shape. §2 quoted this line and did not notice it contradicted the
   reading in the same section.
