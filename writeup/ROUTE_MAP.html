What is left

Avenues that still exist, ranked

  1. W4 clause (c) — statement (D), the torus. The only unbroken localisation clause, and the only surviving path through the finite-energy problem. It sits behind a lane deferred on its own adverse measurements, so taking it means reopening that lane deliberately rather than by default.
  2. §6(ii) — persistence under localisation. Never attacked. Its sibling §6(i) turned out to be far sharper than "no known method" once someone looked, which is the argument for looking here too.
  3. A non-self-similar ansatz. The third branch of the ansatz split, never explored. It escapes the rigidity exclusion by construction, and nothing measured rules it out — nobody has tried to state one.
  4. The search side's realization changes. Multiple shooting and a second-order stepper. The measured cause of 216 failed recoveries is basin structure, and both of these change the basin rather than buying more attempts, which is now refuted twice.
  5. W2's scope, now that the question has been asked and answered. The audit found the certified object is genuinely three-dimensional on W2's own pre-committed test — the swirl component is 57% of the radial one, a principal component rather than a residue. W2 survives only because its statement is scoped to singularity theorems and this is a nonuniqueness theorem. Whether that scope is the wording the wall wants is now an open question on the desk.

What this map is not. A closed branch means closed on a measurement this programme can point at — not proved impossible. Statement (D) is parked, not disproved. The non-self-similar branch is unexplored, not empty.

Live caveats on the two newest closures. Both jaws of the clause-(b) pincer are held at second hand and have never been read at primary source — the same defect that cost this programme two lanes earlier this month. The constant in that unit is basis-dependent and measured on a synthetic profile, because the route has never had a real one banked; the unit now in flight exists to fix exactly that. The verdict survives all of it, because it rests on an exponent measured as zero rather than on any constant.

Nothing here moved a link of the L1 → L4 chain. Closing routes is not the same as approaching an answer. The ceiling is Tier 2 and the odds are unchanged.
