### A note on stale local paths in the record

Roughly thirty banked artefacts — run logs, curated JSON, journal and novelty notes,
and `writeup/CORRECTIONS.md` — contain absolute paths from the original operator's
machine (`/home/andy/…`). They are **left in place deliberately**: this repository's
standing rule is that a banked datum is never edited, only corrected beside, and
scrubbing a cosmetic string out of thirty banked files would break exactly the
discipline the rest of the record depends on.

The paths are not secrets and nothing resolves for anyone else. Templates a reader is
meant to copy — `.mcp.json.example` — have been corrected, because a wrong path there
actively misleads. A handful of experiment scripts still carry hardcoded operator
paths; they would not run unmodified on another machine regardless, and are noted here
rather than silently patched.
